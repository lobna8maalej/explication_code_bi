``` 01

CONTEXTO

Apresentação do projeto

```
```

O projeto Kantra foi realizado como parte da minha formação em Business Intelligence e desenvolvimento de software.

O objetivo era implementar uma cadeia completa de processamento de dados, permitindo passar de dados coletados na Web para uma análise de apoio à decisão com Power BI e, posteriormente, para uma exploração preditiva com Machine Learning.

Uma parte importante do projeto envolve o uso de Web Scraping para recuperar os dados disponíveis nas páginas do Facebook analisadas.
```

``` 07
GERENCIAMENTO DE ESTADO

Redux

```
```

🔄 Gerenciamento global do estado

Redux é utilizado para centralizar determinados dados da aplicação, permitindo que vários componentes acessem o mesmo estado.

O uso de um store evita a circulação desnecessária das mesmas informações entre vários níveis de componentes.

```
```

→
Redux Store
→
Reducer Estado
→
Component Atualização
```
