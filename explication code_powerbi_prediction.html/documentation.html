01

CONTEXTE

Présentation du projet

Le projet Kantra est un projet réalisé dans le cadre de ma formation en Business Intelligence et en développement informatique.

L'objectif était de mettre en place une chaîne complète de traitement des données permettant de passer de données collectées sur le Web à une analyse décisionnelle avec Power BI puis à une exploitation prédictive avec Machine Learning.

Une partie importante du projet concerne l'utilisation du Web Scraping pour récupérer les données disponibles sur les pages Facebook étudiées.

BACKEND

Backend Node.js & Express

Le backend sert d'intermédiaire entre l'application frontend et les services de traitement et de prédiction.

Node.js permet d'exécuter JavaScript côté serveur tandis que Express.js permet de créer les routes de l'API.

React → API Express → Service → Python → Modèle ML

Exemple de route

Express.js

        message: "Prediction OK",

} catch (err) {

    res.status(500).json({
        error: err.toString()
    });

}

07

STATE MANAGEMENT

Redux

🔄 Gestion globale de l'état

Redux est utilisé pour centraliser certaines données de l'application afin de permettre à plusieurs composants d'accéder au même état.

L'utilisation d'un store permet d'éviter de faire circuler inutilement les mêmes informations entre plusieurs niveaux de composants.

Component Action
→
Redux Store
→
Reducer État
→
Component Mise à jour
