CONTEXTO

Presentación del proyecto

```
```

El proyecto Kantra fue realizado como parte de mi formación en Business Intelligence y desarrollo informático.

El objetivo era implementar una cadena completa de procesamiento de datos que permitiera pasar de datos recopilados en la Web a un análisis de toma de decisiones con Power BI y posteriormente a una explotación predictiva mediante Machine Learning.

Una parte importante del proyecto consiste en utilizar Web Scraping para recuperar los datos disponibles en las páginas de Facebook estudiadas.

🌐 Extracción de datos desde Facebook

El proyecto comienza con una fase de recopilación de datos a partir de las páginas de Facebook estudiadas.

GESTIÓN DEL ESTADO

Redux

```
```

🔄 Gestión global del estado

Redux se utiliza para centralizar determinados datos de la aplicación y permitir que varios componentes accedan al mismo estado.

El uso de un store evita hacer circular innecesariamente la misma información entre varios niveles de componentes.
