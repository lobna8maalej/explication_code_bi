CONTEXT

Project Overview

```
```

The Kantra project was developed as part of my training in Business Intelligence and software development.

The objective was to implement a complete data processing pipeline, from data collected on the Web to decision-making analysis with Power BI and then predictive exploitation using Machine Learning.

An important part of the project involves using Web Scraping to retrieve data available from the studied Facebook pages.
