```
1. Apresentação

Esta parte do projeto permite integrar um modelo de Machine Learning em uma aplicação Web.

O modelo é treinado e depois salvo em um arquivo vetement.pkl.

Python é utilizado para carregar o modelo e realizar a predição.

Node.js e Express são utilizados como backend para se comunicar com a aplicação Web.

Objetivo: permitir que o frontend envie um dado ao backend, solicite uma predição ao modelo de Machine Learning, e depois receba o resultado no formato JSON.
```

```
4. Código Python

Python é responsável por carregar o modelo e executar a predição.

📄 predict.py 
import pickle
```

import json

with open("vetement.pkl", "rb") as file:
model = pickle.load(file)

value = 30

result = model.predict([[value]])

print(json.dumps({
"prediction": float(result[0])
}))
