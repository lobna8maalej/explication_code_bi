MODÈLE NCG

Prédiction du numéro de compte global

Lorsque le paramètre mode vaut ncg, le programme charge le modèle NCG_model.pkl.

Python 
if mode == "ncg":

    model_path = os.path.join(
        BASE_DIR,
        "NCG_model.pkl"
    )

    with open(model_path, "rb") as f:
        model = pickle.load(f)

    prediction = model.predict([[value]])

    result = {
        "model": "ncg",
        "input": value,
        "prediction": float(prediction[0])
    }

2. Chemin du modèle

Le chemin vers NCG_model.pkl est construit avec os.path.join().

3. Chargement

Pickle permet de récupérer le modèle Machine Learning déjà entraîné.

4. Prédiction

La méthode model.predict() produit la valeur prédite.

BACKEND

Communication entre Node.js et Python

Node.js sert d'intermédiaire entre l'application et le programme Python.

Le service transaction.js utilise le module child_process pour lancer le programme Python.

transaction.js 
const { spawn } = require("child_process");
const path = require("path");

function runPython(mode, value) {

    return new Promise((resolve, reject) => {

        const scriptPath = path.join(
            __dirname,
            "../../python/app.py"
        );

        const py = spawn("python", [
            scriptPath,
            mode,
            value.toString()
        ]);

        let output = "";

        py.stdout.on(
            "data",
            data => output += data.toString()
        );

        py.stderr.on(
            "data",
            err => console.error(
                "PY ERROR:",
                err.toString()
            )
        );

        py.on("close", (code) => {

            if (code !== 0)
                return reject("Python error");

            resolve(output.trim());

        });

    });

}

module.exports = runPython;

API REST

Route Express de prédiction

POST /transactions

La route Express reçoit les informations nécessaires à la prédiction.

Elle appelle ensuite le service Python, récupère la prédiction et sauvegarde le résultat dans MySQL.

transactionRoute.js 
router.post("/", async (req, res) => {

    let connection;

    try {

        const { mode, value } = req.body;

        if (!mode || value === undefined) {

            return res.status(400).json({
                error: "mode and value are required"
            });

        }

        connection = await getConnection();

        const result =
            await runPython(mode, value);

        console.log(
            "PYTHON RESULT:",
            result
        );

        const data =
            typeof result === "string"
                ? JSON.parse(result)
                : result;

        const prediction =
            data?.prediction ?? null;

        if (prediction === null) {

            return res.status(400).json({
                error: "Invalid prediction from Python",
                debug: data
            });

        }

        await connection.execute(
            `INSERT INTO transactions
             (mode, value, prediction)
             VALUES (?, ?, ?)`,
            [
                mode,
                value,
                prediction
            ]
        );

        return res.json({

            message: "Prediction saved",

            mode,

            value,

            prediction

        });

    } catch (err) {

        console.error(err);

        return res.status(500).json({
            error: err.toString()
        });

    } finally {

        if (connection)
            await connection.end();

    }

});
