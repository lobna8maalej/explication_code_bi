1. Presentación

Esta parte del proyecto permite integrar un modelo de Machine Learning en una aplicación Web.

El modelo se entrena y luego se guarda en un archivo vetement.pkl.

Python se utiliza para cargar el modelo y realizar la predicción.

Node.js y Express se utilizan como backend para comunicarse con la aplicación Web.

Objetivo: permitir que el frontend envíe un dato al backend, solicite una predicción al modelo de Machine Learning y luego recupere el resultado en formato JSON.

7. Integración con Node.js

Node.js constituye la capa backend de la aplicación.

Su función es recibir las solicitudes del frontend, ejecutar el procesamiento necesario y devolver el resultado.

El servidor puede utilizar el módulo nativo child_process para ejecutar Python.

📄 server.js 
const express = require("express"); 
```

const app = express();

app.use(express.json());

const vetementRoute =
require("./routes/vetementRoute");

app.use("/vetement", vetementRoute);

app.listen(3000, () => {
console.log("Server running on port 3000");
});
```

9. Ruta de Ropa

El servidor declara: 

app.use("/vetement", vetementRoute);

Esto significa que las rutas del módulo de ropa comienzan con: 

/vetement

Por ejemplo, si la ruta contiene: 

router.post("/predict", ...)

el endpoint completo se convierte en: 

POST /vetement/predict

10. Ejecución de Python desde Node.js

Node.js puede ejecutar el programa Python gracias al módulo child_process.

Ejemplo de integración Node.js → Python 
const { spawn } = require("child_process"); 
```

const python = spawn("python", [
"predict.py"
]);

let output = "";

python.stdout.on("data", (data) => {
output += data.toString();
});

python.on("close", () => {

const result = JSON.parse(output);

console.log(result);

});
```

10.1 Importación de spawn

const { spawn } = require("child_process");

spawn() permite a Node.js iniciar un proceso externo.

En nuestro caso, el proceso externo es Python.

10.2 Ejecución del script

const python = spawn("python", [ 
```

"predict.py"
]);
```

Node.js solicita al sistema que ejecute: 

python predict.py

10.3 Recuperación de la salida de Python

python.stdout.on("data", (data) => { 
```

output += data.toString();
});
```

Todo lo que Python muestra mediante print() es recuperado por Node.js.

10.4 Conversión del JSON

const result = JSON.parse(output);

Node.js transforma el texto JSON recibido de Python en un objeto JavaScript.

11. Flujo completo de la predicción

  1. El frontend introduce un valor.
  2. El frontend envía una solicitud HTTP a Node.js.
  3. Express recibe la solicitud.
  4. La ruta /vetement/predict procesa la solicitud.
  5. Node.js ejecuta el script Python.
  6. Python carga vetement.pkl.
  7. Python transmite el valor al modelo.
  8. El modelo calcula la predicción.
  9. Python transforma el resultado en JSON.
  10. Node.js recupera el JSON.
  11. Express devuelve la respuesta al frontend.
  12. El frontend muestra la predicción.

13. Seguridad y buenas prácticas

Para un proyecto en producción, se recomiendan algunas mejoras.

  • Utilizar variables de entorno para la información sensible.
  • Evitar colocar las contraseñas directamente en el código.
  • Validar los valores recibidos por la API.
  • Gestionar los errores de Python.
  • Verificar que el archivo del modelo existe.
  • Gestionar los errores de comunicación entre Node.js y Python.
  • Añadir autenticación si la API es pública.
