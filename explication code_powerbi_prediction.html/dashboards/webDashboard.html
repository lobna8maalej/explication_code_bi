Résumé final à retenir

React construit l'interface → useEffect déclenche l'action → dispatch envoie l'action Redux → createWebPrediction reçoit les données → Axios communique avec le backend → le backend traite les données → Machine Learning produit la prédiction → Redux reçoit la réponse → predictionData récupère le résultat → chartData prépare les données → Recharts affiche le résultat → Power BI affiche le rapport analytique.
