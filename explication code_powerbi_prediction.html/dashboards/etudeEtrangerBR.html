Sistema de previsão EduWorld

Este projeto apresenta a integração de um modelo de Machine Learning em Python em uma aplicação web baseada em Node.js / Express, desenvolvida para análise e previsão no contexto de estudos no exterior.

O sistema recebe dados numéricos, envia essas informações para um modelo de Machine Learning treinado, realiza a previsão e retorna o resultado ao backend Node.js.

O resultado final é enviado em formato JSON e pode ser utilizado pelo Dashboard para exibir as informações ao usuário.

Serviço Node.js e comunicação com Python

O backend Node.js é responsável por iniciar o processo Python e recuperar o resultado da previsão.

Importação dos módulos


const { spawn } = require("child_process");
const path = require("path");

Criação da função


function runPrediction(values) {

    return new Promise((resolve, reject) => {

        const pythonScript = path.join(
            __dirname,
            "prediction.py"
        );

        const pythonProcess = spawn(
            "python",
            [pythonScript, ...values]
        );

        let stdout = "";
        let stderr = "";

        pythonProcess.stdout.on("data", (data) => {
            stdout += data.toString();
        });

        pythonProcess.stderr.on("data", (data) => {
            stderr += data.toString();
        });

        pythonProcess.on("close", (code) => {

            if (code !== 0) {
                reject(stderr);
                return;
            }

            resolve(stdout.trim());

        });

    });

}

Rota do Dashboard no Express

Criação do router


const express = require("express");

const router = express.Router();

Importação do serviço


const { runPrediction } = require("../services/predictionService");

Rota do Dashboard


router.get("/dashboard", async (req, res) => {

    try {

        const models = [
            "edufrance",
            "edutest",
            "linked",
            "eduworld"
        ];

        const results = [];

        for (const model of models) {

            const values = [
                parseFloat(req.query.value1),
                parseFloat(req.query.value2)
            ];

            const prediction = await runPrediction(values);

            results.push({
                model,
                prediction
            });

        }

        res.json(results);

    } catch (error) {

        res.status(500).json({
            error: error.message
        });

    }

});

Exemplo concreto do processo

Um usuário acessa o Dashboard e envia valores para realizar uma previsão.

O frontend envia uma requisição para: 


GET /dashboard

O backend Express recebe os dados e chama o serviço Node.js.

O serviço Node.js executa o script Python através de spawn().

O Python carrega o modelo eduworld.pkl, prepara os dados com NumPy e executa a previsão.

O resultado é enviado pelo stdout para Node.js.

Finalmente, Express retorna o resultado em formato JSON para o frontend.
