Présentation générale

Ce module présente l’intégration d’un modèle de Machine Learning développé en Python dans une application Web basée sur Node.js et Express, avec une base de données MySQL pour stocker les résultats.

L’objectif est de créer une architecture permettant à l’application Web de communiquer avec un modèle prédictif Python, de récupérer les résultats sous forme de données JSON, de vérifier ces résultats et de les enregistrer ensuite dans une base de données afin de pouvoir les exploiter dans un dashboard.

Partie Python — Chargement du modèle Machine Learning

Le fichier Python constitue la partie Machine Learning du module. Il est responsable du chargement du modèle diwan.pkl et de la préparation du résultat qui sera transmis à Node.js.

Code Python

📄 radio.py 
import os
import pickle
import json

# 📁 Chemin sécurisé vers le modèle
BASE_DIR = os.path.dirname(__file__)
MODEL_PATH = os.path.join(BASE_DIR, "diwan.pkl")

# 🤖 Chargement du modèle
try:
    with open(MODEL_PATH, "rb") as f:
        model = pickle.load(f)

except Exception as e:
    print("Erreur chargement modèle:", str(e))
    model = None

# 📊 Résultat
result = {
    "status": "success" if model else "error",

    "prediction": 123.4,

    "rows": [
        {
            "reputation_ranking": 80,
            "tuition_fee": 5000,
            "Target": 1
        }
    ],

    "columns": [
        "reputation_ranking",
        "tuition_fee",
        "Target"
    ],

    "images": []
}

# 📤 Affichage JSON
print(json.dumps(result))

Importation des bibliothèques

Le programme commence par importer trois bibliothèques : os, pickle et json.

  • os : permet de manipuler les chemins et les fichiers.
  • pickle : permet de charger le modèle Machine Learning sauvegardé dans le fichier .pkl.
  • json : permet de transformer les résultats Python en format JSON afin que Node.js puisse les récupérer.

Construction du chemin du modèle

BASE_DIR = os.path.dirname(__file__)

MODEL_PATH = os.path.join(
    BASE_DIR,
    "diwan.pkl"
)

BASE_DIR permet de récupérer le dossier dans lequel se trouve le fichier Python.

Ensuite, os.path.join() construit le chemin vers le fichier diwan.pkl.

Cette méthode est plus sécurisée qu’un chemin écrit manuellement car elle permet au programme de retrouver correctement le modèle.

Chargement du modèle

with open(MODEL_PATH, "rb") as f:
    model = pickle.load(f)

Le fichier diwan.pkl est ouvert en mode rb, c’est-à-dire read binary.

La fonction pickle.load() récupère ensuite l’objet Machine Learning sauvegardé dans le fichier.

Le modèle est stocké dans la variable :

model

Gestion des erreurs

except Exception as e:
    print("Erreur chargement modèle:", str(e))
    model = None

Le bloc try / except permet de gérer les erreurs qui peuvent apparaître pendant le chargement du modèle.

Par exemple, si diwan.pkl n’existe pas, le programme ne s’arrête pas brutalement. Le modèle reçoit la valeur None.

Statut du modèle

"status": "success" if model else "error"

Cette instruction vérifie si le modèle a été correctement chargé.

Si le modèle existe, le statut est :

success

Sinon, le statut devient :

error

Attention : prédiction actuellement simulée

Important :

Dans le code fourni, la valeur : 

"prediction": 123.4

est une valeur simulée.

Elle n’est pas encore calculée directement avec model.predict().

Dans une véritable application prédictive, cette partie pourrait être remplacée par une instruction telle que : 

prediction = model.predict(X_test)

avec les données d’entrée correspondant aux variables utilisées lors de l’entraînement du modèle.

Les données `rows`

"rows": [
    {
        "reputation_ranking": 80,
        "tuition_fee": 5000,
        "Target": 1
    }
]

La propriété rows contient les données qui seront ensuite récupérées par Node.js.

Chaque objet représente une ligne de données.

  • reputation_ranking : valeur de classement ou réputation.
  • tuition_fee : valeur numérique associée aux frais.
  • Target : variable cible du modèle ou résultat associé aux données.

Transformation en JSON

print(json.dumps(result))

Cette instruction transforme l’objet Python en JSON.

C’est une étape essentielle car Node.js va récupérer cette sortie afin de l’utiliser dans son application.

03

Service Node.js — Communication avec Python

Le fichier radioservice.js constitue le pont entre Node.js et Python.

Son rôle est de lancer le programme Python, récupérer sa sortie JSON, détecter les erreurs et convertir le JSON Python en objet JavaScript.

Code Node.js

📄 radioservice.js 
const { spawn } = require("child_process");
const path = require("path");

function runPythonPlots() {

    return new Promise((resolve, reject) => {

        console.log("RADIOSERVICE LOADED");

        const py = spawn("python", [
            path.join(
                __dirname,
                "../../python/radio.py"
            )
        ]);

        let output = "";
        let error = "";

        py.stdout.on("data", (data) => {
            output += data.toString();
        });

        py.stderr.on("data", (data) => {
            error += data.toString();
        });

        py.on("close", (code) => {

            if (code !== 0) {
                return reject(
                    error || "Python error"
                );
            }

            try {

                const cleanOutput =
                    output.toString().trim();

                resolve(
                    JSON.parse(cleanOutput)
                );

            } catch (e) {

                console.log(
                    "RAW OUTPUT:",
                    output
                );

                reject(
                    "Invalid JSON from Python"
                );
            }
        });

    });
}

module.exports = {
    runPythonPlots
};

Route Express `/radio`

La route est responsable de coordonner tout le traitement : connexion MySQL, exécution Python, validation des données, insertion dans MySQL et réponse finale.

📄 radioRoute.js 
const express = require("express");
const router = express.Router();

const {
    runPythonPlots
} = require("../service/radioservice");

const {
    getConnection
} = require("../DBMysql/radiodb");

router.get("/", async (req, res) => {

    let connection;

    try {

        connection = await getConnection();

        const result =
            await runPythonPlots();

        if (
            !result ||
            !result.rows ||
            !Array.isArray(result.rows)
        ) {

            return res.status(400).json({
                error: "Invalid Python output"
            });
        }

        for (const row of result.rows) {

            await connection.execute(
                `INSERT INTO plot_data
                (reputation_ranking,
                tuition_fee,
                Target)
                VALUES (?, ?, ?)`,
                [
                    row.reputation_ranking ?? 0,
                    row.tuition_fee ?? 0,
                    row.Target ?? 0
                ]
            );
        }

        res.json({

            message:
                "Plots processed successfully",

            count:
                result.rows.length,

            columns:
                result.columns || [],

            images:
                result.images || []
        });

    } catch (err) {

        console.error(
            "ERROR:",
            err
        );

        res.status(500).json({
            error: err.toString()
        });

    } finally {

        if (connection) {
            await connection.end();
        }
    }
});

module.exports = router;

}

Chaque ligne reçue depuis Python est insérée dans la table plot_data.

Les trois colonnes utilisées sont :

Colonne Valeur Python
reputation_ranking row.reputation_ranking
tuition_fee row.tuition_fee
Target row.Target

Si la valeur de Target est null ou undefined, le backend utilise automatiquement la valeur 0.

Connexion MySQL

Le fichier radiodb.js est responsable de la connexion entre Node.js et MySQL.

📄 radiodb.js 
const mysql =
    require("mysql2/promise");

const dbConfig = {

    host: "localhost",

    user: "root",

    password: "",

    database:
        "POWERBI_PREDICTION"
};

async function getConnection() {

    return await mysql.createConnection(
        dbConfig
    );
}

module.exports = {
    getConnection
};

Cette fonction crée une connexion avec MySQL en utilisant la configuration définie précédemment.

Explication à donner lors de la vente

Lors d’une présentation commerciale, il n’est pas nécessaire de lire chaque ligne du code. Il faut surtout expliquer le fonctionnement global et la valeur apportée par cette architecture.

🎤 Exemple d’explication

« Dans cette partie du projet, j’ai intégré un modèle de Machine Learning développé en Python dans une application Web basée sur Node.js et Express.

Le modèle est sauvegardé dans un fichier diwan.pkl. Lorsque l’application demande les résultats, Express reçoit la requête et appelle un service Node.js dédié.

Ce service utilise child_process.spawn() pour lancer Python et exécuter le script de Machine Learning. Python charge ensuite le modèle avec pickle.

Le résultat produit par Python est transformé en JSON. Node.js récupère ce JSON, le convertit en objet JavaScript et vérifie que les données reçues sont valides.

Les données validées sont ensuite enregistrées dans MySQL, dans la table plot_data.

Enfin, Express retourne une réponse JSON au frontend. Le dashboard peut alors utiliser ces informations pour afficher des tableaux, des indicateurs ou des graphiques.

L’avantage de cette architecture est que chaque technologie possède un rôle précis : Python gère le Machine Learning, Node.js et Express gèrent l’API et la communication, MySQL assure le stockage et le frontend assure la visualisation.

Cette séparation rend le système plus organisé, maintenable et évolutif. »
