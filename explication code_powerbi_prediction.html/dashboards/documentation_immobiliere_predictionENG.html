1. Module Overview

The real estate module processes data coming from real estate agencies and integrates Machine Learning predictions into a Web application.

The system uses two Machine Learning models:

  • model_AROUS.pkl
  • model_gamma.pkl

These models are loaded by Python and then used to produce two predictions from the same input value.

Main objective: allow Node.js to communicate with Python in order to use Machine Learning models within the Web application.

3. Python Prediction Script

The Python script represents the Machine Learning part.

📄 predict.py 
import sys

import json
import pickle
import numpy as np
import os

try:

print("START PYTHON", file=sys.stderr)

# read Node input
data = json.load(sys.stdin)
print("INPUT:", data, file=sys.stderr)

value = data.get("value")

if value is None:
    raise ValueError("missing value")

X_test = np.array([[float(value)]])

# check model files BEFORE loading
if not os.path.exists("model_AROUS.pkl"):
    raise FileNotFoundError("model_AROUS.pkl not found")

if not os.path.exists("model_gamma.pkl"):
    raise FileNotFoundError("model_gamma.pkl not found")

# load models
with open("model_AROUS.pkl", "rb") as f:
    model_arous = pickle.load(f)

with open("model_gamma.pkl", "rb") as f:
    model_gamma = pickle.load(f)

# predictions
prediction_arous = model_arous.predict(X_test)
prediction_gamma = model_gamma.predict(X_test)

result = {
    "status": "ok",
    "input": value,
    "arous": prediction_arous.tolist(),
    "gamma": prediction_gamma.tolist()
}

print(json.dumps(result))

except Exception as e:

print(json.dumps({
    "status": "error",
    "message": str(e)
}))

4. Reading Data Sent by Node.js

4.1 Importing sys 

import sys

The sys module allows access to the standard input and output streams of the Python program.

Here, it is used with: 

sys.stdin

sys.stderr

4.2 Reading Standard Input 

data = json.load(sys.stdin)

This instruction allows Python to read the JSON data sent through its standard input.

For example, Node.js can send: 

{
"value": 30
}

Python then converts this JSON into a Python dictionary.

4.3 Displaying the Received Data 

print("INPUT:", data, file=sys.stderr)

This instruction displays the received information in the standard error output.

Why stderr? Diagnostic messages are separated from the JSON output intended for Node.js. This keeps the standard output clean for the final result.

4.4 Retrieving value 

value = data.get("value")

The get() method retrieves the value property from the dictionary.

4.5 Validation 

if value is None:
raise ValueError("missing value")

This validation prevents the model from running if no value has been provided.

5. Loading the Machine Learning Models

5.1 Converting the Input 

X_test = np.array([[float(value)]])

The received value is converted into a decimal number using float().

It is then transformed into a NumPy array.

Example: 

value = 30

X_test =
[[30.0]]

This structure corresponds to an observation containing one variable.

5.2 Checking the First Model 

if not os.path.exists("model_AROUS.pkl"):
raise FileNotFoundError(
    "model_AROUS.pkl not found"
)

Before loading the model, the program checks that the file actually exists.

5.3 Checking the Second Model 

if not os.path.exists("model_gamma.pkl"):
raise FileNotFoundError(
    "model_gamma.pkl not found"
)

The same check is performed for model_gamma.pkl.

5.4 Loading model_AROUS 

with open("model_AROUS.pkl", "rb") as f:
model_arous = pickle.load(f)

The file is opened in binary mode and the model is reconstructed using pickle.load().

5.5 Loading model_gamma 

with open("model_gamma.pkl", "rb") as f:
model_gamma = pickle.load(f)

The second model is loaded in the same way.

File Python Variable Function

6. Running the Predictions

6.1 AROUS Prediction 

prediction_arous =
model_arous.predict(X_test)

The first model receives the data X_test and calculates its prediction.

6.2 Gamma Prediction 

prediction_gamma =
model_gamma.predict(X_test)

The second model receives exactly the same input but produces its own prediction.

Important point: a single input value can therefore be used to produce two different results thanks to the two Machine Learning models.

10. POST /insert Route

This route allows real estate data to be inserted into the MySQL table.

📄 routes/immobiliereRoute.js 
router.post("/insert", async (req, res) => {

let connection;

try {

    connection =
        await mysql.createConnection(dbConfig);

    const data = req.body;

    for (let row of data) {

        await connection.query(

            "INSERT INTO immobilier " +
            "(idImmobilier, Type, Surface, Prix, Source) " +
            "VALUES (?, ?, ?, ?, ?)",

            [
                row.idImmobilier,
                row.Type,
                row.Surface,
                row.Prix,
                row.Source
            ]

        );

    }

    res.json({

        status: "success",

        message: "Data inserted",

        rows: data.length

    });

}

catch (err) {

    res.status(500).json({

        status: "error",

        message: err.message

    });

}

finally {

    if (connection)
        await connection.end();

}

});

    });

        await connection.end();

}

});

Parameter Value Role

Best practice: in a production application, connection credentials should be stored in environment variables rather than directly in the code.
