📊 Dashboard Plot — Explicación del código

Documentación técnica detallada del funcionamiento de React, Redux Toolkit, Axios, Recharts y Power BI en el Dashboard Plot.

Esta documentación explica el papel de cada parte del archivo PlotDashboard.jsx y del archivo plotSlice.js, así como el recorrido de los datos entre el frontend React, Redux y el backend.

# 152 — Presentación del Dashboard Plot

El Dashboard Plot es una interfaz frontend desarrollada con React. Su objetivo es obtener datos desde el backend, almacenarlos mediante Redux Toolkit, mostrarlos en forma de lista y representarlos gráficamente con Recharts. El dashboard también integra un informe de Power BI mediante un iframe. Por lo tanto, esta funcionalidad se basa en varias tecnologías que trabajan conjuntamente. React construye la interfaz. Redux Toolkit gestiona el estado de los datos. Axios se comunica con la API backend. Recharts crea el gráfico de barras. Power BI proporciona una visualización de Business Intelligence integrada.

# 153 — Organización de los archivos

La funcionalidad Plot se basa principalmente en dos archivos JavaScript:

📄 PlotDashboard.jsx

Este archivo contiene el componente React. Es responsable de mostrar el dashboard, obtener el estado de Redux y representar gráficamente los datos.

📄 plotSlice.js

Este archivo contiene la lógica de Redux. Obtiene los datos desde el backend mediante Axios y gestiona los estados loading, error, message y rows.

Esta separación permite mantener una arquitectura clara. El componente React se ocupa principalmente de la interfaz, mientras que Redux centraliza la lógica de obtención y gestión de los datos.

# 154 — Importación de React y useEffect

El archivo PlotDashboard.jsx comienza importando React y el hook useEffect: 


import React, { useEffect } from "react";

React permite crear el componente de interfaz de usuario. El hook useEffect permite ejecutar código después del renderizado del componente. En nuestro caso, se utiliza para activar automáticamente la obtención de los datos Plot cuando se carga el dashboard. Por lo tanto, el usuario no necesita pulsar un botón para obtener los datos.

# 155 — Importación de useDispatch y useSelector

El componente importa a continuación los dos hooks principales de React Redux: 


import {
    useDispatch,
    useSelector
} from "react-redux";

useDispatch() permite al componente enviar una acción a Redux. En este proyecto se utilizará para ejecutar: 


dispatch(fetchPlotData());

useSelector() permite al componente obtener los datos almacenados en el store de Redux. El componente obtiene aquí: loading, error, message y rows. Estos valores permiten a la interfaz conocer el estado actual de la solicitud y los datos disponibles.

# 156 — Importación de fetchPlotData

El componente importa la acción asíncrona fetchPlotData: 


import { fetchPlotData }
from "../redux/plotSlice";

Esta función está definida en plotSlice.js. Utiliza createAsyncThunk() para realizar una solicitud asíncrona al backend. Por lo tanto, el componente React no contiene directamente la lógica de Axios. Simplemente solicita a Redux que obtenga los datos.

# 157 — Importación de los componentes de Recharts

El dashboard utiliza varios componentes de la biblioteca Recharts: 


import {
    BarChart,
    Bar,
    XAxis,
    YAxis,
    Tooltip,
    CartesianGrid,
    Legend,
    ResponsiveContainer
} from "recharts";

Cada componente tiene una función específica.

  • BarChart: estructura general del gráfico.
  • Bar: representa una serie de datos mediante barras.
  • XAxis: representa el eje horizontal.
  • YAxis: representa el eje vertical.
  • Tooltip: muestra información al pasar el cursor.
  • CartesianGrid: añade una cuadrícula al gráfico.
  • Legend: muestra la leyenda de las series.
  • ResponsiveContainer: permite que el gráfico se adapte al ancho disponible.

# 158 — Importación del archivo CSS

El archivo CSS específico del dashboard se importa mediante: 


import "./plot.css";

Esta instrucción permite separar la lógica del componente de su presentación visual. El archivo plot.css puede controlar: las dimensiones del dashboard, el título, el iframe de Power BI, la lista, los mensajes, el gráfico, los espacios y la responsividad.

# 159 — Creación del componente PlotDashboard

El componente principal se crea mediante: 


export default function PlotDashboard() {

PlotDashboard representa la página completa del Dashboard Plot. Contiene todas las partes visibles para el usuario: el título, el informe de Power BI, el estado de carga, el mensaje de error, el mensaje devuelto por el backend, la lista de datos y el gráfico Plot.

# 160 — Inicialización de dispatch

El componente inicializa la función dispatch: 


const dispatch = useDispatch();

dispatch representa el mecanismo que permite enviar acciones a Redux. En nuestro caso, permitirá activar la obtención de los datos: 


dispatch(fetchPlotData());

Esta instrucción inicia el procesamiento definido en plotSlice.js.

# 161 — Lectura del estado de Redux

El componente obtiene a continuación los datos desde el store de Redux: 


const {
    loading,
    error,
    message,
    rows
} = useSelector(state => state.plot);

El componente accede a:

  • loading: indica si los datos están siendo obtenidos.
  • error: contiene un posible error.
  • message: contiene el mensaje devuelto por el backend.
  • rows: contiene las filas de datos Plot.

Gracias a useSelector(), cualquier modificación de estos valores en Redux provoca automáticamente una actualización de la interfaz React.

# 162 — Activación automática de la solicitud

El hook useEffect contiene: 


useEffect(() => {

    dispatch(fetchPlotData());

}, [dispatch]);

Cuando se carga el componente, React ejecuta este hook. Este llama a: dispatch(fetchPlotData()). Redux Toolkit comienza entonces la ejecución del thunk fetchPlotData. El proceso de obtención de los datos comienza automáticamente.

# 163 — Creación de chartData

Los datos recibidos en rows se preparan para Recharts: 


const chartData = rows.map((item) => ({
    name: `X${item.x}`,
    X: item.x,
    Y: item.y
}));

El método map() recorre cada elemento del array rows. Para cada fila se crea un nuevo objeto.

La propiedad: 


name: `X${item.x}`

construye el nombre utilizado en el eje horizontal. Por ejemplo, si item.x = 10, el nombre será: X10.

La propiedad: 


X: item.x

conserva el valor X.

La propiedad: 


Y: item.y

conserva el valor Y. El array chartData se convierte así en una estructura adaptada a Recharts.
