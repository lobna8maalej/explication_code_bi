PYTHON

Executing the prediction with Python

The voyage.py file is the Python program responsible for executing the prediction.

It retrieves the data sent by Node.js, loads the Machine Learning model saved in voyagito.pkl, prepares the variables and executes the prediction.

voyage.py — Model loading 
BASE_DIR = os.path.dirname(__file__) 
model_path = os.path.join( 
BASE_DIR, 
"voyagito.pkl" 
) 
 
with open(model_path, "rb") as f: 
model = pickle.load(f)

📁 BASE_DIR

Provides the path to the folder containing the Python script.

💾 voyagito.pkl

Contains the already trained and saved Machine Learning model.

🐍 pickle

Allows the saved model to be loaded so that it can be used for a new prediction.

API REST

Express prediction route

An Express route receives data sent by the frontend and triggers the Python prediction process.

POST /voyage
voyageRoute.js 
router.post("/", async (req, res) => { 
 
try { 
 
    if ( 
        !req.body || 
        Object.keys(req.body).length === 0 
    ) { 
 
        return res.status(400).json({ 
            error: "No input data provided" 
        }); 
 
    } 
 
    const result = 
        await runVoyagePython(req.body); 
 
    res.json({ 
        message: "Prediction OK", 
        data: result 
    }); 
 
} catch (err) { 
 
    console.error("ERROR:", err); 
 
    res.status(500).json({ 
        error: err.toString() 
    }); 
 
} 
});

01 — Validation

The server checks that data has actually been sent.

02 — Python

Node.js calls the function that executes the Python program.

03 — Response

The Python result is returned to the frontend in JSON format.
