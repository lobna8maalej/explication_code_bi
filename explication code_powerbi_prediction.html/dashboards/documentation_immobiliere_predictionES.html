Python Machine Learning Node.js Express MySQL JSON

1. Presentación del módulo

El módulo inmobiliario permite procesar datos procedentes de agencias inmobiliarias e integrar predicciones de Machine Learning en una aplicación Web.

El sistema utiliza dos modelos de Machine Learning:

  • model_AROUS.pkl
  • model_gamma.pkl

Estos modelos son cargados por Python y posteriormente utilizados para generar dos predicciones a partir de un mismo valor de entrada.

Objetivo principal: permitir que Node.js se comunique con Python para utilizar los modelos de Machine Learning dentro de la aplicación Web.

3. Script Python de predicción

El script Python constituye la parte de Machine Learning.

📄 predict.py 
import sys

import json
import pickle
import numpy as np
import os

try:

print("START PYTHON", file=sys.stderr)

# leer input Node
data = json.load(sys.stdin)
print("INPUT:", data, file=sys.stderr)

value = data.get("value")

if value is None:
    raise ValueError("value manquante")

X_test = np.array([[float(value)]])

# verificar archivos de modelos ANTES de load
if not os.path.exists("model_AROUS.pkl"):
    raise FileNotFoundError("model_AROUS.pkl introuvable")

if not os.path.exists("model_gamma.pkl"):
    raise FileNotFoundError("model_gamma.pkl introuvable")

# cargar modelos
with open("model_AROUS.pkl", "rb") as f:
    model_arous = pickle.load(f)

with open("model_gamma.pkl", "rb") as f:
    model_gamma = pickle.load(f)

# predicciones
prediction_arous = model_arous.predict(X_test)
prediction_gamma = model_gamma.predict(X_test)

result = {
    "status": "ok",
    "input": value,
    "arous": prediction_arous.tolist(),
    "gamma": prediction_gamma.tolist()
}

print(json.dumps(result))

except Exception as e:

print(json.dumps({
    "status": "error",
    "message": str(e)
}))

4. Lectura de los datos enviados por Node.js

4.1 Importación de sys 

import sys

El módulo sys permite acceder, entre otras cosas, a los flujos de entrada y salida del programa Python.

Aquí se utiliza con: 

sys.stdin

sys.stderr

4.2 Lectura de la entrada estándar 

data = json.load(sys.stdin)

Esta instrucción permite a Python leer los datos JSON enviados a través de su entrada estándar.

Por ejemplo, Node.js puede enviar: 

{
"value": 30
}

Python transforma posteriormente este JSON en un diccionario de Python.

4.3 Mostrar el contenido recibido 

print("INPUT:", data, file=sys.stderr)

Esta instrucción muestra la información recibida en la salida de error estándar.

¿Por qué stderr? Los mensajes de diagnóstico se separan de la salida JSON destinada a Node.js. Esto permite mantener una salida estándar limpia para el resultado final.

4.4 Recuperación de value 

value = data.get("value")

El método get() recupera la propiedad value del diccionario.

4.5 Verificación 

if value is None:
raise ValueError("value manquante")

Esta verificación evita que el modelo funcione si no se ha proporcionado ningún valor.

5. Carga de los modelos de Machine Learning

5.1 Conversión de la entrada 

X_test = np.array([[float(value)]])

El valor recibido se convierte en un número decimal mediante float().

Después se transforma en un array de NumPy.

El archivo se abre en modo binario y el modelo se reconstruye mediante pickle.load().

6. Ejecución de las predicciones

6.1 Predicción AROUS

El primer modelo recibe los datos X_test y calcula su predicción.

10. Ruta POST /insert

Esta ruta permite insertar datos inmobiliarios en la tabla MySQL.

📄 routes/immobiliereRoute.js 
router.post("/insert", async (req, res) => {

let connection;

try {

    connection =
        await mysql.createConnection(dbConfig);

    const data = req.body;

    for (let row of data) {

        await connection.query(

            "INSERT INTO immobilier " +
            "(idImmobilier, Type, Surface, Prix, Source) " +
            "VALUES (?, ?, ?, ?, ?)",

            [
                row.idImmobilier,
                row.Type,
                row.Surface,
                row.Prix,
                row.Source
            ]

        );

    }

    res.json({

        status: "success",

        message: "Data inserted",

        rows: data.length

    });

}

catch (err) {

    res.status(500).json({

        status: "error",

        message: err.message

    });

}

finally {

    if (connection)
        await connection.end();

}

});

11. Ruta POST /process-data

Esta ruta permite realizar un procesamiento de los datos inmobiliarios almacenados en MySQL. 

router.post("/process-data", async (req, res) => {

let connection;

try {

    connection =
        await mysql.createConnection(dbConfig);

    const rawData =
        await fetchData(connection);

    const processedData =
        await processData(rawData);

    await insertData(
        connection,
        processedData
    );

    res.json({

        status: "success",

        message:
            "Immobilier data processed successfully",

        rows:
            processedData.length

    });

}

catch (err) {

    res.status(500).json({

        status: "error",

        message: err.message

    });

}

finally {

    if (connection)
        await connection.end();

}

});

Paso 1 — Conexión MySQL 

connection =
await mysql.createConnection(dbConfig);

Se crea una conexión con la base de datos POWERBI_PREDICTION.

Paso 2 — Recuperación de los datos 

const rawData =
await fetchData(connection);

La función fetchData() recupera los datos de la tabla immobilier.

Paso 3 — Procesamiento 

const processedData =
await processData(rawData);

Los datos se envían a processData() para realizar las transformaciones necesarias.

Paso 4 — Inserción 

await insertData(
connection,
processedData
);

Los datos transformados se insertan en la tabla: 

immobilier_processed

Paso 5 — Respuesta 

res.json({
status: "success",

    "Immobilier data processed successfully",

15. Gestión de errores

El script Python utiliza: 

try:
...

except Exception as e:
...

Esto permite evitar que un error de Python detenga silenciosamente el procesamiento.

Ejemplo: valor faltante 

if value is None:
raise ValueError("value manquante")

Ejemplo: modelo ausente 

if not os.path.exists("model_AROUS.pkl"):
raise FileNotFoundError(
    "model_AROUS.pkl introuvable"
)

Respuesta en caso de error 

{
"status": "error",
"message": "..."
}

En Express, los errores también se capturan mediante: 

catch (err) {

res.status(500).json({

    status: "error",

    message: err.message

});

}
Resultado: el backend puede informar al frontend de que se produjo un error en lugar de permitir que la solicitud falle sin explicación.
