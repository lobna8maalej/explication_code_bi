01 — Apresentação geral do sistema

Este sistema permite integrar modelos de Machine Learning desenvolvidos em Python em uma aplicação web desenvolvida com Node.js e Express.

O objetivo é receber dados enviados pelo frontend, executar os modelos de previsão e retornar os resultados em formato JSON.

Fluxo geral: Frontend → Express → Node.js → Python → Modelos ML → Python → Node.js → Express → Frontend

02 — Script Python de previsão

O arquivo info.py é responsável por executar a parte Machine Learning do sistema.

Ele recebe os dados enviados pelo Node.js, carrega os modelos treinados, realiza as previsões e retorna os resultados em JSON. 

import sys
import json
import pickle
import numpy as np

Importação das bibliotecas

Biblioteca Função
sys Permite recuperar os argumentos enviados pelo Node.js.
json Permite converter os dados JSON.
pickle Permite carregar os modelos Machine Learning.
numpy Permite preparar os dados para os modelos.

03 — Carregamento dos três modelos de Machine Learning

O sistema utiliza três modelos previamente treinados e salvos no formato .pkl. 

with open("INFO2.pkl", "rb") as f:
    model_info2 = pickle.load(f)

with open("INFO3.pkl", "rb") as f:
    model_info3 = pickle.load(f)

with open("gomycode.pkl", "rb") as f:
    model_gomycode = pickle.load(f)
Arquivo Função
INFO2.pkl Modelo de previsão INFO2.
INFO3.pkl Modelo de previsão INFO3.
gomycode.pkl Modelo de previsão Gomycode.

O formato pickle permite salvar e reutilizar modelos Python previamente treinados.

04 — Recepção e preparação dos dados

O Node.js envia os dados para o script Python em formato JSON. 

data = json.loads(sys.argv[1])

O JSON recebido é convertido em um objeto Python.

Em seguida, os dados são transformados em uma matriz NumPy de duas dimensões para serem compatíveis com os modelos. 

X = np.array([[
    data["value"]
]])

Antes da previsão, o sistema também verifica se os dados contêm valores inválidos ou NaN. 

if np.isnan(X).any():
    raise ValueError("Os dados contêm valores NaN")

05 — Execução das três previsões

Depois de preparar os dados, o Python executa os três modelos de Machine Learning. 

prediction_info2 = model_info2.predict(X)
prediction_info3 = model_info3.predict(X)
prediction_gomycode = model_gomycode.predict(X)

Cada modelo retorna uma previsão independente.

Modelo Resultado
INFO2 Previsão do modelo INFO2.
INFO3 Previsão do modelo INFO3.
Gomycode Previsão do modelo Gomycode.

06 — Resultado JSON e tratamento de erros

Depois de executar as previsões, o Python prepara um objeto JSON contendo os três resultados. 

result = {
    "info2": prediction_info2.tolist(),
    "info3": prediction_info3.tolist(),
    "gomycode": prediction_gomycode.tolist()
}

print(json.dumps(result))

O comando print() envia o resultado para o processo Node.js através do stdout.

Em caso de erro, o script também pode retornar uma mensagem para permitir que o Node.js identifique o problema.

07 — Serviço Node.js e comunicação com Python

No backend Node.js, a função runInfoPrediction() é responsável por executar o script Python.

Para isso, o sistema utiliza child_process.spawn(). 

const { spawn } = require("child_process");

Le principe est de lancer le processus Python depuis Node.js et de lui transmettre les données nécessaires. 

const pythonProcess = spawn("python", [
    "info.py",
    JSON.stringify(data)
]);

O JSON é enviado como argumento para o script Python.

08 — Rota Express de previsão

Uma rota Express recebe a solicitação do frontend e chama o serviço de previsão. 

router.post("/predict", async (req, res) => {
    try {
        const result = await runInfoPrediction(req.body);

        res.json(result);
    } catch (error) {
        res.status(500).json({
            message: error.message
        });
    }
});

A rota utilizada para a previsão é:

POST /info/predict

O frontend envia os dados para essa rota e recebe o resultado da previsão em formato JSON.

09 — Servidor Express principal

O servidor Express registra a rota de previsão. 

app.use("/info", infoRoutes);

Isso significa que todas as rotas definidas em infoRoutes estarão disponíveis a partir do prefixo /info.

Portanto, a rota final será:

POST /info/predict

14 — Conclusão

Este sistema permite integrar de forma eficiente modelos de Machine Learning em uma aplicação web.

A arquitetura utiliza Node.js e Express para gerenciar a API, enquanto Python executa os modelos de previsão.

A comunicação entre as diferentes partes do sistema é feita através de JSON.

Essa abordagem permite combinar as vantagens do ecossistema JavaScript para o desenvolvimento web com as ferramentas disponíveis no ecossistema Python para Machine Learning.

Fluxo final: Frontend → API Express → Node.js → Python → Modelos ML → JSON → Node.js → Frontend
