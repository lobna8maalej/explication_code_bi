🤖 Panel de Servidor de Machine Learning — Documentación Técnica

Esta documentación explica detalladamente cómo funciona el componente ServerDashboard.jsx, su conexión con serverSlice.js, su archivo ServerDashboard.css, así como el uso de React, Redux Toolkit, useState, Power BI y el sistema de predicción de Machine Learning.

El Dashboard permite al usuario seleccionar un modelo de Machine Learning, introducir dos variables numéricas X1 y X2, y luego ejecutar una predicción utilizando Redux.

El resultado de la predicción se muestra posteriormente en la interfaz y se añade a un historial de predicciones.

1. Visión General del Proyecto

El componente ServerDashboard.jsx representa la interfaz principal de un Dashboard dedicado a la predicción mediante Machine Learning.

Utiliza React para construir la interfaz de usuario y gestionar los estados locales.

También utiliza Redux Toolkit para gestionar los resultados de las predicciones, el estado de carga, los errores y el historial.

El Dashboard también contiene un informe de Power BI integrado mediante un elemento iframe.

Usuario ↓ ServerDashboard.jsx ↓ Selección del modelo ↓ Entrada de X1 y X2 ↓ Validación ↓ dispatch(fetchServerPrediction()) ↓ serverSlice.js ↓ Procesamiento de la predicción ↓ Redux Store ↓ result / loading / error / history ↓ ServerDashboard.jsx ↓ Visualización del resultado ↓ Historial de predicciones

14. Validación de los Campos

if (
x1 === "" ||
x2 === ""
) {

alert(
    "Please fill in x1 and x2."
);

return;

}

Esta condición comprueba si X1 o X2 están vacíos.

La palabra clave return detiene inmediatamente la ejecución de handlePredict.

¿Por qué es importante esta validación?

Evita que se envíe una solicitud de predicción con variables faltantes.

15. Conversión de los Valores en Números

Los valores procedentes de los campos HTML generalmente se recuperan como cadenas de texto.

La función Number() convierte estos valores en números.

Por ejemplo: 


x1 = "100"
↓
Number(x1)
↓
100

El mismo principio se aplica a X2.

16. Validación Numérica

);

}

Number.isNaN() permite detectar un valor que no es un número válido.

Si X1 o X2 no es válido, el sistema muestra: 


x1 and x2 must be numbers.

React construye la interfaz → useState gestiona el modelo, X1 y X2 → el usuario introduce las variables → handlePredict() valida los datos → dispatch(fetchServerPrediction()) envía la solicitud a Redux → serverSlice.js procesa la predicción → Machine Learning produce un valor → Redux actualiza result, loading, error y history → useSelector recupera esta información → React vuelve a renderizar el componente → el valor predicho se muestra → el historial se actualiza → Power BI muestra el Dashboard analítico → ServerDashboard.css controla la presentación final.

El componente ServerDashboard.jsx constituye, por lo tanto, la interfaz de usuario del sistema de predicción de Machine Learning.

Permite al usuario seleccionar un modelo, introducir dos variables numéricas y ejecutar una predicción.

Antes de enviar la solicitud, el componente comprueba que X1 y X2 estén introducidos y que puedan convertirse en números.

La función dispatch() permite entonces enviar la solicitud a fetchServerPrediction() desde serverSlice.js.

Redux gestiona posteriormente los diferentes estados de la operación: result, loading, error y history.

Cuando la predicción tiene éxito, el resultado se muestra en una tarjeta que contiene el modelo utilizado, los valores X1 y X2, así como el valor predicho.

Cada predicción también puede mostrarse en el historial utilizando history.map().

Al mismo tiempo, el informe de Power BI se integra en un iframe para presentar análisis e indicadores comerciales.

Finalmente, ServerDashboard.css es responsable de la presentación visual de todo el Dashboard.
