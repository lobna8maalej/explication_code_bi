📡 Radio Analytics Dashboard — Documentación técnica

Esta documentación explica en detalle cómo funciona el componente RadioDashboard.jsx, su conexión con radioSlice.js, su archivo RadioDashboard.css, así como el uso de Redux Toolkit, Axios a través del slice, Recharts y Power BI.

El componente proporciona una interfaz de análisis que muestra un informe de Power BI, recupera información del store de Redux y representa determinados datos mediante un gráfico Scatter Plot.

1. Visión general del proyecto

El componente RadioDashboard.jsx representa la interfaz principal del Dashboard dedicada a los datos de RADIO.

Utiliza React para construir la interfaz, Redux Toolkit para recuperar y gestionar los datos globales y Recharts para crear un gráfico Scatter Plot.

El Dashboard también contiene un informe de Power BI integrado directamente en la página mediante un elemento iframe.

Cuando el componente se carga, se ejecuta la acción fetchRadio() para recuperar la información disponible desde el store de Redux.

RadioDashboard.jsx ↓ useEffect() ↓ dispatch(fetchRadio()) ↓ radioSlice.js ↓ Recuperación de datos ↓ Redux ↓ data / loading / error ↓ RadioDashboard.jsx ↓ Información + Scatter Plot ↓ RadioDashboard.css ↓ Interfaz final

3. Importación de fetchRadio

El componente comienza importando la acción fetchRadio desde el archivo radioSlice.js. 

import { fetchRadio } from "../redux/radioSlice";

Esta instrucción crea la conexión entre el componente React y el slice de Redux dedicado a los datos de RADIO.

El componente puede entonces utilizar: 

dispatch(fetchRadio());

para solicitar la recuperación de los datos.

RadioDashboard.jsx ↓ fetchRadio() ↓ radioSlice.js ↓ Proceso de recuperación ↓ Redux Store

4. Importación de React y useEffect

import React, { useEffect } from "react";

React permite construir el componente funcional.

useEffect es un React Hook que permite ejecutar una operación después de que el componente haya sido renderizado.

En este Dashboard, useEffect se utiliza para activar automáticamente fetchRadio() cuando se carga el componente.

5. Importación de useDispatch y useSelector

import {
    useDispatch,
    useSelector
} from "react-redux";

Estos dos Hooks permiten la comunicación entre React y Redux.

useDispatch

useDispatch permite acceder a la función dispatch.

Esta función permite enviar una acción de Redux, en este caso: 

dispatch(fetchRadio());

useSelector

useSelector permite leer una parte del estado global de Redux.

En este componente, recupera el estado: 

state.radio

14. useEffect y recuperación automática de datos

useEffect(() => {
    dispatch(fetchRadio());
}, [dispatch]);

Este bloque se ejecuta después de que el componente haya sido renderizado.

Dentro de él, el componente llama a: 

dispatch(fetchRadio());

Esto activa automáticamente la recuperación de los datos de RADIO cuando se carga el Dashboard.

El array [dispatch]

[dispatch]

indica la dependencia del Hook useEffect.

Por lo tanto, el componente utiliza el mecanismo estándar de React para ejecutar esta operación cuando se carga.

15. Conexión con radioSlice.js

16. Creación de chartData

El componente prepara los datos destinados al gráfico mediante: 

const chartData = data
    ? [
        {
            reputation_ranking: 120,
            tuition_fee: 18000,
            Target: "A"
        },
        {
            reputation_ranking: 200,
            tuition_fee: 22000,
            Target: "B"
        },
    ]
    : [];

El código utiliza aquí una expresión condicional.

Si data existe, el array contiene dos objetos.

Si data no existe, el array se convierte en: 

[]

Esto evita que el gráfico se muestre mientras data no esté disponible.

Punto importante:

En el código proporcionado, los valores reputation_ranking, tuition_fee y Target están escritos directamente dentro del componente.

Por lo tanto, en este código no se extraen directamente de data.

17. Propiedades de chartData

Propiedad Valor de ejemplo Uso
reputation_ranking 120 Se utiliza en el eje X.
tuition_fee 18000 Se utiliza en el eje Y.

Las clases className permiten entonces que CSS controle su apariencia.
