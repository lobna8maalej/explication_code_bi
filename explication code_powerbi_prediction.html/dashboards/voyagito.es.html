El archivo voyage.py constituye el programa Python encargado de ejecutar la predicción.

Recupera los datos enviados por Node.js, carga el modelo de Machine Learning guardado en voyagito.pkl, prepara las variables y ejecuta la predicción.

BASE_DIR = os.path.dirname(__file__) 
model_path = os.path.join(

"voyagito.pkl" 
) 
 
with open(model_path, "rb") as f: 
model = pickle.load(f)

📁 BASE_DIR

Permite obtener la ruta de la carpeta donde se encuentra el script Python.

💾 voyagito.pkl

Contiene el modelo de Machine Learning ya entrenado y guardado.

🐍 pickle

Permite cargar el modelo guardado para utilizarlo en una nueva predicción.

API REST

Ruta Express de predicción

Una ruta Express recibe los datos enviados por el frontend y activa el proceso de predicción de Python.

POST /voyage
voyageRoute.js 
router.post("/", async (req, res) => { 
 
try { 
 
    if ( 
        !req.body || 
        Object.keys(req.body).length === 0 
    ) { 
 
        return res.status(400).json({ 
            error: "No input data provided" 
        }); 
 
    } 
 
    const result = 
        await runVoyagePython(req.body); 
 
    res.json({ 
        message: "Prediction OK", 
        data: result 
    }); 
 
} catch (err) { 
 
    console.error("ERROR:", err); 
 
    res.status(500).json({ 
        error: err.toString() 
    }); 
 
} 
});

01 — Validación

El servidor verifica que se hayan enviado datos.

02 — Python

Node.js llama a la función que ejecuta el programa Python.

03 — Respuesta

El resultado de Python se devuelve al frontend en formato JSON.
