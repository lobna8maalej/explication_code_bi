Seção Python — Carregamento do Modelo de Machine Learning

O arquivo Python representa a parte de Machine Learning do módulo. Ele é responsável por carregar o modelo diwan.pkl e preparar o resultado que será enviado para o Node.js.

Código Python

📄 radio.py 
import os
import pickle
import json

# 📁 Caminho seguro para o modelo
BASE_DIR = os.path.dirname(__file__)
MODEL_PATH = os.path.join(BASE_DIR, "diwan.pkl")

# 🤖 Carregar o modelo
try:
    with open(MODEL_PATH, "rb") as f:
        model = pickle.load(f)

except Exception as e:
    print("Erro ao carregar o modelo:", str(e))
    model = None

# 📊 Resultado
result = {
    "status": "success" if model else "error",

    "prediction": 123.4,

    "rows": [
        {
            "reputation_ranking": 80,
            "tuition_fee": 5000,
            "Target": 1
        }
    ],

    "columns": [
        "reputation_ranking",
        "tuition_fee",
        "Target"
    ],

    "images": []
}

# 📤 Exibir JSON
print(json.dumps(result))

Importação das Bibliotecas

O programa começa importando três bibliotecas: os, pickle e json.

  • os: permite gerenciar caminhos e arquivos.
  • pickle: permite carregar o modelo de Machine Learning salvo no arquivo .pkl.
  • json: permite converter os resultados do Python para o formato JSON, para que o Node.js possa recuperá-los.

Construção do Caminho do Modelo

BASE_DIR = os.path.dirname(__file__)

MODEL_PATH = os.path.join(
    BASE_DIR,
    "diwan.pkl"
)

BASE_DIR obtém o diretório onde o arquivo Python está localizado.

Em seguida, os.path.join() constrói o caminho para o arquivo diwan.pkl.

Esse método é mais seguro do que escrever manualmente um caminho, pois permite localizar corretamente o modelo.

Carregamento do Modelo

with open(MODEL_PATH, "rb") as f:
    model = pickle.load(f)

O arquivo diwan.pkl é aberto no modo rb, que significa read binary.

A função pickle.load() recupera o objeto de Machine Learning armazenado no arquivo.

O modelo é armazenado na seguinte variável:

model

Tratamento de Erros

except Exception as e:
    print("Erro ao carregar o modelo:", str(e))
    model = None

O bloco try / except é utilizado para tratar os erros que podem ocorrer durante o carregamento do modelo.

Por exemplo, se diwan.pkl não existir, o programa não será interrompido inesperadamente. O modelo receberá o valor None.

Status do Modelo

"status": "success" if model else "error"

Essa instrução verifica se o modelo foi carregado corretamente.

Se o modelo existir, o status será:

success

Caso contrário, o status será:

error

Importante: a Previsão Atualmente é Simulada

Importante:

No código fornecido, o valor: 

"prediction": 123.4

é um valor simulado.

Ele ainda não é calculado diretamente utilizando model.predict().

Em uma aplicação preditiva real, essa parte poderia ser substituída por uma instrução como: 

prediction = model.predict(X_test)

utilizando dados de entrada correspondentes às variáveis utilizadas durante o treinamento do modelo.

Dados de `rows`

"rows": [
    {
        "reputation_ranking": 80,
        "tuition_fee": 5000,
        "Target": 1
    }
]

A propriedade rows contém os dados que posteriormente serão recuperados pelo Node.js.

Cada objeto representa uma linha de dados.

  • reputation_ranking: valor de ranking ou reputação.
  • tuition_fee: valor numérico associado às mensalidades ou taxas de matrícula.
  • Target: variável-alvo do modelo ou resultado associado aos dados.

Conversão para JSON

print(json.dumps(result))

Essa instrução converte o objeto Python para JSON.

Essa etapa é essencial porque o Node.js irá recuperar essa saída e utilizá-la dentro da aplicação.

Serviço Node.js — Comunicação com Python

O arquivo radioservice.js funciona como uma ponte entre Node.js e Python.

Sua função é executar o programa Python, recuperar sua saída JSON, detectar erros e converter o JSON do Python em um objeto JavaScript.

Código Node.js

📄 radioservice.js 
const { spawn } = require("child_process");
const path = require("path");

function runPythonPlots() {

    return new Promise((resolve, reject) => {

        console.log("RADIOSERVICE LOADED");

        const py = spawn("python", [
            path.join(
                __dirname,
                "../../python/radio.py"
            )
        ]);

        let output = "";
        let error = "";

        py.stdout.on("data", (data) => {
            output += data.toString();
        });

        py.stderr.on("data", (data) => {
            error += data.toString();
        });

        py.on("close", (code) => {

            if (code !== 0) {
                return reject(
                    error || "Python error"
                );
            }

            try {

                const cleanOutput =
                    output.toString().trim();

                resolve(
                    JSON.parse(cleanOutput)
                );

            } catch (e) {

                console.log(
                    "RAW OUTPUT:",
                    output
                );

                reject(
                    "Invalid JSON from Python"
                );
            }
        });

    });
}

module.exports = {
    runPythonPlots
};

Importando `child_process`

const { spawn } = require("child_process");

O módulo child_process é fornecido pelo Node.js.

Ele permite que o Node.js execute programas externos.

Neste caso, ele é utilizado para executar:

Python

Uso de `spawn()`

const py = spawn("python", [
    path.join(
        __dirname,
        "../../python/radio.py"
    )
]);

Essa instrução solicita ao Node.js que execute o programa Python e o arquivo radio.py.

Esse é o ponto principal da integração:

Node.js
↓
spawn()
↓
Python
↓
Modelo de Machine Learning

Recuperando a Saída do Python

py.stdout.on("data", (data) => {
    output += data.toString();
});

O Python exibe o resultado utilizando: 

print(json.dumps(result))

O Node.js recupera esse resultado por meio de py.stdout.

Recuperando Erros

py.stderr.on("data", (data) => {
    error += data.toString();
});

As mensagens de erro são armazenadas na variável error.

Conversão de JSON

const cleanOutput =
    output.toString().trim();

resolve(
    JSON.parse(cleanOutput)
);

O Python produz texto no formato JSON.

O Node.js utiliza então: 

JSON.parse()

para converter o JSON em um objeto JavaScript.

Rota Express `/radio`

A rota é responsável por coordenar todo o processo: conexão com MySQL, execução do Python, validação dos dados, inserção no MySQL e resposta final.

📄 radioRoute.js 
const express = require("express");
const router = express.Router();

const {
    runPythonPlots
} = require("../service/radioservice");

const {
    getConnection
} = require("../DBMysql/radiodb");

router.get("/", async (req, res) => {

    let connection;

    try {

        connection = await getConnection();

        const result =
            await runPythonPlots();

        if (
            !result ||
            !result.rows ||
            !Array.isArray(result.rows)
        ) {

            return res.status(400).json({
                error: "Invalid Python output"
            });
        }

        for (const row of result.rows) {

            await connection.execute(
                `INSERT INTO plot_data
                (reputation_ranking,
                tuition_fee,
                Target)
                VALUES (?, ?, ?)`,
                [
                    row.reputation_ranking ?? 0,
                    row.tuition_fee ?? 0,
                    row.Target ?? 0
                ]
            );
        }

        res.json({

            message:
                "Plots processed successfully",

            count:
                result.rows.length,

            columns:
                result.columns || [],

            images:
                result.images || []
        });

    } catch (err) {

        console.error(
            "ERROR:",
            err
        );

        res.status(500).json({
            error: err.toString()
        });

    } finally {

        if (connection) {
            await connection.end();
        }
    }
});

module.exports = router;

const router = express.Router();

    await connection.execute(

        (reputation_ranking,
        tuition_fee,
        Target)
        VALUES (?, ?, ?)`,
        [
            row.reputation_ranking ?? 0,
            row.tuition_fee ?? 0,
            row.Target ?? 0
        ]
    );
}

Cada linha recebida do Python é inserida na tabela plot_data.

As três colunas utilizadas são:

Coluna Valor do Python

tuition_fee row.tuition_fee
Target row.Target

Operador `??`

Se o valor de Target for null ou undefined, o backend utilizará automaticamente o valor 0.

    message:

    count:
        result.rows.length,

    columns:
        result.columns || [],

    images:
        result.images || []

Conexão com MySQL

O arquivo radiodb.js é responsável pela conexão entre Node.js e MySQL.

📄 radiodb.js 
const mysql =
    require("mysql2/promise");

const dbConfig = {

    host: "localhost",

    user: "root",

    password: "",

    database:
        "POWERBI_PREDICTION"
};

async function getConnection() {

    return await mysql.createConnection(
        dbConfig
    );
}

module.exports = {
    getConnection
};

Configuração

Parâmetro Valor Função
host localhost Servidor MySQL local
user root Usuário MySQL
password vazio Senha no ambiente de desenvolvimento
database POWERBI_PREDICTION Banco de dados do projeto

Função `getConnection()`

async function getConnection() {

    return await mysql.createConnection(
        dbConfig
    );
}

Essa função cria uma conexão com o MySQL utilizando a configuração definida anteriormente.

O uso de async / await permite que a aplicação aguarde corretamente a criação da conexão.

Explicação para uma Apresentação Comercial

Durante uma apresentação comercial, não é necessário ler cada linha de código. O principal objetivo é explicar o funcionamento geral e o valor proporcionado por essa arquitetura.

🎤 Exemplo de Explicação

“Nesta parte do projeto, integrei um modelo de Machine Learning desenvolvido em Python em uma aplicação Web baseada em Node.js e Express.

O modelo está salvo em um arquivo diwan.pkl. Quando a aplicação solicita os resultados, o Express recebe a requisição e chama um serviço dedicado em Node.js.

Esse serviço utiliza child_process.spawn() para executar o Python e iniciar o script de Machine Learning. Em seguida, o Python carrega o modelo utilizando pickle.

O resultado produzido pelo Python é convertido para JSON. O Node.js recupera esse JSON, converte-o em um objeto JavaScript e verifica se os dados recebidos são válidos.

Os dados validados são então armazenados no MySQL, na tabela plot_data.

Finalmente, o Express retorna uma resposta JSON para o frontend. O dashboard pode então utilizar essas informações para exibir tabelas, indicadores ou gráficos.

A vantagem dessa arquitetura é que cada tecnologia possui uma função específica: o Python cuida do Machine Learning, o Node.js e o Express cuidam da API e da comunicação, o MySQL fornece o armazenamento dos dados e o frontend cuida da visualização.

Essa separação torna o sistema mais organizado, fácil de manter e escalável.”
