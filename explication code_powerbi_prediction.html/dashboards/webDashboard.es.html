Final summary to remember

React builds the interface → useEffect triggers the action → dispatch sends the Redux action → createWebPrediction receives the data → Axios communicates with the backend → the backend processes the data → Machine Learning produces the prediction → Redux receives the response → predictionData retrieves the result → chartData prepares the data → Recharts displays the result → Power BI displays the analytical report.
