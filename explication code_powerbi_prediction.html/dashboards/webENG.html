CONTEXT

Dashboard Overview

This dashboard is based on a complete data processing pipeline, from retrieving information available on the Web to using it within a Web application.

The process begins with data collection from the Web, particularly from a Facebook page studied as part of the training program.

The collected data is then prepared and used in Power BI to build visualizations, indicators and analyses.

A Machine Learning component is then added to generate a prediction based on new values.

Finally, the Python predictive model is integrated into an application using Node.js with Express. This integration allows the frontend to send data to the backend and automatically retrieve the prediction result.

PYTHON PREDICTION

Using the Model

The second Python file is not intended to train the model.

It is used to:

  • load the WUBIK.pkl model;
  • receive data sent by Node.js;
  • validate the data;
  • perform the prediction;
  • return the result in JSON format.
web.py 
import sys
import json
import pickle
import os

try:

    BASE_DIR = os.path.dirname(__file__)

    model_path = os.path.join(
        BASE_DIR,
        "WUBIK.pkl"
    )

    if not os.path.exists(model_path):

        print(json.dumps({
            "error": "Model not found"
        }))

        sys.exit(1)

    with open(model_path, "rb") as f:

        model = pickle.load(f)

    raw_input = sys.stdin.read().strip()

    if not raw_input:

        print(json.dumps({
            "error": "No input received"
        }))

        sys.exit(1)

    input_data = json.loads(raw_input)

    if "x1" not in input_data or "x2" not in input_data:

        print(json.dumps({
            "error": "Missing x1 or x2"
        }))

        sys.exit(1)

    x1 = float(input_data["x1"])
    x2 = float(input_data["x2"])

    X = [[x1, x2]]

    result = model.predict(X)[0]

    print(json.dumps({
        "prediction": float(result)
    }))

except Exception as e:

    print(json.dumps({
        "error": str(e)
    }))

    sys.exit(1)

BACKEND

Node.js — Communication with Python

The webService.js file allows Node.js to launch the Python process and exchange data with it.

webService.js 
const { spawn } = require("child_process");

function runPython(inputData) {

return new Promise((resolve, reject) => {

    if (!inputData) {

        return reject(
            "inputData is undefined"
        );

    }

    const py = spawn(
        "python",
        ["python/web.py"]
    );

    let output = "";
    let error = "";

    py.stdin.write(
        JSON.stringify(inputData)
    );

    py.stdin.end();

    py.stdout.on("data", (data) => {

        output += data.toString();

    });

    py.stderr.on("data", (data) => {

        error += data.toString();

        console.error(
            "PYTHON STDERR:",
            data.toString()
        );

    });

    py.on("close", (code) => {

        console.log(
            "EXIT CODE:",
            code
        );

        console.log(
            "OUTPUT:",
            output
        );

        console.log(
            "ERROR:",
            error
        );

        if (code !== 0) {

            return reject(
                error ||
                output ||
                "Python crashed"
            );

        }

        try {

            resolve(
                JSON.parse(
                    output.trim()
                )
            );

        } catch (e) {

            reject(
                "JSON parse error: " + e
            );

        }

    });

});

}

module.exports = {
runPython
};

REST API

Express Route

The webRoute.js file creates the HTTP route that allows the frontend to request a prediction.

webRoute.js 
const express = require("express");

const router = express.Router();

const {
runPython
} = require("../service/webService");

router.post("/", async (req, res) => {

try {

    console.log(
        "BODY RECEIVED:",
        req.body
    );

    if (!req.body) {

        return res.status(400).json({
            error:
                "No input data provided"
        });

    }

    const result =
        await runPython(req.body);

    res.json({

        message:
            "Prediction OK",

        data:
            result

    });

} catch (err) {

    console.error(
        "ERROR:",
        err
    );

    res.status(500).json({

        error:
            err.toString()

    });

}

});

module.exports = router;
