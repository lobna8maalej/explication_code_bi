📊 Dashboard Plot — Explicação do código

Documentação técnica detalhada do funcionamento de React, Redux Toolkit, Axios, Recharts e Power BI no Dashboard Plot.

Esta documentação explica o papel de cada parte do arquivo PlotDashboard.jsx e do arquivo plotSlice.js, bem como o fluxo dos dados entre o frontend React, Redux e o backend.

# 152 — Apresentação do Dashboard Plot

O Dashboard Plot é uma interface frontend desenvolvida com React. Seu objetivo é obter dados do backend, armazená-los por meio do Redux Toolkit, exibi-los em formato de lista e representá-los graficamente com o Recharts. O dashboard também integra um relatório do Power BI por meio de um iframe. Portanto, essa funcionalidade é baseada em várias tecnologias que trabalham em conjunto. O React constrói a interface. O Redux Toolkit gerencia o estado dos dados. O Axios se comunica com a API do backend. O Recharts cria o gráfico de barras. O Power BI fornece uma visualização integrada de Business Intelligence.

# 153 — Organização dos arquivos

A funcionalidade Plot é baseada principalmente em dois arquivos JavaScript:

📄 PlotDashboard.jsx

Este arquivo contém o componente React. Ele é responsável por exibir o dashboard, obter o estado do Redux e representar graficamente os dados.

📄 plotSlice.js

Este arquivo contém a lógica do Redux. Ele obtém os dados do backend por meio do Axios e gerencia os estados loading, error, message e rows.

Essa separação permite manter uma arquitetura clara. O componente React é responsável principalmente pela interface, enquanto o Redux centraliza a lógica de obtenção e gerenciamento dos dados.

# 154 — Importação do React e useEffect

O arquivo PlotDashboard.jsx começa importando o React e o hook useEffect: 


import React, { useEffect } from "react";

React permite criar o componente da interface do usuário. O hook useEffect permite executar código depois da renderização do componente. Neste projeto, ele é utilizado para iniciar automaticamente a obtenção dos dados Plot quando o dashboard é carregado. Portanto, o usuário não precisa clicar em um botão para obter os dados.

# 155 — Importação de useDispatch e useSelector

O componente importa em seguida os dois principais hooks do React Redux: 


import {
    useDispatch,
    useSelector
} from "react-redux";

useDispatch() permite que o componente envie uma ação para o Redux. Neste projeto, ele será utilizado para executar: 


dispatch(fetchPlotData());

useSelector() permite que o componente obtenha os dados armazenados no store do Redux. O componente obtém aqui: loading, error, message e rows. Esses valores permitem que a interface conheça o estado atual da solicitação e os dados disponíveis.

# 156 — Importação de fetchPlotData

O componente importa a ação assíncrona fetchPlotData: 


import { fetchPlotData }
from "../redux/plotSlice";

Essa função está definida em plotSlice.js. Ela utiliza createAsyncThunk() para realizar uma solicitação assíncrona ao backend. Portanto, o componente React não contém diretamente a lógica do Axios. Ele simplesmente solicita ao Redux que obtenha os dados.

# 157 — Importação dos componentes do Recharts

O dashboard utiliza vários componentes da biblioteca Recharts: 


import {
    BarChart,
    Bar,
    XAxis,
    YAxis,
    Tooltip,
    CartesianGrid,
    Legend,
    ResponsiveContainer
} from "recharts";

Cada componente possui uma função específica.

  • BarChart: estrutura geral do gráfico.
  • Bar: representa uma série de dados por meio de barras.
  • XAxis: representa o eixo horizontal.
  • YAxis: representa o eixo vertical.
  • Tooltip: exibe informações ao passar o cursor.
  • CartesianGrid: adiciona uma grade ao gráfico.
  • Legend: exibe a legenda das séries.
  • ResponsiveContainer: permite que o gráfico se adapte à largura disponível.

# 159 — Criação do componente PlotDashboard

O componente principal é criado por meio de: 


export default function PlotDashboard() {

PlotDashboard representa a página completa do Dashboard Plot. Ele contém todas as partes visíveis para o usuário: o título, o relatório do Power BI, o estado de carregamento, a mensagem de erro, a mensagem retornada pelo backend, a lista de dados e o gráfico Plot.

# 160 — Inicialização do dispatch

O componente inicializa a função dispatch: 


const dispatch = useDispatch();

dispatch representa o mecanismo que permite enviar ações para o Redux. Neste caso, ele permitirá iniciar a obtenção dos dados: 


dispatch(fetchPlotData());

Essa instrução inicia o processamento definido em plotSlice.js.

# 161 — Leitura do estado do Redux

O componente obtém em seguida os dados do store do Redux: 


const {
    loading,
    error,
    message,
    rows
} = useSelector(state => state.plot);

O componente acessa:

  • loading: indica se os dados estão sendo obtidos.
  • error: contém um possível erro.
  • message: contém a mensagem retornada pelo backend.
  • rows: contém as linhas de dados Plot.

Graças ao useSelector(), qualquer alteração desses valores no Redux provoca automaticamente uma atualização da interface React.

# 162 — Ativação automática da solicitação

O hook useEffect contém: 


useEffect(() => {

    dispatch(fetchPlotData());

}, [dispatch]);

Quando o componente é carregado, o React executa esse hook. Ele chama: dispatch(fetchPlotData()). O Redux Toolkit inicia então a execução do thunk fetchPlotData. O processo de obtenção dos dados começa automaticamente.

# 163 — Criação de chartData

Os dados recebidos em rows são preparados para o Recharts: 


const chartData = rows.map((item) => ({
    name: `X${item.x}`,
    X: item.x,
    Y: item.y
}));

O método map() percorre cada elemento do array rows. Para cada linha, um novo objeto é criado.

A propriedade: 


name: `X${item.x}`

constrói o nome utilizado no eixo horizontal. Por exemplo, se item.x = 10, o nome será: X10.

A propriedade: 


X: item.x

mantém o valor X.

A propriedade: 


Y: item.y

mantém o valor Y. O array chartData torna-se assim uma estrutura adaptada ao Recharts.
