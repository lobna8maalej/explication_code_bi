🤖 Prédiction Machine Learning

Documentation technique de l'intégration d'un modèle Machine Learning Python avec une API Node.js et Express.

1. Présentation

Cette partie du projet permet d'intégrer un modèle de Machine Learning dans une application Web.

Le modèle est entraîné puis sauvegardé dans un fichier vetement.pkl.

Python est utilisé pour charger le modèle et effectuer la prédiction.

Node.js et Express sont utilisés comme backend afin de communiquer avec l'application Web.

Objectif : permettre au frontend d'envoyer une donnée au backend, demander une prédiction au modèle Machine Learning, puis récupérer le résultat sous forme de JSON.

13. Sécurité et bonnes pratiques

Pour un projet de production, certaines améliorations sont recommandées.

  • Utiliser des variables d'environnement pour les informations sensibles.
  • Éviter de placer les mots de passe directement dans le code.
  • Valider les valeurs reçues par l'API.
  • Gérer les erreurs Python.
  • Vérifier que le fichier du modèle existe.
  • Gérer les erreurs de communication entre Node.js et Python.
  • Ajouter une authentification si l'API est publique.
