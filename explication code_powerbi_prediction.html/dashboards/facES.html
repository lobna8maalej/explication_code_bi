Sistema de predicción Universidades Privadas

Integración de un modelo de Machine Learning desarrollado con Python, Pandas, Scikit-learn y SVR en una aplicación Web Node.js / Express destinada al análisis de instituciones universitarias privadas.

01

Presentación general del sistema

Este sistema implementa una arquitectura de Machine Learning destinada al análisis y la predicción en el contexto de las universidades privadas. El objetivo es construir un modelo capaz de estudiar una relación entre la duración de un evento o actividad universitaria y un indicador de éxito de los graduados. En este ejemplo, los datos utilizados contienen dos variables principales: graduate_success_rate, que representa la tasa de éxito de los graduados, y event_duration, que representa la duración del evento. El modelo se desarrolla con Python y la biblioteca Scikit-learn. El algoritmo utilizado es una SVR, es decir, una Support Vector Regression, configurada con un núcleo lineal. Una vez entrenado, el modelo se guarda en el archivo EDUCATION_model.pkl mediante Joblib. Esta operación permite reutilizar posteriormente el modelo sin tener que volver a entrenarlo. El backend Node.js utiliza posteriormente el módulo nativo child_process para ejecutar un script Python. La función spawn() permite ejecutar el script Python como un proceso externo. Node.js recupera posteriormente la salida estándar del programa Python mediante stdout. El resultado producido por Python se interpreta como JSON mediante JSON.parse(). Finalmente, Express expone una ruta GET /plot que permite al frontend recuperar los datos preparados por Python. En conjunto, esto constituye una arquitectura en la que Python se encarga del procesamiento de datos y del Machine Learning, mientras que Node.js y Express gestionan la comunicación con la aplicación Web y el dashboard.

Entrenamiento del modelo de Machine Learning

El primer script Python está dedicado a la creación y al entrenamiento del modelo de predicción. El programa comienza importando Pandas, SVR desde Scikit-learn y Joblib. Pandas permite construir un DataFrame que contiene los datos utilizados para el aprendizaje. En este ejemplo, el DataFrame contiene la tasa de éxito de los graduados y la duración de los eventos. La variable X corresponde a las características utilizadas como entrada del modelo. Aquí, el modelo utiliza event_duration. La variable y corresponde a la variable objetivo, es decir, graduate_success_rate. A continuación, se crea el modelo SVR con SVR(kernel='linear'). La elección del núcleo lineal significa que el modelo busca una relación de tipo lineal entre la variable de entrada y la variable que se desea predecir. El método fit(X, y) entrena el modelo a partir de los datos disponibles. Una vez finalizado el aprendizaje, el modelo se guarda en EDUCATION_model.pkl mediante joblib.dump(). El archivo obtenido puede utilizarse posteriormente mediante otro script Python para realizar predicciones sin tener que volver a entrenar el modelo.

Importación de las bibliotecas 

import pandas as pd

from sklearn.svm import SVR

import joblib

Pandas se utiliza para crear y manipular los datos en forma de DataFrame. SVR proporciona el algoritmo de regresión Support Vector Regression. Joblib permite guardar el objeto del modelo entrenado en un archivo para poder reutilizarlo posteriormente.

Creación de los datos 

data = {

    'graduate_success_rate': [85, 85, 90],

    'event_duration': [2, 2, 2]

}

El diccionario data contiene la información utilizada para el aprendizaje. La columna graduate_success_rate representa la tasa de éxito de los graduados, mientras que event_duration representa la duración del evento. En un proyecto real, estos datos podrían proceder de una base de datos, un archivo CSV, una API o un sistema de recopilación de datos.

Creación del DataFrame 

df = pd.DataFrame(data)

La función pd.DataFrame() transforma el diccionario Python en una tabla Pandas. El DataFrame facilita posteriormente la selección de las columnas utilizadas para entrenar el modelo.

Separación de las variables 

X = df[['event_duration']]

y = df['graduate_success_rate']

La variable X contiene la característica de entrada del modelo. En este ejemplo, se trata de la duración del evento. La variable y contiene el valor que el modelo debe aprender a predecir: la tasa de éxito de los graduados. Esta separación corresponde al principio clásico del aprendizaje supervisado.

03

Algoritmo SVR

El algoritmo elegido en este proyecto es SVR, o Support Vector Regression. Se trata de un método de Machine Learning utilizado para resolver problemas de regresión, es decir, cuando el objetivo consiste en predecir un valor numérico. A diferencia de una simple regresión lineal clásica, SVR se basa en el principio de las Support Vector Machines y busca construir una función que respete un determinado margen alrededor de las observaciones. En el código, el modelo se crea mediante SVR(kernel='linear'). El parámetro kernel='linear' indica que el modelo utiliza una relación lineal entre las variables. El método fit(X, y) permite posteriormente que el modelo aprenda la relación entre la duración del evento y la tasa de éxito. La elección de SVR puede ser interesante cuando se desea implementar un enfoque de regresión capaz de generalizar a partir de las observaciones disponibles. En un proyecto real, el modelo debería naturalmente entrenarse con un volumen de datos suficientemente grande y evaluarse mediante métricas adecuadas antes de utilizarlo en una aplicación de toma de decisiones.

Creación del modelo 

model = SVR(kernel='linear')

Esta instrucción crea un modelo SVR con un núcleo lineal. En esta etapa, el modelo todavía está vacío: debe entrenarse con los datos disponibles.

Entrenamiento 

model.fit(X, y)

El método fit() inicia el proceso de aprendizaje. X contiene las variables explicativas y y contiene la variable objetivo. El modelo analiza las relaciones presentes en los datos para poder posteriormente producir predicciones sobre nuevas observaciones.

Principio: Datos universitarios → X = duración del evento → y = tasa de éxito → SVR → Aprendizaje → Modelo entrenado
04

Guardado del modelo con Joblib

Después del entrenamiento, no es necesario conservar todos los datos de aprendizaje en el backend Web. El modelo entrenado puede guardarse como un archivo. En este proyecto, la biblioteca Joblib se utiliza para realizar este guardado. La instrucción joblib.dump(model, 'EDUCATION_model.pkl') guarda el objeto del modelo en un archivo llamado EDUCATION_model.pkl. Este archivo representa el modelo de Machine Learning entrenado. Posteriormente puede ser cargado por otro script Python para producir predicciones. Esta separación entre el entrenamiento y la utilización del modelo es importante en una arquitectura profesional. El entrenamiento puede realizarse periódicamente, mientras que la aplicación Web puede simplemente utilizar la última versión validada del modelo. 

joblib.dump(
    model,
    'EDUCATION_model.pkl'
)

joblib.dump() recibe aquí dos parámetros: el primero corresponde al objeto del modelo entrenado y el segundo corresponde al nombre del archivo de guardado. El archivo PKL podrá posteriormente cargarse con Joblib en un script de predicción.

Resultado: Modelo SVR entrenado → Joblib → EDUCATION_model.pkl → Reutilización del modelo

Preparación de datos con Pandas y JSON

En el sistema completo, Python también puede preparar datos destinados a mostrarse en un gráfico o dashboard. Pandas es especialmente adecuado para esta tarea porque permite manipular fácilmente datos en forma de filas y columnas. Después de crear un DataFrame, el método to_dict(orient="records") permite transformar las filas en una lista de diccionarios Python. Esta estructura se coloca posteriormente en un objeto result. La biblioteca json permite finalmente convertir este objeto Python en una cadena JSON mediante json.dumps(). JSON constituye un formato de intercambio especialmente adecuado entre Python y Node.js. Node.js puede así recibir una estructura fácilmente interpretable por JavaScript. El frontend puede posteriormente utilizar la información recibida para construir gráficos que representen, por ejemplo, la relación entre la duración de un evento y la tasa de éxito.

Creación del DataFrame 

data = {

    "x": [1, 2, 3],

    "y": [10, 20, 30]

}

df = pd.DataFrame(data)

El diccionario contiene dos series de valores. Pandas las transforma en dos columnas dentro del DataFrame. Esta estructura facilita la preparación de los datos antes de transmitirlos a Node.js.

Conversión en records 

result = {

    "rows":
        df.to_dict(
            orient="records"
        )

}

La opción orient="records" pide a Pandas que represente cada fila como un diccionario. El resultado puede tomar la forma de una lista de objetos JavaScript después de la conversión a JSON.

Generación del JSON 

print(
    json.dumps(result)
)

json.dumps() transforma el objeto Python en una cadena JSON. La instrucción print() envía posteriormente esta cadena a stdout, donde Node.js podrá recuperarla.

06

Servicio Node.js y comunicación con Python

El archivo fac.js desempeña el papel de pasarela entre el backend Node.js y los scripts Python. Utiliza el módulo nativo child_process de Node.js y, específicamente, la función spawn(). Esta función permite iniciar un proceso externo, en este caso el programa Python. La función runPython(scriptName) recibe el nombre del script Python que debe ejecutarse y construye automáticamente su ruta mediante path.join(). El proceso Python se inicia posteriormente con spawn("python", [scriptPath]). Durante la ejecución, Node.js escucha stdout para recuperar los datos producidos por Python y stderr para recuperar posibles errores. Cuando Python finaliza, se activa el evento close. Node.js verifica entonces el código de salida. Si este código es diferente de cero, la Promise se rechaza con el mensaje de error. Si la ejecución es correcta, Node.js intenta transformar la salida Python en un objeto JavaScript mediante JSON.parse(). Esta etapa es esencial cuando Python devuelve datos estructurados en JSON. De esta manera, el servicio se convierte en una interfaz entre el mundo Python, especializado en Data Science, y el backend Node.js, especializado en comunicación Web.

Importación de los módulos 

const { spawn } =
require("child_process");

const path =
require("path");

child_process permite ejecutar Python desde Node.js. El módulo path permite construir una ruta de archivo fiable.

Función runPython() 

function runPython(scriptName) {

    return new Promise(
        (resolve, reject) => {

            ...

        }
    );

}

La función devuelve una Promise porque la ejecución del proceso Python es asíncrona. La Promise se resolverá cuando el script haya terminado correctamente o se rechazará en caso de error.

Construcción de la ruta Python 

const scriptPath = path.join(
    __dirname,
    "..",
    "..",
    "python",
    scriptName
);

__dirname representa la carpeta del archivo JavaScript actual. Los diferentes elementos se combinan posteriormente mediante path.join() para localizar el script Python.

Ejecución de Python 

const py = spawn(
    "python",
    [scriptPath]
);

Node.js inicia el programa Python y le proporciona la ruta del script. Esta técnica permite utilizar directamente el entorno Python desde el backend JavaScript.

Recuperación de stdout 

py.stdout.on("data", (data) => {

    output += data.toString();

});

Python escribe su resultado mediante print(). Node.js recupera este resultado gracias a stdout. El método toString() transforma los datos recibidos en texto y el operador += permite reconstruir la salida completa.

Gestión de stderr 

py.stderr.on("data", (data) => {

    error += data.toString();

});

Los mensajes de error generados por Python se recuperan mediante stderr. Esto permite a Node.js conocer los posibles problemas encontrados durante la ejecución.

Transformación JSON 

try {

    resolve(
        JSON.parse(output)
    );

} catch (e) {

    reject(output);

}

Cuando Python devuelve una cadena JSON, JSON.parse() la transforma en un objeto JavaScript. Node.js puede entonces manipular directamente los datos y transmitirlos a Express. Si la salida no es un JSON válido, el bloque catch intercepta el error y rechaza la Promise con la salida recibida.

Ruta Express del sistema

El router Express constituye la capa API que permite al frontend acceder a los datos producidos por Python. El archivo comienza importando Express y posteriormente crea un router mediante express.Router(). El servicio fac.js se importa para utilizar la función runPython(). La ruta GET /plot constituye el punto de entrada que permite recuperar los datos destinados a la visualización. Cuando esta ruta recibe una solicitud, llama a await runPython("plot.py"). El servicio Node.js inicia entonces el script Python plot.py. Python prepara los datos, genera eventualmente las estructuras necesarias para el gráfico y las devuelve en formato JSON. Node.js recibe el resultado y Express lo coloca en la propiedad data. Finalmente, el servidor devuelve una respuesta JSON que contiene un mensaje de confirmación y los datos. El frontend puede entonces recuperar esta respuesta y utilizar los valores para construir un gráfico o alimentar un dashboard dedicado a las universidades privadas.

Creación del router 

const express =
require("express");

const router =
express.Router();

Express se importa y posteriormente se crea un router independiente. Esta organización permite separar las rutas relacionadas con las universidades privadas de las demás rutas de la aplicación.

Importación del servicio 

const { runPython } =
require("../service/fac");

El router recupera la función runPython() desde el servicio Node.js. De esta manera puede iniciar el script Python cuando llega una solicitud.

Ruta GET /plot 

router.get(
    "/plot",
    async (req, res) => {

        ...

    }
);

La ruta utiliza el método HTTP GET. La palabra clave async permite utilizar await para esperar a que finalice la ejecución de Python.

Llamada al script Python 

const result =
    await runPython(
        "plot.py"
    );

Express solicita al servicio Node.js que ejecute específicamente el archivo plot.py. El resultado JSON producido por Python se almacena en la variable result.

Respuesta API 

res.json({

    message: "OK",

    data: result

});

Express devuelve una respuesta JSON que contiene un mensaje de confirmación y los datos producidos por Python. El frontend puede entonces utilizar directamente la propiedad data.

Gestión de errores 

catch (err) {

    res.status(500).json({

        error:
            err.toString()

    });

}

El bloque catch permite gestionar los errores procedentes del servicio Python o de la ejecución del proceso. El servidor devuelve entonces el estado HTTP 500 para indicar un error interno.

Arquitectura completa del sistema

La arquitectura completa se basa en una separación de responsabilidades entre la parte de Machine Learning y la parte de la aplicación Web. El proceso comienza con los datos relativos a las universidades privadas. Estos datos pueden prepararse con Pandas y posteriormente utilizarse para entrenar un modelo SVR. El modelo aprende una relación entre las variables explicativas y la tasa de éxito de los graduados. Después del entrenamiento, el modelo se guarda en EDUCATION_model.pkl mediante Joblib. En la parte Web, el frontend se comunica con la API Express. Cuando llega una solicitud GET /plot, Express llama al servicio fac.js. Este utiliza spawn() para ejecutar el script Python plot.py. El script Python prepara los datos y los devuelve en formato JSON mediante print(json.dumps(...)). Node.js recupera esta salida mediante stdout y posteriormente utiliza JSON.parse() para transformar la cadena JSON en un objeto JavaScript. Express devuelve entonces los datos al frontend. El dashboard puede utilizar estos datos para construir gráficos, indicadores o tablas que permitan realizar un seguimiento de la información relacionada con las universidades privadas. Esta arquitectura permite mantener Python para los procesos de Data Science y Machine Learning, mientras que Node.js y Express se utilizan para exponer los resultados al frontend.

Ejemplo concreto de funcionamiento

Para comprender el funcionamiento completo, imaginemos que el frontend desea recuperar los datos necesarios para mostrar un gráfico sobre las universidades privadas. El frontend envía una solicitud HTTP GET /plot hacia la API Express. La ruta recibe la solicitud y llama a runPython("plot.py"). El servicio Node.js construye automáticamente la ruta del archivo Python y ejecuta el proceso mediante spawn(). El script Python prepara entonces los datos con Pandas. Si los datos deben transformarse en una estructura que pueda utilizar JavaScript, Pandas utiliza to_dict(orient="records"). El objeto obtenido se transforma posteriormente en una cadena JSON mediante json.dumps(). Python utiliza print() para enviar esta cadena a stdout. Node.js recupera la salida mediante py.stdout.on("data", ...). Cuando el proceso Python termina su ejecución, Node.js verifica el código de salida. Si todo se ha ejecutado correctamente, la cadena JSON se convierte en un objeto JavaScript mediante JSON.parse(). Express coloca posteriormente este objeto en la propiedad data de la respuesta. El frontend recibe entonces los datos y puede utilizarlos para construir un gráfico que represente los resultados del sistema de predicción o los datos relacionados con las universidades privadas.
