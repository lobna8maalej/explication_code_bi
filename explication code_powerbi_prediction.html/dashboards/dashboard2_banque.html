1. Présentation du Dashboard

Ce dashboard est consacré à l'analyse des données relatives aux banques.

Les données utilisées dans le projet sont collectées automatiquement à partir de sources disponibles sur Facebook à l'aide d'un processus de Web Scraping.

L'objectif est de transformer les données collectées en données structurées afin de produire des indicateurs et des visualisations dans Power BI, puis d'exploiter ces données dans une partie Machine Learning.

8. Intégration avec Node.js / Express

Le système de Machine Learning peut être intégré au backend Node.js / Express afin de permettre à l'application de communiquer avec les scripts Python.

Node.js utilise le module child_process et la fonction spawn() pour exécuter le programme Python. 


const { spawn } = require("child_process");

const python = spawn(
    "python",
    ["prediction.py"]
);

Le résultat généré par Python est ensuite récupéré par Node.js et peut être retourné sous forme de réponse JSON via une route Express.

7. Machine Learning — Prédiction bancaire

Après la préparation et la structuration des données, une partie Machine Learning est intégrée au projet afin de produire une prédiction à partir des variables sélectionnées.

7.1 Modèle entraîné

Le modèle de Machine Learning est entraîné puis sauvegardé dans un fichier BNA.pkl. Ce fichier contient le modèle entraîné qui sera ensuite chargé par le script Python chargé d'effectuer la prédiction.

7.2 Fichier Python — banque.py

Rôle du fichier :

Le fichier banque.py constitue le programme Python chargé d'effectuer la prédiction. Il reçoit les données envoyées par Node.js sous forme de JSON, charge le modèle BNA.pkl, prépare les variables d'entrée et exécute la prédiction.

Code source


import sys
import json
import pickle
import os
import traceback

try:

    BASE_DIR = os.path.dirname(__file__)

    model_path = os.path.join(BASE_DIR, "BNA.pkl")

    model = pickle.load(open(model_path, "rb"))

    raw = sys.stdin.read().strip()

    print("RAW INPUT:", raw, file=sys.stderr)

    print("MODEL TYPE:", type(model), file=sys.stderr)

    input_data = json.loads(raw)

    X = [[
        float(input_data["x1"]),
        float(input_data["x2"])
    ]]

    result = model.predict(X)[0]

    print(json.dumps({
        "prediction": float(result)
    }))

except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Explication du code

sys permet au programme Python de communiquer avec le processus lancé par Node.js.

json est utilisé pour lire les données reçues au format JSON et retourner le résultat de la prédiction dans ce même format.

pickle permet de charger le modèle Machine Learning précédemment entraîné et sauvegardé dans BNA.pkl.

os permet de construire le chemin vers le fichier du modèle indépendamment de l'emplacement courant d'exécution.

traceback est utilisé pour récupérer les informations détaillées lorsqu'une erreur se produit.

Chargement du modèle


BASE_DIR = os.path.dirname(__file__)

model_path = os.path.join(BASE_DIR, "BNA.pkl")

model = pickle.load(open(model_path, "rb"))

BASE_DIR récupère le dossier dans lequel se trouve le fichier Python. Le chemin vers BNA.pkl est ensuite construit à partir de ce dossier. Enfin, pickle.load() recharge le modèle Machine Learning.

Réception des données


raw = sys.stdin.read().strip()

input_data = json.loads(raw)

Le script lit les données envoyées sur l'entrée standard (stdin). Les données reçues sont ensuite converties depuis JSON vers une structure Python avec json.loads().

Préparation des variables


X = [[
    float(input_data["x1"]),
    float(input_data["x2"])
]]

Les deux variables x1 et x2 sont récupérées depuis les données JSON. Elles sont converties en nombres avec float() puis placées dans une structure compatible avec le modèle de Machine Learning.

Génération de la prédiction


result = model.predict(X)[0]

La méthode predict() applique le modèle entraîné aux données d'entrée. Le résultat correspondant à la première prédiction est récupéré avec [0].

Retour du résultat


print(json.dumps({
    "prediction": float(result)
}))

Le résultat est converti en JSON afin de pouvoir être récupéré facilement par Node.js.

Gestion des erreurs


except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Si une erreur apparaît pendant le chargement du modèle, la lecture des données ou la prédiction, le programme retourne un objet JSON contenant le message d'erreur ainsi que la trace détaillée.
