Système de prédiction Universités Privées

Intégration d'un modèle Machine Learning développé avec Python, Pandas, Scikit-learn et SVR dans une application Web Node.js / Express destinée à l'analyse des établissements universitaires privés.

01

Présentation générale du système

Ce système met en place une architecture de Machine Learning destinée à l'analyse et à la prédiction dans le contexte des universités privées. L'objectif est de construire un modèle capable d'étudier une relation entre la durée d'un événement ou d'une activité universitaire et un indicateur de réussite des diplômés. Dans cet exemple, les données utilisées contiennent deux variables principales : graduate_success_rate, qui représente le taux de réussite des diplômés, et event_duration, qui représente la durée de l'événement. Le modèle est développé avec Python et la bibliothèque Scikit-learn. L'algorithme utilisé est une SVR, c'est-à-dire une Support Vector Regression, configurée avec un noyau linéaire. Une fois entraîné, le modèle est sauvegardé dans le fichier EDUCATION_model.pkl grâce à Joblib. Cette sauvegarde permet de réutiliser le modèle ultérieurement sans refaire son entraînement. Le backend Node.js utilise ensuite le module natif child_process pour lancer un script Python. La fonction spawn() permet d'exécuter le script Python comme un processus externe. Node.js récupère ensuite la sortie standard du programme Python grâce à stdout. Le résultat produit par Python est interprété comme du JSON grâce à JSON.parse(). Enfin, Express expose une route GET /plot permettant au frontend de récupérer les données préparées par Python. L'ensemble constitue donc une architecture dans laquelle Python est responsable du traitement des données et du Machine Learning tandis que Node.js et Express assurent la communication avec l'application Web et le dashboard.

Entraînement du modèle Machine Learning

Le premier script Python est consacré à la création et à l'entraînement du modèle de prédiction. Le programme commence par importer Pandas, SVR depuis Scikit-learn et Joblib. Pandas permet de construire un DataFrame contenant les données utilisées pour l'apprentissage. Dans cet exemple, le DataFrame contient le taux de réussite des diplômés ainsi que la durée des événements. La variable X correspond aux caractéristiques utilisées comme entrée du modèle. Ici, le modèle utilise event_duration. La variable y correspond à la variable cible, c'est-à-dire graduate_success_rate. Le modèle SVR est ensuite créé avec SVR(kernel='linear'). Le choix du noyau linéaire signifie que le modèle cherche une relation de type linéaire entre la variable d'entrée et la variable à prédire. La méthode fit(X, y) entraîne le modèle à partir des données disponibles. Une fois l'apprentissage terminé, le modèle est sauvegardé dans EDUCATION_model.pkl avec joblib.dump(). Le fichier obtenu peut ensuite être utilisé par un autre script Python pour effectuer des prédictions sans refaire l'entraînement.

Importation des bibliothèques 

import pandas as pd

from sklearn.svm import SVR

import joblib

Pandas est utilisé pour créer et manipuler les données sous forme de DataFrame. SVR fournit l'algorithme de régression Support Vector Regression. Joblib permet de sauvegarder l'objet modèle entraîné dans un fichier afin de pouvoir le réutiliser ultérieurement.

Création des données 

data = {

    'graduate_success_rate': [85, 85, 90],

    'event_duration': [2, 2, 2]

}

Le dictionnaire data contient les informations utilisées pour l'apprentissage. La colonne graduate_success_rate représente le taux de réussite des diplômés, tandis que event_duration représente la durée de l'événement. Dans un véritable projet, ces données pourraient provenir d'une base de données, d'un fichier CSV, d'une API ou d'un système de collecte de données.

Création du DataFrame 

df = pd.DataFrame(data)

La fonction pd.DataFrame() transforme le dictionnaire Python en tableau Pandas. Le DataFrame facilite ensuite la sélection des colonnes utilisées pour entraîner le modèle.

Séparation des variables 

X = df[['event_duration']]

y = df['graduate_success_rate']

La variable X contient la caractéristique d'entrée du modèle. Dans cet exemple, il s'agit de la durée de l'événement. La variable y contient la valeur que le modèle doit apprendre à prédire : le taux de réussite des diplômés. Cette séparation correspond au principe classique de l'apprentissage supervisé.

03

Algorithme SVR

L'algorithme choisi dans ce projet est SVR, ou Support Vector Regression. Il s'agit d'une méthode de Machine Learning utilisée pour résoudre des problèmes de régression, c'est-à-dire lorsque l'objectif consiste à prédire une valeur numérique. Contrairement à une simple régression linéaire classique, SVR repose sur le principe des Support Vector Machines et cherche à construire une fonction qui respecte une certaine marge autour des observations. Dans le code, le modèle est créé avec SVR(kernel='linear'). Le paramètre kernel='linear' indique que le modèle utilise une relation linéaire entre les variables. La méthode fit(X, y) permet ensuite au modèle d'apprendre la relation entre la durée de l'événement et le taux de réussite. Le choix de SVR peut être intéressant lorsqu'on souhaite mettre en place une approche de régression capable de généraliser à partir des observations disponibles. Dans un projet réel, le modèle devrait naturellement être entraîné sur un volume de données suffisamment important et évalué avec des métriques adaptées avant d'être utilisé dans une application décisionnelle.

Création du modèle 

model = SVR(kernel='linear')

Cette instruction crée un modèle SVR avec un noyau linéaire. Le modèle est encore vide à cette étape : il doit être entraîné avec les données disponibles.

Entraînement 

model.fit(X, y)

La méthode fit() lance le processus d'apprentissage. X contient les variables explicatives et y contient la variable cible. Le modèle analyse les relations présentes dans les données afin de pouvoir ensuite produire des prédictions sur de nouvelles observations.

Principe : Données universitaires → X = durée de l'événement → y = taux de réussite → SVR → Apprentissage → Modèle entraîné
04

Sauvegarde du modèle avec Joblib

Après l'entraînement, il n'est pas nécessaire de conserver toutes les données d'apprentissage dans le backend Web. Le modèle entraîné peut être sauvegardé sous forme de fichier. Dans ce projet, la bibliothèque Joblib est utilisée pour effectuer cette sauvegarde. L'instruction joblib.dump(model, 'EDUCATION_model.pkl') enregistre l'objet modèle dans un fichier appelé EDUCATION_model.pkl. Ce fichier représente le modèle Machine Learning entraîné. Il peut ensuite être chargé par un autre script Python afin de produire des prédictions. Cette séparation entre l'entraînement et l'utilisation du modèle est importante dans une architecture professionnelle. L'entraînement peut être effectué périodiquement, tandis que l'application Web peut simplement utiliser la dernière version validée du modèle. 

joblib.dump(
    model,
    'EDUCATION_model.pkl'
)

joblib.dump() prend ici deux paramètres : le premier correspond à l'objet modèle entraîné et le second correspond au nom du fichier de sauvegarde. Le fichier PKL pourra ensuite être chargé avec Joblib dans un script de prédiction.

Résultat : Modèle SVR entraîné → Joblib → EDUCATION_model.pkl → Réutilisation du modèle

Préparation des données avec Pandas et JSON

Dans le système complet, Python peut également préparer des données destinées à être affichées dans un graphique ou un dashboard. Pandas est particulièrement adapté à cette tâche car il permet de manipuler facilement des données sous forme de lignes et de colonnes. Après la création d'un DataFrame, la méthode to_dict(orient="records") permet de transformer les lignes en une liste de dictionnaires Python. Cette structure est ensuite placée dans un objet result. La bibliothèque json permet enfin de convertir cet objet Python en chaîne JSON avec json.dumps(). Le JSON constitue un format d'échange particulièrement adapté entre Python et Node.js. Node.js récupère ainsi une structure facilement interprétable par JavaScript. Le frontend peut ensuite utiliser les informations reçues pour construire des graphiques représentant, par exemple, la relation entre la durée d'un événement et le taux de réussite.

Création du DataFrame 

data = {

    "x": [1, 2, 3],

    "y": [10, 20, 30]

}

df = pd.DataFrame(data)

Le dictionnaire contient deux séries de valeurs. Pandas les transforme en deux colonnes dans le DataFrame. Cette structure facilite la préparation des données avant leur transmission à Node.js.

Conversion en records 

result = {

    "rows":
        df.to_dict(
            orient="records"
        )

}

L'option orient="records" demande à Pandas de représenter chaque ligne comme un dictionnaire. Le résultat peut donc prendre la forme d'une liste d'objets JavaScript après conversion JSON.

Génération du JSON 

print(
    json.dumps(result)
)

json.dumps() transforme l'objet Python en chaîne JSON. L'instruction print() envoie ensuite cette chaîne dans stdout, où Node.js pourra la récupérer.

06

Service Node.js et communication avec Python

Le fichier fac.js joue le rôle de passerelle entre le backend Node.js et les scripts Python. Il utilise le module natif child_process de Node.js et particulièrement la fonction spawn(). Cette fonction permet de lancer un processus externe, ici le programme Python. La fonction runPython(scriptName) reçoit le nom du script Python à exécuter et construit automatiquement son chemin grâce à path.join(). Le processus Python est ensuite lancé avec spawn("python", [scriptPath]). Pendant l'exécution, Node.js écoute stdout afin de récupérer les données produites par Python et stderr afin de récupérer les éventuelles erreurs. Lorsque Python termine, l'événement close est déclenché. Node.js vérifie alors le code de sortie. Si ce code est différent de zéro, la Promise est rejetée avec le message d'erreur. Si l'exécution est correcte, Node.js tente de transformer la sortie Python en objet JavaScript grâce à JSON.parse(). Cette étape est essentielle lorsque Python retourne des données structurées en JSON. Le service devient ainsi une interface entre le monde Python, spécialisé dans la Data Science, et le backend Node.js, spécialisé dans la communication Web.

Importation des modules 

const { spawn } =
require("child_process");

const path =
require("path");

child_process permet de lancer Python depuis Node.js. Le module path permet de construire un chemin de fichier fiable.

Fonction runPython() 

function runPython(scriptName) {

    return new Promise(
        (resolve, reject) => {

            ...

        }
    );

}

La fonction retourne une Promise car l'exécution du processus Python est asynchrone. La Promise sera résolue lorsque le script aura terminé correctement ou rejetée en cas d'erreur.

Construction du chemin Python 

const scriptPath = path.join(
    __dirname,
    "..",
    "..",
    "python",
    scriptName
);

__dirname représente le dossier du fichier JavaScript actuel. Les différents éléments sont ensuite assemblés avec path.join() afin de localiser le script Python.

Exécution de Python 

const py = spawn(
    "python",
    [scriptPath]
);

Node.js lance le programme Python et lui transmet le chemin du script. Cette technique permet d'utiliser directement l'environnement Python depuis le backend JavaScript.

Récupération de stdout 

py.stdout.on("data", (data) => {

    output += data.toString();

});

Python écrit son résultat avec print(). Node.js récupère ce résultat grâce à stdout. La méthode toString() transforme les données reçues en texte et l'opérateur += permet de reconstruire la sortie complète.

Gestion de stderr 

py.stderr.on("data", (data) => {

    error += data.toString();

});

Les messages d'erreur générés par Python sont récupérés grâce à stderr. Cela permet à Node.js de connaître les éventuels problèmes rencontrés pendant l'exécution.

Transformation JSON 

try {

    resolve(
        JSON.parse(output)
    );

} catch (e) {

    reject(output);

}

Lorsque Python retourne une chaîne JSON, JSON.parse() la transforme en objet JavaScript. Node.js peut alors manipuler directement les données et les transmettre à Express. Si la sortie n'est pas un JSON valide, le bloc catch intercepte l'erreur et rejette la Promise avec la sortie reçue.

Route Express du système

Le routeur Express constitue la couche API qui permet au frontend d'accéder aux données produites par Python. Le fichier commence par importer Express puis crée un routeur avec express.Router(). Le service fac.js est ensuite importé afin d'utiliser la fonction runPython(). La route GET /plot constitue le point d'entrée permettant de récupérer les données destinées à la visualisation. Lorsque cette route reçoit une requête, elle appelle await runPython("plot.py"). Le service Node.js lance alors le script Python plot.py. Python prépare les données, génère éventuellement les structures nécessaires au graphique et les retourne au format JSON. Node.js reçoit le résultat et Express le place dans la propriété data. Le serveur retourne finalement une réponse JSON contenant un message de confirmation et les données. Le frontend peut alors récupérer cette réponse et utiliser les valeurs pour construire un graphique ou alimenter un dashboard dédié aux universités privées.

Création du routeur 

const express =
require("express");

const router =
express.Router();

Express est importé puis un routeur indépendant est créé. Cette organisation permet de séparer les routes relatives aux universités privées des autres routes de l'application.

Importation du service 

const { runPython } =
require("../service/fac");

Le routeur récupère la fonction runPython() depuis le service Node.js. Il peut ainsi déclencher le script Python lorsqu'une requête arrive.

Route GET /plot 

router.get(
    "/plot",
    async (req, res) => {

        ...

    }
);

La route utilise la méthode HTTP GET. Le mot-clé async permet d'utiliser await afin d'attendre la fin de l'exécution Python.

Appel du script Python 

const result =
    await runPython(
        "plot.py"
    );

Express demande au service Node.js d'exécuter précisément le fichier plot.py. Le résultat JSON produit par Python est récupéré dans la variable result.

Réponse API 

res.json({

    message: "OK",

    data: result

});

Express retourne une réponse JSON contenant un message de confirmation et les données produites par Python. Le frontend peut alors exploiter directement la propriété data.

Gestion des erreurs 

catch (err) {

    res.status(500).json({

        error:
            err.toString()

    });

}

Le bloc catch permet de gérer les erreurs provenant du service Python ou de l'exécution du processus. Le serveur retourne alors le statut HTTP 500 afin d'indiquer une erreur interne.

Architecture complète du système

L'architecture complète repose sur une séparation des responsabilités entre la partie Machine Learning et la partie application Web. Le processus commence avec les données relatives aux universités privées. Ces données peuvent être préparées avec Pandas puis utilisées pour entraîner un modèle SVR. Le modèle apprend une relation entre les variables explicatives et le taux de réussite des diplômés. Après l'entraînement, le modèle est sauvegardé dans EDUCATION_model.pkl avec Joblib. Dans la partie Web, le frontend communique avec l'API Express. Lorsqu'une requête GET /plot arrive, Express appelle le service fac.js. Celui-ci utilise spawn() pour lancer le script Python plot.py. Le script Python prépare les données et les retourne au format JSON grâce à print(json.dumps(...)). Node.js récupère cette sortie grâce à stdout puis utilise JSON.parse() pour transformer la chaîne JSON en objet JavaScript. Express retourne ensuite les données au frontend. Le dashboard peut utiliser ces données pour construire des graphiques, des indicateurs ou des tableaux permettant de suivre les informations relatives aux universités privées. Cette architecture permet donc de conserver Python pour les traitements Data Science et Machine Learning tout en utilisant Node.js et Express pour exposer les résultats au frontend.

Rôle des technologies

Chaque technologie possède une fonction précise dans l'architecture. Python constitue l'environnement d'exécution du Machine Learning. Pandas permet de créer et manipuler les données. Scikit-learn fournit l'algorithme SVR utilisé pour la régression. Joblib permet de sauvegarder le modèle entraîné dans un fichier PKL. Cette combinaison permet donc d'associer les capacités Data Science de Python avec les capacités Web de Node.js et Express.

Exemple concret de fonctionnement

Pour comprendre le fonctionnement complet, imaginons que le frontend souhaite récupérer les données nécessaires à l'affichage d'un graphique sur les universités privées. Le frontend envoie une requête HTTP GET /plot vers l'API Express. La route reçoit la requête et appelle runPython("plot.py"). Le service Node.js construit automatiquement le chemin du fichier Python et lance le processus avec spawn(). Le script Python prépare alors les données avec Pandas. Si les données doivent être transformées en structure exploitable par JavaScript, Pandas utilise to_dict(orient="records"). L'objet obtenu est ensuite transformé en chaîne JSON avec json.dumps(). Python utilise print() pour envoyer cette chaîne dans stdout. Node.js récupère la sortie avec py.stdout.on("data", ...). Lorsque le processus Python termine son exécution, Node.js vérifie le code de sortie. Si tout s'est correctement déroulé, la chaîne JSON est convertie en objet JavaScript avec JSON.parse(). Express place ensuite cet objet dans la propriété data de la réponse. Le frontend reçoit alors les données et peut les utiliser pour construire un graphique représentant les résultats du système de prédiction ou les données relatives aux universités privées.

Cette architecture montre comment un modèle Data Science développé en Python peut être intégré efficacement dans une application Web moderne basée sur Node.js et Express.
