Sistema de Predicción EduWorld

Integración de un modelo de Machine Learning desarrollado en Python dentro de una aplicación Web con Node.js / Express diseñada para el análisis y la predicción en el ámbito de los estudios en el extranjero.

01

Visión general del sistema

Este sistema implementa una arquitectura de predicción basada en Machine Learning diseñada para una aplicación Web relacionada con los estudios en el extranjero. El objetivo es permitir que una aplicación desarrollada con Node.js y Express utilice un modelo de Machine Learning entrenado en Python. El funcionamiento se divide en varias partes con el fin de hacer que la aplicación sea organizada, modular y fácilmente escalable. La primera parte corresponde al modelo de Machine Learning guardado en el archivo eduworld.pkl. Este archivo contiene un modelo previamente entrenado que puede ser cargado por Python para producir una predicción sin tener que volver a entrenar el modelo en cada solicitud. La segunda parte corresponde al script de Python predict.py. Este script actúa como motor de predicción. Recupera los valores enviados como argumentos desde Node.js, los convierte en números utilizando float(), verifica que el número de variables coincida exactamente con el número de características esperado por el modelo, transforma los datos en un array de NumPy y después llama al método predict() del modelo cargado. El resultado se envía posteriormente a la salida estándar utilizando print(). Otra parte del proyecto también utiliza Pandas para crear y manipular datos tabulares. El DataFrame creado con Pandas puede convertirse en objetos JSON para facilitar su uso por parte de una aplicación Web. La tercera parte corresponde al servicio de Node.js etudeEtranger. Este servicio utiliza el módulo nativo child_process, especialmente la función spawn(), para ejecutar el programa Python desde Node.js. Los valores se pasan al script de Python como argumentos de línea de comandos. Node.js escucha stdout para recuperar el resultado de Python y stderr para recuperar posibles errores. Finalmente, una ruta de Express llamada /dashboard utiliza este servicio varias veces con diferentes modos de predicción. Los resultados se agrupan en un array y posteriormente se devuelven al frontend como un objeto JSON. Por lo tanto, la arquitectura completa permite conectar un modelo de Machine Learning de Python con una aplicación Web moderna y centralizar múltiples predicciones en un dashboard.

02

Script de predicción en Python

El archivo predict.py representa el núcleo del procesamiento de Machine Learning. Su función es cargar el modelo guardado, recibir los datos enviados por Node.js, validarlos, preparar las variables en formato numérico y posteriormente ejecutar la predicción. El script comienza importando las bibliotecas necesarias. El módulo sys proporciona acceso a los argumentos enviados al programa Python desde Node.js. El módulo os se utiliza para construir rutas de archivos fiables independientemente del directorio desde el cual se ejecuta el programa. La biblioteca pickle permite volver a cargar el modelo de Machine Learning guardado previamente. Finalmente, numpy se utiliza para crear el array numérico que será enviado al modelo. Después de las importaciones, el script determina automáticamente el directorio en el que se encuentra utilizando os.path.abspath(__file__) y os.path.dirname(). A continuación, se construye la ruta hacia eduworld.pkl utilizando os.path.join(). El archivo se abre en modo binario utilizando "rb" y el modelo se carga mediante pickle.load(). El modelo queda entonces disponible en memoria y puede utilizarse para realizar una predicción.

Importación de las bibliotecas 

import sys

import os
import pickle
import numpy as np

sys se utiliza para recuperar los argumentos enviados al script de Python. os se utiliza para gestionar las rutas de archivos. pickle se utiliza para cargar el modelo de Machine Learning guardado en un archivo PKL. Finalmente, NumPy se utiliza para transformar los datos recibidos en una estructura numérica compatible con el modelo.

Determinación del directorio de Python 

BASE_DIR = os.path.dirname(
os.path.abspath(__file__)
)

Esta instrucción determina la ruta absoluta del directorio que contiene el script de Python. __file__ representa el archivo que se está ejecutando actualmente. abspath() transforma su ruta en una ruta absoluta y dirname() recupera únicamente el directorio. Este enfoque evita depender del directorio actual desde el cual Node.js ejecuta Python.

Ubicación del modelo 

MODEL_PATH = os.path.join(
BASE_DIR,
"eduworld.pkl"
)

La ruta completa del modelo se construye combinando el directorio del script con el nombre de archivo eduworld.pkl. De esta manera, el modelo puede cargarse incluso cuando la aplicación se ejecuta desde otra ubicación.

Carga del modelo 

with open(
MODEL_PATH,
"rb"
) as f:

model = pickle.load(f)

El archivo PKL se abre en modo de lectura binaria utilizando "rb". La función pickle.load() reconstruye el objeto de Machine Learning que se había guardado previamente. El modelo queda entonces disponible en la variable model. La ventaja de este enfoque es que un modelo ya entrenado puede reutilizarse directamente en lugar de volver a entrenarlo para cada predicción.

03

Recepción y validación de variables

Una vez cargado el modelo, el script debe recuperar las variables necesarias para realizar la predicción. En esta arquitectura, Node.js envía los valores a Python directamente mediante la línea de comandos. Python puede recuperar estos valores utilizando sys.argv. La expresión sys.argv[1:] recupera únicamente los argumentos enviados después del nombre del script. La función map(float, ...) convierte cada valor recibido en un número decimal. Todo el resultado se convierte posteriormente en una lista mediante list(). El bloque try / except protege esta operación. Si un valor no puede convertirse en un número, el programa muestra un mensaje de error y utiliza sys.exit() para detener su ejecución. Después de esta validación inicial, el programa comprueba el número de variables recibidas. La propiedad model.n_features_in_ permite determinar el número de características utilizadas por el modelo durante el entrenamiento. Por lo tanto, el script compara el número de valores recibidos con el número de características esperadas. Esta verificación es importante porque un modelo entrenado con cuatro variables no puede recibir arbitrariamente una o cinco variables. Si el número no coincide, el script devuelve un error explícito. Este paso permite asegurar la transferencia de datos entre la aplicación Web y el modelo de Machine Learning.

Recuperación de argumentos 

values = list(
map(float, sys.argv[1:])
)

sys.argv contiene los argumentos enviados al programa Python. La expresión sys.argv[1:] ignora el primer elemento, que generalmente corresponde al nombre del script, y recupera los valores reales utilizados para la predicción. Cada valor se convierte en un float.

Gestión de errores de entrada 

try:

values = list(
    map(float, sys.argv[1:])
)

except:

print(
    "error: invalid input format"
)

sys.exit()

El bloque try intenta convertir los datos. Si un valor no es válido, se ejecuta el bloque except. El programa muestra entonces un mensaje indicando que el formato de entrada es incorrecto y detiene el proceso. Esta validación evita enviar datos incompatibles al modelo.

Número esperado de características 

expected_features =
model.n_features_in_

Esta propiedad determina automáticamente el número de variables esperadas por el modelo. Por lo tanto, el script no supone directamente un número fijo de variables: pregunta al modelo cuántas características se utilizaron durante su entrenamiento.

Validación de características 

if len(values) != expected_features:

print(
    f"error: expected {expected_features} features, got {len(values)}"
)

sys.exit()

El programa compara el número de valores recibidos con el número esperado de variables. Si los dos números son diferentes, se devuelve un error. Esta verificación protege el modelo frente a una estructura de entrada incorrecta.

04

Preparación de datos y predicción

Después de validar el número de variables, el script prepara los datos para el modelo de Machine Learning. Los valores se transforman en un array de NumPy utilizando np.array([values]). Este paso produce una estructura compatible con los modelos de Scikit-learn. La estructura creada representa una observación que contiene varias características. El modelo puede entonces recibir esta observación utilizando el método predict(). La instrucción model.predict(X) utiliza el modelo previamente cargado con Pickle y aplica los parámetros aprendidos durante su entrenamiento. El resultado generalmente se devuelve como un array de NumPy. Por ello, el código recupera el primer valor utilizando prediction[0]. La función float() convierte después el resultado en un número estándar de Python para que pueda mostrarse y transmitirse fácilmente a Node.js. Esta parte representa el paso esencial entre los datos numéricos recibidos por la aplicación y el resultado calculado por el modelo de Machine Learning.

Creación del array de NumPy 

X = np.array([
values
])

NumPy transforma la lista de valores en un array numérico. El uso de np.array([values]) representa una observación que contiene todas sus características en una estructura adecuada para los modelos de Scikit-learn.

Cálculo de la predicción 

prediction = model.predict(X)

El método predict() aplica el modelo de Machine Learning a los datos X. El modelo utiliza el conocimiento aprendido durante el entrenamiento para calcular el valor previsto.

Retorno del resultado 

print(
float(prediction[0])
)

El resultado devuelto por model.predict() generalmente se encuentra dentro de un array. El índice [0] recupera la primera predicción. La función float() convierte este valor en un número estándar de Python. Finalmente, print() escribe la predicción en stdout. Node.js recupera este valor mediante el proceso hijo.

Flujo de Python: Argumentos → Validación → NumPy → Modelo PKL → predict() → Resultado

Uso de Pandas y generación de JSON

Otra parte del sistema demuestra el uso de la biblioteca Pandas para manipular datos tabulares. Pandas se utiliza ampliamente en proyectos de Data Science y Machine Learning para cargar, limpiar, transformar y analizar datos. En este ejemplo, un diccionario de Python contiene dos columnas: x y y. Los valores son respectivamente 1, 2, 3 y 10, 20, 30. La función pd.DataFrame() transforma este diccionario en una tabla de datos. El DataFrame permite manipular información en filas y columnas. Después, el método to_dict(orient="records") convierte cada fila del DataFrame en un diccionario de Python. El resultado se convierte entonces en una lista de objetos que contienen las propiedades x e y. Esta estructura se coloca posteriormente en el objeto result. Finalmente, json.dumps() transforma el objeto Python en una cadena JSON. Este paso es importante en una arquitectura Web porque JSON es un formato que puede utilizarse fácilmente con JavaScript, Node.js y aplicaciones frontend. Pandas puede, por lo tanto, utilizarse en el proceso para preparar los datos antes de enviarlos a la aplicación Web.

Importación de Pandas 

import pandas as pd

Esta instrucción importa Pandas y le asigna el alias pd. Este alias es una convención muy común en proyectos Python que utilizan Pandas.

Creación de los datos 

data = {

"x": [1, 2, 3],

"y": [10, 20, 30]
}

El diccionario contiene dos series de datos. Cada clave representa una columna del futuro DataFrame.

Creación del DataFrame 

df = pd.DataFrame(
data
)

Pandas transforma el diccionario en un DataFrame. El resultado se presenta como una tabla que contiene dos columnas y tres filas.

Transformación en registros 

result = {

"rows":
    df.to_dict(
        orient="records"
    )
}

to_dict(orient="records") transforma las filas del DataFrame en una lista de diccionarios. Esta estructura resulta especialmente conveniente para enviar datos a una API o a un frontend.

Conversión a JSON 

print(
json.dumps(result)
)

json.dumps() transforma el objeto Python en una cadena JSON. JavaScript y Node.js pueden utilizar fácilmente esta estructura.

Servicio Node.js y comunicación con Python

El archivo de servicio etudeEtranger.js permite que Node.js se comunique con el programa Python. Esta comunicación se realiza utilizando el módulo nativo child_process. Node.js tiene la capacidad de ejecutar programas externos y aquí se utiliza spawn() para crear un proceso Python independiente. La función runPrediction(values) devuelve una Promise porque la ejecución de Python es asíncrona. La ruta del script Python se construye utilizando path.join(). Después, spawn("python", ...) ejecuta Python y le pasa la ruta del archivo junto con los valores recibidos. El método split(",") transforma una cadena como "10,20,30" en el array ["10", "20", "30"]. El operador ... permite entonces pasar cada valor como un argumento independiente al programa Python. Durante la ejecución, Node.js escucha stdout para recuperar la predicción devuelta por Python. También escucha stderr para recuperar posibles mensajes de error. Cuando Python termina, se activa el evento close. Node.js comprueba entonces el código de salida. Si el código es diferente de cero, la Promise es rechazada. De lo contrario, el resultado se limpia utilizando trim() y se devuelve mediante resolve(). Por lo tanto, esta función actúa como puente técnico entre la aplicación JavaScript y el modelo de Machine Learning desarrollado en Python.

Importación de los módulos 

const {
spawn
} = require(
"child_process"
);

const path =
require("path");

child_process proporciona la función spawn() utilizada para ejecutar Python. path proporciona las funciones necesarias para construir la ruta del script.

Creación de la función 

function runPrediction(
values
) {

return new Promise(
    (resolve, reject) => {

        ...

    }
);

}

La función recibe los valores como una cadena y devuelve una Promise. resolve() se utiliza cuando Python produce una respuesta correcta, mientras que reject() se utiliza en caso de error.

Ruta del script Python 

const pyFile =
path.join(
    __dirname,
    "../../python/predict.py"
);

Esta instrucción construye la ruta hacia el archivo Python. __dirname representa el directorio del archivo JavaScript actual y path.join() combina correctamente las diferentes partes de la ruta.

Ejecución de Python 

const py = spawn(
"python",
[
    pyFile,
    ...values.split(",")
]
);

spawn() inicia Python. El primer argumento especifica el programa que debe ejecutarse y el segundo argumento contiene la lista de parámetros. La ruta del script se pasa primero, seguida de cada valor como un argumento individual. Por ejemplo, la cadena "10,20,30" se convierte en tres argumentos Python: 10, 20 y 30.

Recuperación de stdout 

py.stdout.on(
"data",
(data) => {

    result +=
        data.toString();

}
);

Python utiliza print() para enviar la predicción a stdout. Node.js escucha esta salida y añade los datos recibidos a la variable result. Como stdout puede recibirse en varios fragmentos, el código utiliza += para reconstruir el resultado completo.

Recuperación de errores 

py.stderr.on(
"data",
(data) => {

    error +=
        data.toString();

}
);

Los mensajes de error de Python se recuperan a través de stderr. Esto permite al backend determinar la causa de un fallo en el proceso Python.

Finalización del proceso 

py.on(
"close",
(code) => {

    if (code !== 0)
        return reject(error);

    resolve(
        result.trim()
    );

}
);

Cuando Python termina su ejecución, se activa el evento close. El código de salida indica si el programa se completó correctamente. Un código diferente de cero indica un error. En este caso, la Promise es rechazada. De lo contrario, el resultado se limpia utilizando trim() y se devuelve mediante resolve().

Ruta del Dashboard en Express

El router de Express representa la capa API que permite al frontend o al dashboard solicitar múltiples predicciones. El archivo comienza importando Express y posteriormente crea un router utilizando express.Router(). A continuación, se importa el servicio etudeEtranger para poder llamar a la función runPrediction(). La ruta GET /dashboard representa el punto de entrada principal. Cuando una solicitud llega a esta ruta, el servidor define un array models que contiene varios modos: edufrance, edutest, linked y eduworld. Cada modo contiene una cadena de valores que se enviará al servicio Python. Un bucle for...of recorre cada elemento del array. Para cada modelo, el servidor llama a await runPrediction() para esperar a que finalice el proceso Python. La predicción devuelta como texto se convierte en un número mediante parseFloat(). Posteriormente, se añade un objeto que contiene el modo, los valores y la predicción al array results. Una vez completadas todas las predicciones, Express devuelve un objeto JSON que contiene la propiedad data. El frontend puede entonces recuperar todas las predicciones en una sola solicitud y mostrarlas en un dashboard mediante tarjetas, gráficos, indicadores o tablas.

Creación del Router 

const express =
require("express");

const router =
express.Router();

Express se importa y se crea un router independiente. Esto permite separar las rutas del resto de la aplicación backend.

Importación del servicio 

const runPrediction =
require(
    "../service/etudeEtranger"
);

El router importa la función responsable de ejecutar Python. Por lo tanto, la ruta puede activar el modelo de Machine Learning mediante esta función.

Ruta del Dashboard 

router.get(
"/dashboard",
async (req, res) => {

    ...

}
);

Esta ruta utiliza el método HTTP GET. Se declara como async porque debe esperar varias operaciones asíncronas relacionadas con la ejecución de Python.

Lista de modelos 

const models = [

{
    mode: "edufrance",
    values: "1,2,3,4"
},

{
    mode: "edutest",
    values: "2,3,4,5"
},

{
    mode: "linked",
    values: "1"
},

{
    mode: "eduworld",
    values: "10"
}
];

Este array centraliza los diferentes modos de predicción. Cada objeto contiene un nombre lógico utilizado para identificar el resultado y una cadena que contiene las variables que se enviarán a Python.

Procesamiento de cada predicción 

for (let m of models) {

const prediction =
    await runPrediction(
        m.values
    );

results.push({

    mode: m.mode,

    value: m.values,

    prediction:
        parseFloat(
            prediction
        )

});
}

El bucle procesa cada configuración una después de otra. await espera a que Python termine antes de pasar a la siguiente predicción. El resultado se convierte después en un número utilizando parseFloat() y se añade al array results junto con su modo y sus valores de entrada.

Respuesta JSON 

res.json({
data: results
});

Una vez completadas todas las predicciones, Express devuelve los resultados en formato JSON. El frontend puede utilizar directamente esta estructura para rellenar su dashboard.

Gestión de errores 

catch (err) {

res.status(500).json({

    error:
        err.toString()

});
}

El bloque catch captura los errores encontrados durante la ejecución. El servidor devuelve entonces el estado HTTP 500, que indica un error interno del servidor, junto con un mensaje que puede ayudar a diagnosticar el problema.

Arquitectura completa del sistema

La arquitectura general se basa en una separación clara entre Machine Learning y la aplicación Web. El proceso comienza en el nivel del dashboard o frontend. Este solicita la información necesaria mediante una petición HTTP a la API de Express. La ruta /dashboard recibe esta solicitud y prepara la lista de los diferentes modos de predicción. Para cada modo, Express llama a la función runPrediction() del servicio Node.js. Esta función utiliza child_process.spawn() para ejecutar el script Python. Las variables se pasan a Python como argumentos de línea de comandos. El script Python carga entonces eduworld.pkl utilizando Pickle. Las variables recibidas se convierten en números y el número de características se verifica utilizando model.n_features_in_. Los datos validados se transforman en un array de NumPy y posteriormente se envían al modelo mediante model.predict(). Python produce entonces el resultado utilizando print(). Node.js recupera este valor mediante stdout y lo devuelve a la ruta Express. Express convierte cada predicción en un número y construye el array final results. Finalmente, se envía al frontend una respuesta JSON que contiene todas las predicciones. El dashboard puede utilizar estos datos para mostrar diferentes indicadores de rendimiento, gráficos o estadísticas. Esta arquitectura permite mantener Python para la capa de Data Science y Machine Learning mientras Node.js y Express se utilizan para la capa Web y API.

La predicción se devuelve posteriormente a Node.js mediante stdout. Node.js recupera esta información y Express la envía al frontend en formato JSON. El dashboard puede presentar entonces los diferentes resultados mediante tarjetas, gráficos, indicadores o tablas. Esta separación de responsabilidades permite utilizar las herramientas especializadas de Python para Machine Learning mientras Node.js y Express se encargan de la comunicación Web. La arquitectura también puede ampliarse progresivamente con nuevos modelos, nuevas variables, nuevos destinos o nuevos indicadores sin modificar el principio general de comunicación entre el frontend, Node.js y Python.

Conclusión

Este sistema representa una integración completa de un modelo de Machine Learning dentro de una arquitectura Web. El modelo entrenado se guarda mediante Pickle en eduworld.pkl. El script Python vuelve a cargar este modelo, recupera las variables transmitidas por Node.js, valida su número, las transforma en un array de NumPy y produce una predicción utilizando predict(). Node.js gestiona posteriormente la comunicación entre la aplicación Web y Python utilizando el módulo child_process y la función spawn(). Express expone la ruta /dashboard, que permite ejecutar múltiples predicciones y agrupar sus resultados. Pandas también puede utilizarse para procesar y transformar datos tabulares antes de utilizarlos en el sistema.
