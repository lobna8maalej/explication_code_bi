🤖 Machine Learning Server Dashboard — Documentation technique

Cette documentation explique en détail le fonctionnement du composant ServerDashboard.jsx, sa liaison avec serverSlice.js, son fichier ServerDashboard.css, ainsi que l'utilisation de React, Redux Toolkit, useState, Power BI et du système de prédiction Machine Learning.

Le Dashboard permet à l'utilisateur de sélectionner un modèle de Machine Learning, de saisir deux variables numériques X1 et X2, puis de lancer une prédiction grâce à Redux.

Le résultat de la prédiction est ensuite affiché dans l'interface et ajouté à un historique des prédictions.

```
```

1. Présentation générale du projet

Le composant ServerDashboard.jsx représente l'interface principale d'un Dashboard consacré à la prédiction Machine Learning.

Il utilise React pour construire l'interface utilisateur et gérer les états locaux.

Il utilise également Redux Toolkit pour gérer les résultats de prédiction, l'état de chargement, les erreurs et l'historique.

Le Dashboard contient aussi un rapport Power BI intégré grâce à un élément iframe.

``` Utilisateur ↓ ServerDashboard.jsx ↓ Sélection du modèle ↓ Saisie de X1 et X2 ↓ Validation ↓ dispatch(fetchServerPrediction()) ↓ serverSlice.js ↓ Traitement de la prédiction ↓ Redux Store ↓ result / loading / error / history ↓ ServerDashboard.jsx ↓ Affichage du résultat ↓ Historique des prédictions ```
```
```

60. Résumé final à retenir

React construit l'interface → useState gère le modèle, X1 et X2 → l'utilisateur saisit les variables → handlePredict() valide les données → dispatch(fetchServerPrediction()) envoie la demande à Redux → serverSlice.js traite la prédiction → le Machine Learning produit une valeur → Redux met à jour result, loading, error et history → useSelector récupère ces informations → React réaffiche le composant → la valeur prédite est affichée → l'historique est mis à jour → Power BI affiche le Dashboard analytique → ServerDashboard.css contrôle la présentation finale.

Le composant ServerDashboard.jsx constitue donc l'interface utilisateur du système de prédiction Machine Learning.

Il permet à l'utilisateur de sélectionner un modèle, de saisir deux variables numériques et de lancer une prédiction.

Avant d'envoyer la demande, le composant vérifie que X1 et X2 sont renseignés et qu'ils peuvent être convertis en nombres.

La fonction dispatch() permet ensuite de transmettre la demande à fetchServerPrediction() provenant de serverSlice.js.

Redux gère alors les différents états de l'opération : result, loading, error et history.

Lorsque la prédiction réussit, le résultat est affiché dans une carte contenant le modèle utilisé, les valeurs X1 et X2 ainsi que la valeur prédite.

Chaque prédiction peut également être affichée dans l'historique grâce à history.map().

En parallèle, le rapport Power BI est intégré dans un iframe afin de présenter les analyses et indicateurs commerciaux.

Enfin, ServerDashboard.css assure la présentation visuelle de l'ensemble du Dashboard.
