💳 Transaction ML Dashboard — Technical Documentation

This documentation explains in detail how the TransactionDashboard.jsx component works, its connection with transactionSlice.js, its TransactionDashboard.css file, as well as the use of React, Redux Toolkit, Recharts, Power BI and the Machine Learning prediction system.

The Dashboard allows a Machine Learning prediction to be triggered for a transaction of type invoice. A value of 18175 TND is sent to Redux through the createTransaction() action.

The prediction result is then retrieved from Redux and displayed in a KPI card. The Dashboard also compares the predicted value with a fixed value corresponding to the Global Account (NCG).

At the same time, a Power BI report is integrated into the interface using an iframe element.

1. General overview of the project

The TransactionDashboard.jsx component represents the React interface of a Dashboard dedicated to the analysis and prediction of transaction data.

It uses React to build the user interface.

It also uses Redux Toolkit to trigger the creation of a transaction and retrieve the prediction data.

The component also uses the Recharts library to graphically represent the predicted value and the Global Account (NCG) value.

Finally, a Power BI report is integrated directly into the page using an iframe element.

59. Concrete example of how it works

When the component is loaded, it automatically sends: 

{ 
    mode: "facture", 
    value: 18175 
}

The request is sent to Redux using: 

dispatch( 
  createTransaction({ 
    mode: "facture", 
    value: 18175, 
  }) 
);

The system then processes this data and returns a prediction.

Suppose the system returns, for example: 

prediction = 25000

The component retrieves this value using: 

lastTransaction.prediction

and then displays it in the card: 

25000.00 TND

and also uses it in the chart.

60. Final summary to remember

React builds the interface → useEffect automatically triggers createTransaction() when the component loads → useDispatch sends the action to Redux → transactionSlice.js processes the transaction → the Machine Learning system produces a prediction → Redux updates items, loading and error → useSelector retrieves this information → lastTransaction retrieves the latest transaction → chartData prepares the chart data → the KPI card displays the value and prediction → Recharts represents the prediction and the Global Account NCG as a bar chart → Power BI displays the analytical report → TransactionDashboard.css handles the visual presentation.

The TransactionDashboard.jsx component therefore constitutes the user interface of the transaction prediction system.

Unlike a Dashboard that requires the user to manually enter several variables, this component automatically triggers a transaction when it is loaded using the useEffect Hook.

The transaction sent to Redux contains the mode "facture" and a value of 18175.

The dispatch() function sends this request to createTransaction(), provided by transactionSlice.js.

Redux then manages the state of the operation through items, loading and error.

When the data is available, the component retrieves the latest transaction using: 

items[items.length - 1]

This latest transaction provides the predicted value through: 

lastTransaction.prediction

The prediction is displayed in a KPI card and formatted with two decimal places using toFixed(2).

The data is then prepared in chartData so that it can be used by Recharts.

At the same time, the Power BI report is integrated using an iframe.

Finally, TransactionDashboard.css controls the visual appearance of the Dashboard.
