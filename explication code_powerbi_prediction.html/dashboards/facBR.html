Sistema de previsão Universidades Privadas

Integração de um modelo de Machine Learning desenvolvido com Python, Pandas, Scikit-learn e SVR em uma aplicação Web Node.js / Express destinada à análise de instituições privadas de ensino superior.

01

Visão geral do sistema

Este sistema implementa uma arquitetura de Machine Learning destinada à análise e previsão no contexto de universidades privadas. O objetivo é construir um modelo capaz de estudar uma relação entre a duração de um evento ou atividade universitária e um indicador de sucesso dos formandos. Neste exemplo, os dados utilizados contêm duas variáveis principais: graduate_success_rate, que representa a taxa de sucesso dos formandos, e event_duration, que representa a duração do evento. O modelo é desenvolvido com Python e a biblioteca Scikit-learn. O algoritmo utilizado é uma SVR, ou Support Vector Regression, configurada com um kernel linear. Depois de treinado, o modelo é salvo no arquivo EDUCATION_model.pkl utilizando Joblib. Essa operação permite reutilizar posteriormente o modelo sem precisar treiná-lo novamente. O backend Node.js utiliza então o módulo nativo child_process para executar um script Python. A função spawn() permite executar o script Python como um processo externo. O Node.js recupera posteriormente a saída padrão do programa Python por meio de stdout. O resultado produzido pelo Python é interpretado como JSON usando JSON.parse(). Finalmente, o Express disponibiliza uma rota GET /plot que permite ao frontend recuperar os dados preparados pelo Python. Em conjunto, isso constitui uma arquitetura na qual o Python é responsável pelo processamento de dados e pelo Machine Learning, enquanto Node.js e Express gerenciam a comunicação com a aplicação Web e o dashboard.

Treinamento do modelo de Machine Learning

O primeiro script Python é dedicado à criação e ao treinamento do modelo de previsão. O programa começa importando Pandas, SVR do Scikit-learn e Joblib. Pandas permite construir um DataFrame contendo os dados utilizados para o aprendizado. Neste exemplo, o DataFrame contém a taxa de sucesso dos formandos e a duração dos eventos. A variável X corresponde às características utilizadas como entrada do modelo. Aqui, o modelo utiliza event_duration. A variável y corresponde à variável-alvo, ou seja, graduate_success_rate. Em seguida, o modelo SVR é criado com SVR(kernel='linear'). A escolha do kernel linear significa que o modelo busca uma relação linear entre a variável de entrada e a variável que se deseja prever. O método fit(X, y) treina o modelo com base nos dados disponíveis. Depois do treinamento, o modelo é salvo em EDUCATION_model.pkl usando joblib.dump(). O arquivo obtido poderá posteriormente ser utilizado por outro script Python para realizar previsões sem precisar treinar novamente o modelo.

Importação das bibliotecas 

import pandas as pd

from sklearn.svm import SVR

import joblib

Pandas é utilizado para criar e manipular os dados em formato de DataFrame. SVR fornece o algoritmo de regressão Support Vector Regression. Joblib permite salvar o objeto do modelo treinado em um arquivo para que ele possa ser reutilizado posteriormente.

Criação dos dados 

data = {

    'graduate_success_rate': [85, 85, 90],

    'event_duration': [2, 2, 2]

}

O dicionário data contém as informações utilizadas para o aprendizado. A coluna graduate_success_rate representa a taxa de sucesso dos formandos, enquanto event_duration representa a duração do evento. Em um projeto real, esses dados poderiam vir de um banco de dados, arquivo CSV, API ou sistema de coleta de dados.

Criação do DataFrame 

df = pd.DataFrame(data)

A função pd.DataFrame() transforma o dicionário Python em uma tabela Pandas. O DataFrame facilita posteriormente a seleção das colunas utilizadas para treinar o modelo.

Separação das variáveis 

X = df[['event_duration']]

y = df['graduate_success_rate']

A variável X contém a característica de entrada do modelo. Neste exemplo, trata-se da duração do evento. A variável y contém o valor que o modelo deve aprender a prever: a taxa de sucesso dos formandos. Essa separação corresponde ao princípio clássico do aprendizado supervisionado.

03

Algoritmo SVR

O algoritmo escolhido neste projeto é o SVR, ou Support Vector Regression. Trata-se de um método de Machine Learning utilizado para resolver problemas de regressão, ou seja, quando o objetivo é prever um valor numérico. Diferentemente de uma simples regressão linear clássica, o SVR é baseado no princípio das Support Vector Machines e busca construir uma função que respeite uma determinada margem ao redor das observações. No código, o modelo é criado utilizando SVR(kernel='linear'). O parâmetro kernel='linear' indica que o modelo utiliza uma relação linear entre as variáveis. O método fit(X, y) permite então que o modelo aprenda a relação entre a duração do evento e a taxa de sucesso. A escolha do SVR pode ser interessante quando se deseja implementar uma abordagem de regressão capaz de generalizar a partir das observações disponíveis. Em um projeto real, o modelo naturalmente deveria ser treinado com um volume de dados suficientemente grande e avaliado utilizando métricas adequadas antes de ser utilizado em um sistema de apoio à tomada de decisão.

Criação do modelo 

model = SVR(kernel='linear')

Essa instrução cria um modelo SVR com um kernel linear. Nesta etapa, o modelo ainda não foi treinado: ele precisa ser treinado com os dados disponíveis.

Treinamento 

model.fit(X, y)

O método fit() inicia o processo de aprendizado. X contém as variáveis explicativas e y contém a variável-alvo. O modelo analisa as relações presentes nos dados para posteriormente produzir previsões sobre novas observações.

Princípio: Dados universitários → X = duração do evento → y = taxa de sucesso → SVR → Aprendizado → Modelo treinado
04

Salvamento do modelo com Joblib

Depois do treinamento, não é necessário manter todos os dados de treinamento no backend Web. O modelo treinado pode ser salvo como um arquivo. Neste projeto, a biblioteca Joblib é utilizada para realizar esse salvamento. A instrução joblib.dump(model, 'EDUCATION_model.pkl') salva o objeto do modelo em um arquivo chamado EDUCATION_model.pkl. Esse arquivo representa o modelo de Machine Learning treinado. Posteriormente, ele pode ser carregado por outro script Python para produzir previsões. Essa separação entre o treinamento e a utilização do modelo é importante em uma arquitetura profissional. O treinamento pode ser realizado periodicamente, enquanto a aplicação Web pode simplesmente utilizar a última versão validada do modelo. 

joblib.dump(
    model,
    'EDUCATION_model.pkl'
)

joblib.dump() recebe aqui dois parâmetros: o primeiro corresponde ao objeto do modelo treinado e o segundo corresponde ao nome do arquivo de salvamento. O arquivo PKL poderá posteriormente ser carregado com Joblib em um script de previsão.

Resultado: Modelo SVR treinado → Joblib → EDUCATION_model.pkl → Reutilização do modelo

Preparação dos dados com Pandas e JSON

No sistema completo, o Python também pode preparar dados destinados a serem exibidos em um gráfico ou dashboard. Pandas é especialmente adequado para essa tarefa porque permite manipular facilmente dados em formato de linhas e colunas. Depois de criar um DataFrame, o método to_dict(orient="records") permite transformar as linhas em uma lista de dicionários Python. Essa estrutura é posteriormente colocada em um objeto result. A biblioteca json permite finalmente converter esse objeto Python em uma string JSON utilizando json.dumps(). JSON é um formato de intercâmbio especialmente adequado entre Python e Node.js. O Node.js pode assim receber uma estrutura facilmente interpretável pelo JavaScript. O frontend pode posteriormente utilizar as informações recebidas para construir gráficos que representem, por exemplo, a relação entre a duração de um evento e a taxa de sucesso.

Criação do DataFrame 

data = {

    "x": [1, 2, 3],

    "y": [10, 20, 30]

}

df = pd.DataFrame(data)

O dicionário contém duas séries de valores. O Pandas as transforma em duas colunas dentro do DataFrame. Essa estrutura facilita a preparação dos dados antes de enviá-los ao Node.js.

Conversão em records 

result = {

    "rows":
        df.to_dict(
            orient="records"
        )

}

A opção orient="records" solicita ao Pandas que represente cada linha como um dicionário. O resultado pode assumir a forma de uma lista de objetos JavaScript depois da conversão para JSON.

Geração do JSON 

print(
    json.dumps(result)
)

json.dumps() transforma o objeto Python em uma string JSON. A instrução print() envia posteriormente essa string para stdout, onde o Node.js poderá recuperá-la.

06

Serviço Node.js e comunicação com Python

O arquivo fac.js desempenha o papel de gateway entre o backend Node.js e os scripts Python. Ele utiliza o módulo nativo child_process do Node.js e, especificamente, a função spawn(). Essa função permite iniciar um processo externo, neste caso o programa Python. A função runPython(scriptName) recebe o nome do script Python que deve ser executado e constrói automaticamente seu caminho utilizando path.join(). O processo Python é iniciado posteriormente com spawn("python", [scriptPath]). Durante a execução, o Node.js escuta o stdout para recuperar os dados produzidos pelo Python e o stderr para recuperar possíveis erros. Quando o Python termina, o evento close é acionado. O Node.js verifica então o código de saída. Se esse código for diferente de zero, a Promise será rejeitada com a mensagem de erro. Se a execução for bem-sucedida, o Node.js tenta transformar a saída Python em um objeto JavaScript utilizando JSON.parse(). Essa etapa é essencial quando o Python retorna dados estruturados em JSON. Dessa forma, o serviço torna-se uma interface entre o mundo Python, especializado em Data Science, e o backend Node.js, especializado em comunicação Web.

Importação dos módulos 

const { spawn } =
require("child_process");

const path =
require("path");

child_process permite executar Python a partir do Node.js. O módulo path permite construir um caminho de arquivo confiável.

Função runPython() 

function runPython(scriptName) {

    return new Promise(
        (resolve, reject) => {

            ...

        }
    );

}

A função retorna uma Promise porque a execução do processo Python é assíncrona. A Promise será resolvida quando o script terminar corretamente ou rejeitada em caso de erro.

Construção do caminho Python 

const scriptPath = path.join(
    __dirname,
    "..",
    "..",
    "python",
    scriptName
);

__dirname representa a pasta do arquivo JavaScript atual. Os diferentes elementos são posteriormente combinados por path.join() para localizar o script Python.

Execução do Python 

const py = spawn(
    "python",
    [scriptPath]
);

O Node.js inicia o programa Python e fornece o caminho do script. Essa técnica permite utilizar diretamente o ambiente Python a partir do backend JavaScript.

Recuperação do stdout 

py.stdout.on("data", (data) => {

    output += data.toString();

});

O Python escreve seu resultado utilizando print(). O Node.js recupera esse resultado por meio do stdout. O método toString() transforma os dados recebidos em texto e o operador += permite reconstruir a saída completa.

Gerenciamento do stderr 

py.stderr.on("data", (data) => {

    error += data.toString();

});

As mensagens de erro geradas pelo Python são recuperadas por meio do stderr. Isso permite que o Node.js identifique possíveis problemas encontrados durante a execução.

Conversão JSON 

try {

    resolve(
        JSON.parse(output)
    );

} catch (e) {

    reject(output);

}

Quando o Python retorna uma string JSON, JSON.parse() a transforma em um objeto JavaScript. O Node.js pode então manipular diretamente os dados e enviá-los ao Express. Se a saída não for um JSON válido, o bloco catch captura o erro e rejeita a Promise com a saída recebida.

Rota Express do sistema

O router Express constitui a camada de API que permite ao frontend acessar os dados produzidos pelo Python. O arquivo começa importando o Express e posteriormente cria um router utilizando express.Router(). O serviço fac.js é importado para utilizar a função runPython(). A rota GET /plot constitui o ponto de entrada que permite recuperar os dados destinados à visualização. Quando essa rota recebe uma solicitação, ela chama await runPython("plot.py"). O serviço Node.js inicia então o script Python plot.py. O Python prepara os dados, gera eventualmente as estruturas necessárias para o gráfico e as retorna em formato JSON. O Node.js recebe o resultado e o Express o coloca na propriedade data. Finalmente, o servidor retorna uma resposta JSON contendo uma mensagem de confirmação e os dados. O frontend pode então recuperar essa resposta e utilizar os valores para construir um gráfico ou alimentar um dashboard dedicado às universidades privadas.

Criação do router 

const express =
require("express");

const router =
express.Router();

O Express é importado e posteriormente um router independente é criado. Essa organização permite separar as rotas relacionadas às universidades privadas das demais rotas da aplicação.

Importação do serviço 

const { runPython } =
require("../service/fac");

O router recupera a função runPython() do serviço Node.js. Dessa forma, ele pode iniciar o script Python quando uma solicitação chega.

Rota GET /plot 

router.get(
    "/plot",
    async (req, res) => {

        ...

    }
);

A rota utiliza o método HTTP GET. A palavra-chave async permite utilizar await para aguardar a conclusão da execução do Python.

Chamada do script Python 

const result =
    await runPython(
        "plot.py"
    );

O Express solicita ao serviço Node.js que execute especificamente o arquivo plot.py. O resultado JSON produzido pelo Python é armazenado na variável result.

Resposta da API 

res.json({

    message: "OK",

    data: result

});

O Express retorna uma resposta JSON contendo uma mensagem de confirmação e os dados produzidos pelo Python. O frontend pode então utilizar diretamente a propriedade data.

Gerenciamento de erros 

catch (err) {

    res.status(500).json({

        error:
            err.toString()

    });

}

O bloco catch permite gerenciar erros provenientes do serviço Python ou da execução do processo. O servidor retorna então o status HTTP 500 para indicar um erro interno.

Exemplo concreto de funcionamento

Para compreender o funcionamento completo, podemos imaginar que o frontend deseja recuperar os dados necessários para exibir um gráfico sobre universidades privadas. O frontend envia uma solicitação HTTP GET /plot para a API Express. A rota recebe a solicitação e chama runPython("plot.py"). O serviço Node.js constrói automaticamente o caminho do arquivo Python e executa o processo utilizando spawn(). O script Python então prepara os dados com Pandas. Se os dados precisarem ser transformados em uma estrutura que possa ser utilizada pelo JavaScript, o Pandas utiliza to_dict(orient="records"). O objeto obtido é posteriormente transformado em uma string JSON por meio de json.dumps(). O Python utiliza print() para enviar essa string para stdout. O Node.js recupera a saída por meio de py.stdout.on("data", ...). Quando o processo Python termina sua execução, o Node.js verifica o código de saída. Se tudo tiver sido executado corretamente, a string JSON é convertida em um objeto JavaScript utilizando JSON.parse(). O Express coloca então esse objeto na propriedade data da resposta. O frontend recebe os dados e pode utilizá-los para construir um gráfico que represente os resultados do sistema de previsão ou os dados relacionados às universidades privadas.
