📊 Explanation of the InfoDashboard.jsx component, the infoSlice.js file and their connection with CSS

This documentation explains how the GOMYCODE AI Dashboard works and the communication between React, Redux Toolkit, Axios, the backend, Machine Learning, Power BI, Recharts and the associated CSS file.

1. General overview

The InfoDashboard.jsx component is the React interface of the Dashboard dedicated to the analysis and prediction of GOMYCODE data. It uses several complementary technologies to retrieve a prediction from the backend, manage its state with Redux Toolkit, display an integrated Power BI report and represent the prediction as a chart using Recharts.

The infoSlice.js file is the Redux Toolkit part responsible for retrieving and managing the prediction data.

Finally, the InfoDashboard.css file is responsible for the visual presentation of the InfoDashboard.jsx component.

2. Imports in InfoDashboard.jsx

The InfoDashboard.jsx file starts by importing React and the useEffect hook. The useEffect hook allows an operation to be automatically executed after the component loads.

The component also imports useDispatch and useSelector from react-redux. useDispatch allows a Redux action to be dispatched, while useSelector allows the component to retrieve data stored in the Redux store.

The component then imports fetchInfoData from ../redux/infoSlice. This asynchronous function is responsible for sending the request to the backend in order to obtain the prediction.

Several components from the Recharts library are also imported: BarChart, Bar, XAxis, YAxis, Tooltip, CartesianGrid and ResponsiveContainer.

Important point:

The React file also contains: 

import "./InfoDashboard.css";

This instruction is placed in InfoDashboard.jsx, not in the HTML documentation file.

3. How is InfoDashboard.jsx connected to InfoDashboard.css?

The connection between React and CSS is made in two main ways.

First connection: CSS import

Second connection: className

4. The InfoDashboard function

The InfoDashboard function represents the main React component.

At the beginning of the component, const dispatch = useDispatch() retrieves the dispatch function from Redux.

This function allows the component to dispatch the fetchInfoData() action to the Redux store.

Then, useSelector is used with (state) => state.info to retrieve the three main pieces of information:

  • data: contains the prediction result.
  • loading: indicates whether the request is in progress.
  • error: contains a possible error.

5. The role of useEffect

The useEffect hook plays an important role in the Dashboard workflow. 

useEffect(() => {
    dispatch(fetchInfoData());
}, [dispatch]);

When the user opens the GOMYCODE AI Dashboard page, React loads the component and then executes useEffect.

It triggers: 

dispatch(fetchInfoData());

Redux then receives the action and starts the asynchronous function defined in infoSlice.js.

6. Preparing chartData

The chartData constant prepares the data required by Recharts. 

const chartData = data
    ? [
        {
            name: "GOMYCODE",
            prediction: data.gomycode_pred
        }
    ]
    : [];

If data exists, an array containing one object is created.

The object contains:

  • name with the value "GOMYCODE"
  • prediction with the value data.gomycode_pred

If the data is not yet available, an empty array is returned: 

[]

This precaution prevents the application from using unavailable data during the first render.

10. Managing the loading state

While the request is in progress, the component uses: 

{loading && (
    <p className="loading">
        Loading prediction...
    </p>

If loading is true, the message is displayed.

If error contains a value, React displays the paragraph.

The error class can be styled with:

16. The infoSlice.js file

The infoSlice.js file is the Redux Toolkit part responsible for retrieving and managing the prediction data.

It imports in particular:

  • createSlice
  • createAsyncThunk
  • axios

The fetchInfoData function is created using createAsyncThunk. 

createAsyncThunk(
    "info/fetchInfoData",
    async (_, thunkAPI) => {
        ...
    }
)

This function represents the asynchronous operation used to communicate with the backend.

17. Axios request

Axios uses axios.post() to send an HTTP POST request to: 

http://localhost:3000/info/predict

The request body contains: 

{
    values: [1000, 2500]
}

These values represent the input data sent to the prediction system.

18. Handling the response

After executing the Axios request, the code: 

return res.data.data;

retrieves the useful data from the HTTP response.

This value then becomes the result of the asynchronous Redux action.

19. Error handling with try/catch

The function uses a try/catch block to handle the success or failure of the request. 

try {
    ...
} catch (err) {
    ...
}

In case of an error, the code uses: 

thunkAPI.rejectWithValue(
    err.response?.data || err.message
)

The ?. operator allows response.data to be accessed only if response exists.

If no server response is available, err.message is used.

20. initialState

The slice has an initial state: 

initialState: {
    data: null,
    loading: false,
    error: null
}

Initially:

  • data contains no prediction.
  • loading indicates that no request is in progress.
  • error contains no error.

21. fetchInfoData.pending

When the request starts, Redux triggers: 

fetchInfoData.pending

The state is then modified: 

state.loading = true;
state.error = null;

React then retrieves this new value using useSelector.

22. fetchInfoData.fulfilled

When the request succeeds, Redux triggers: 

fetchInfoData.fulfilled

The code then sets: 

state.loading = false;
state.data = action.payload;

The prediction is therefore stored in state.info.data.

Through useSelector, the React component automatically retrieves the new data and updates its interface.

23. fetchInfoData.rejected

If the request fails, Redux triggers: 

fetchInfoData.rejected

The state becomes: 

state.loading = false;
state.error = action.payload;

React then retrieves error and displays the corresponding message using the CSS class error.

24. Connection between Redux, React and CSS

It is important to understand that Redux does not communicate directly with CSS.

Redux provides data and states to React. React then decides which elements should be displayed. The className attributes finally connect these elements to the CSS file.

27. Complete project flow

When the user opens the Dashboard, React loads InfoDashboard.jsx.

The useEffect is then executed and triggers: 

dispatch(fetchInfoData());

Redux Toolkit enters the pending state and sets loading to true.

Axios then sends the values: 

[1000, 2500]

to: 

POST /info/predict

The backend receives these values and uses the Machine Learning model to calculate the prediction.

The result then returns to Redux.

If the request succeeds, Redux enters the fulfilled state and stores the result in: 

state.info.data

useSelector then retrieves the new data. React automatically updates the interface.

The value data.gomycode_pred is displayed in the prediction card and used to build chartData.

Recharts then uses chartData to create the chart.

At the same time, the iframe displays the Power BI report.

Finally, InfoDashboard.css applies the styles to the different elements through their className attributes.

29. Summary to remember for the presentation

React builds → Redux manages → Axios communicates → Backend predicts → Recharts visualizes → Power BI analyzes → CSS presents.

The InfoDashboard.jsx component builds the interface and retrieves information from Redux. The infoSlice.js file manages the asynchronous request and the data, loading and error states.

Axios handles communication with the backend, which uses the Machine Learning system to produce the prediction.

Recharts then transforms the prediction into a graphical representation, while Power BI provides the integrated business intelligence report.

Finally, InfoDashboard.css does not perform the prediction or retrieve the data. Its role is to control the appearance of the elements created by React.

The connection between React and CSS is achieved through import "./InfoDashboard.css"; in the JSX file and through the className attributes that correspond to the CSS selectors.
