✈️ Voyage ML Dashboard — Documentation technique

Cette documentation explique en détail le fonctionnement du composant VoyageDashboard.jsx, du fichier voyageSlice.js, de la communication avec le backend grâce à Axios, de la gestion d'état avec Redux Toolkit, de la visualisation avec Recharts, ainsi que l'intégration de Power BI et du système de Machine Learning.

Introduction

Le Dashboard Voyage permet de transmettre automatiquement des données concernant les prix d'un voyage vers le backend.

Les données envoyées au backend sont :

  • prix_concurrent_2 = 1900
  • prix_concurrent_agence2 = 2000
  • prix_extra = 50

La requête est envoyée avec la méthode HTTP POST vers : 

http://localhost:3000/voyage

Le backend traite ensuite les données et retourne une réponse JSON contenant notamment une prédiction.

Cette réponse est récupérée par Redux Toolkit et stockée dans l'état du module voyage.

La valeur de la prédiction est ensuite utilisée pour construire un graphique en barres avec Recharts.

En parallèle, un rapport Power BI est intégré directement dans le Dashboard grâce à une iframe.

1. Présentation générale du projet

Le composant VoyageDashboard.jsx représente l'interface React du Dashboard consacré à l'analyse et à la prédiction des données de voyage.

Son objectif est d'envoyer automatiquement plusieurs variables concernant les prix d'un voyage vers le backend.

Le backend traite ensuite ces données selon la logique définie dans le système de Machine Learning.

Le résultat retourné par le backend est récupéré par Redux Toolkit.

Le Dashboard affiche ensuite la prédiction ainsi qu'un graphique permettant de comparer une valeur réelle avec la valeur prédite.

67. Pourquoi utiliser Redux Toolkit ?

Redux Toolkit permet de centraliser l'état du module Voyage.

Au lieu de conserver la réponse uniquement dans un état local du composant, elle est stockée dans le Redux Store.

``` 
Backend
   ↓
Redux Toolkit
   ↓
Redux Store
   ↓
state.voyage
   ↓
VoyageDashboard
```

Le composant peut ainsi récupérer : 

items
```

loading
error
```

État loading items error
Avant la requête false null null
pending true éventuellement ancienne valeur null
fulfilled false réponse backend null

Le frontend React ne réalise pas directement le calcul de Machine Learning.

Son rôle consiste à transmettre les données nécessaires au backend.

Le backend reçoit notamment :

72. Rôle de Power BI et du Machine Learning

Élément Fonction

Machine Learning Produit une prédiction à partir des variables envoyées au backend.

Recharts Compare visuellement la valeur réelle et la prédiction.
