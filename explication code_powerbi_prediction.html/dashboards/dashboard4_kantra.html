Prédiction

De la Business Intelligence vers l'analyse prédictive

La Business Intelligence permet principalement d'analyser les données existantes.

La prédiction va plus loin en utilisant les données historiques pour estimer une valeur future ou inconnue.

Analyse descriptive → Analyse prédictive
SCIKIT-LEARN

Régression linéaire

🤖

Le modèle utilisé dans le projet est une régression linéaire.

Elle permet de modéliser une relation entre une ou plusieurs variables d'entrée et une variable cible.

Python 
from sklearn.linear_model import LinearRegression
```

model = LinearRegression()
```
```

APPRENTISSAGE

Entraînement du modèle

📚 Données d'entraînement

Le modèle est entraîné à partir de données historiques.

Python 
X = np.array([
[1, 10],
[2, 20],
[3, 30],
[4, 40]
```

])

y = np.array([15, 25, 35, 45])
```

X représente les variables d'entrée et y représente la variable cible.

⚙️ Entraînement

L'apprentissage est réalisé avec :

Python 
model.fit(X, y)

Le modèle apprend la relation entre les variables d'entrée et la variable cible.
