Python Section — Machine Learning Model Loading

The Python file represents the Machine Learning part of the module. It is responsible for loading the diwan.pkl model and preparing the result that will be sent to Node.js.

Python Code

📄 radio.py 
import os
import pickle
import json

# 📁 Secure path to the model
BASE_DIR = os.path.dirname(__file__)
MODEL_PATH = os.path.join(BASE_DIR, "diwan.pkl")

# 🤖 Load the model
try:
    with open(MODEL_PATH, "rb") as f:
        model = pickle.load(f)

except Exception as e:
    print("Model loading error:", str(e))
    model = None

# 📊 Result
result = {
    "status": "success" if model else "error",

    "prediction": 123.4,

    "rows": [
        {
            "reputation_ranking": 80,
            "tuition_fee": 5000,
            "Target": 1
        }
    ],

    "columns": [
        "reputation_ranking",
        "tuition_fee",
        "Target"
    ],

    "images": []
}

# 📤 Display JSON
print(json.dumps(result))

Library Imports

The program begins by importing three libraries: os, pickle, and json.

  • os: allows the program to manage paths and files.
  • pickle: allows the saved Machine Learning model to be loaded from the .pkl file.
  • json: allows Python results to be converted into JSON format so that Node.js can retrieve them.

Building the Model Path

BASE_DIR = os.path.dirname(__file__)

MODEL_PATH = os.path.join(
    BASE_DIR,
    "diwan.pkl"
)

BASE_DIR retrieves the directory in which the Python file is located.

Then, os.path.join() builds the path to the diwan.pkl file.

This method is more secure than manually writing a path because it allows the program to correctly locate the model.

Loading the Model

with open(MODEL_PATH, "rb") as f:
    model = pickle.load(f)

The diwan.pkl file is opened in rb mode, meaning read binary.

The pickle.load() function then retrieves the Machine Learning object saved in the file.

The model is stored in the following variable:

model

Error Handling

except Exception as e:
    print("Model loading error:", str(e))
    model = None

The try / except block is used to handle errors that may occur while loading the model.

For example, if diwan.pkl does not exist, the program does not stop unexpectedly. The model is assigned the value None.

Model Status

"status": "success" if model else "error"

This instruction checks whether the model has been loaded successfully.

If the model exists, the status is:

success

Otherwise, the status becomes:

error

Important: Prediction Currently Simulated

Important:

In the provided code, the value: 

"prediction": 123.4

is a simulated value.

It is not yet calculated directly using model.predict().

In a real predictive application, this part could be replaced with an instruction such as: 

prediction = model.predict(X_test)

using input data corresponding to the variables used during model training.

The `rows` Data

"rows": [
    {
        "reputation_ranking": 80,
        "tuition_fee": 5000,
        "Target": 1
    }
]

The rows property contains the data that will later be retrieved by Node.js.

Each object represents one row of data.

  • reputation_ranking: ranking or reputation value.
  • tuition_fee: numerical value associated with tuition fees.
  • Target: target variable of the model or result associated with the data.

JSON Conversion

print(json.dumps(result))

This instruction converts the Python object into JSON.

This is an essential step because Node.js will retrieve this output and use it within the application.

Node.js Service — Communication with Python

The radioservice.js file acts as the bridge between Node.js and Python.

Its role is to launch the Python program, retrieve its JSON output, detect errors, and convert the Python JSON into a JavaScript object.

Node.js Code

📄 radioservice.js 
const { spawn } = require("child_process");
const path = require("path");

function runPythonPlots() {

    return new Promise((resolve, reject) => {

        console.log("RADIOSERVICE LOADED");

        const py = spawn("python", [
            path.join(
                __dirname,
                "../../python/radio.py"
            )
        ]);

        let output = "";
        let error = "";

        py.stdout.on("data", (data) => {
            output += data.toString();
        });

        py.stderr.on("data", (data) => {
            error += data.toString();
        });

        py.on("close", (code) => {

            if (code !== 0) {
                return reject(
                    error || "Python error"
                );
            }

            try {

                const cleanOutput =
                    output.toString().trim();

                resolve(
                    JSON.parse(cleanOutput)
                );

            } catch (e) {

                console.log(
                    "RAW OUTPUT:",
                    output
                );

                reject(
                    "Invalid JSON from Python"
                );
            }
        });

    });
}

module.exports = {
    runPythonPlots
};

Importing `child_process`

const { spawn } = require("child_process");

The child_process module is provided by Node.js.

It allows Node.js to launch external programs.

Using `spawn()`

    path.join(
        __dirname,
        "../../python/radio.py"
    )
]);

This instruction asks Node.js to execute the Python program and the radio.py file.

Express Route `/radio`

The route is responsible for coordinating the entire process: MySQL connection, Python execution, data validation, insertion into MySQL, and the final response.

📄 radioRoute.js 
const express = require("express");
const router = express.Router();

const {
    runPythonPlots
} = require("../service/radioservice");

const {
    getConnection
} = require("../DBMysql/radiodb");

router.get("/", async (req, res) => {

    let connection;

    try {

        connection = await getConnection();

        const result =
            await runPythonPlots();

        if (
            !result ||
            !result.rows ||
            !Array.isArray(result.rows)
        ) {

            return res.status(400).json({
                error: "Invalid Python output"
            });
        }

        for (const row of result.rows) {

            await connection.execute(
                `INSERT INTO plot_data
                (reputation_ranking,
                tuition_fee,
                Target)
                VALUES (?, ?, ?)`,
                [
                    row.reputation_ranking ?? 0,
                    row.tuition_fee ?? 0,
                    row.Target ?? 0
                ]
            );
        }

        res.json({

            message:
                "Plots processed successfully",

            count:
                result.rows.length,

            columns:
                result.columns || [],

            images:
                result.images || []
        });

    } catch (err) {

        console.error(
            "ERROR:",
            err
        );

        res.status(500).json({
            error: err.toString()
        });

    } finally {

        if (connection) {
            await connection.end();
        }
    }
});

module.exports = router;

const router = express.Router();

        tuition_fee,
        Target)
        VALUES (?, ?, ?)`,

            row.Target ?? 0
        ]
    );
}

Each row received from Python is inserted into the plot_data table.

The three columns used are:

Column Python Value
reputation_ranking row.reputation_ranking
tuition_fee row.tuition_fee
Target row.Target

`??` Operator

If the value of Target is null or undefined, the backend automatically uses the value 0.

Explanation to Give During a Sales Presentation

During a commercial presentation, it is not necessary to read every line of code. The main objective is to explain the overall operation and the value provided by this architecture.

🎤 Example Explanation

“In this part of the project, I integrated a Machine Learning model developed in Python into a Web application based on Node.js and Express.

The model is saved in a diwan.pkl file. When the application requests the results, Express receives the request and calls a dedicated Node.js service.

This service uses child_process.spawn() to launch Python and execute the Machine Learning script. Python then loads the model using pickle.

The result produced by Python is converted into JSON. Node.js retrieves this JSON, converts it into a JavaScript object, and verifies that the received data is valid.

The validated data is then stored in MySQL, in the plot_data table.

Finally, Express returns a JSON response to the frontend. The dashboard can then use this information to display tables, indicators, or charts.

The advantage of this architecture is that each technology has a specific role: Python handles Machine Learning, Node.js and Express handle the API and communication, MySQL provides data storage, and the frontend handles visualization.

This separation makes the system more organized, maintainable, and scalable.”
