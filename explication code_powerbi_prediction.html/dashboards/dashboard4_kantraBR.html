MACHINE LEARNING

Predição

De Business Intelligence à análise preditiva

Business Intelligence permite principalmente analisar os dados existentes.

A predição vai além, utilizando os dados históricos para estimar um valor futuro ou desconhecido.

Análise descritiva → Análise preditiva
SCIKIT-LEARN

Regressão linear

🤖

O modelo utilizado no projeto é a regressão linear.

Ele permite modelar uma relação entre uma ou várias variáveis de entrada e uma variável-alvo.

Python 
from sklearn.linear_model import LinearRegression  
  
model = LinearRegression()
10

TREINAMENTO

Treinamento do modelo

📚 Dados de treinamento

O modelo é treinado utilizando dados históricos.

Python 
X = np.array([  
[1, 10],  
[2, 20],  
[3, 30],  
[4, 40]  
])  
  
y = np.array([15, 25, 35, 45])

X representa as variáveis de entrada e y representa a variável-alvo.

⚙️ Treinamento

O treinamento é realizado utilizando:

Python 
model.fit(X, y)

O modelo aprende a relação entre as variáveis de entrada e a variável-alvo.

11

SERIALIZAÇÃO DO MODELO

Salvamento do modelo

Após o treinamento, o modelo é salvo em um arquivo chamado MENTION.pkl.

Python 
with open("MENTION.pkl", "wb") as f:  
pickle.dump(model, f)
Dados históricos → Treinamento → MENTION.pkl → Novos dados → Predição

with open("python/MENTION.pkl", "rb") as f:

VALIDAÇÃO

Validação e preparação dos dados

✓ Validação

Antes de realizar a predição, o programa verifica se as variáveis necessárias estão presentes. 

if "a" not in data or "b" not in data:

    "message": "Fields a and b are required"

🔢 Preparação

Os valores são convertidos em números e posteriormente preparados em um array do NumPy. 

a = float(data["a"])

Comunicação com Python

Node.js 
const { spawn } = require("child_process");  
  
const py = spawn("python", [scriptPath]);

O módulo child_process permite ao Node.js executar o script Python.

16

COMUNICAÇÃO

Envio e recuperação de dados

📤 Node.js → Python

py.stdin.write(JSON.stringify(data));  
  
py.stdin.end();

Os dados JavaScript são convertidos para JSON e posteriormente enviados ao programa Python.

📥 Python → Node.js

py.stdout.on("data", (data) => {  
output += data.toString();  
  
});

O Node.js recupera posteriormente a saída gerada pelo Python.

17

REST API

Rota Express /kantra

Uma rota POST permite que o frontend envie os dados necessários para realizar a predição.

POST /kantra
kantraRoute.js 
router.post("/", async (req, res) => {  
try {  
  
    const result =  
        await runPython("kantra.py", req.body);  
  
    res.json(result);  
  
} catch (err) {  
  
    res.status(500).json({  
        success: false,  
        error: err?.error ||  
               err?.message ||  
               err  
    });  
  
}  
});
