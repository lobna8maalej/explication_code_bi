Execução da previsão com Python

O arquivo voyage.py é o programa Python responsável por executar a previsão.

Ele recebe os dados enviados pelo Node.js, carrega o modelo de Machine Learning salvo em voyagito.pkl, prepara as variáveis e executa a previsão.

voyage.py — Carregamento do modelo 
BASE_DIR = os.path.dirname(__file__) 
model_path = os.path.join( 
BASE_DIR, 
"voyagito.pkl" 
) 
 
with open(model_path, "rb") as f: 
model = pickle.load(f)

📁 BASE_DIR

Permite obter o caminho da pasta onde está localizado o script Python.

💾 voyagito.pkl

Contém o modelo de Machine Learning já treinado e salvo.

🐍 pickle

Permite carregar o modelo salvo para utilizá-lo em uma nova previsão.

API REST

Rota Express de previsão

Uma rota Express recebe os dados enviados pelo frontend e inicia o processo de previsão em Python.

POST /voyage
voyageRoute.js 
router.post("/", async (req, res) => { 
 
try { 
 
    if ( 
        !req.body || 
        Object.keys(req.body).length === 0 
    ) { 
 
        return res.status(400).json({ 
            error: "No input data provided" 
        }); 
 
    } 
 
    const result = 
        await runVoyagePython(req.body); 
 
    res.json({ 
        message: "Prediction OK", 
        data: result 
    }); 
 
} catch (err) { 
 
    console.error("ERROR:", err); 
 
    res.status(500).json({ 
        error: err.toString() 
    }); 
 
} 
});

01 — Validação

O servidor verifica se os dados foram realmente enviados.

02 — Python

O Node.js chama a função que executa o programa Python.

03 — Resposta

O resultado do Python é retornado ao frontend em formato JSON.
