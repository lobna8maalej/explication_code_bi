💳 Transaction ML Dashboard — Technical Documentation

This documentation explains in detail how TransactionDashboard.jsx works, its connection with transactionSlice.js, its TransactionDashboard.css file, as well as the use of React, Redux Toolkit, Recharts, Power BI and the Machine Learning prediction system.

Introduction

The Dashboard allows a Machine Learning prediction to be activated for an invoice-type transaction. A value of 18175 TND is sent to Redux through the createTransaction() action.

The prediction result is retrieved from Redux and displayed in a KPI card. The Dashboard also compares the predicted value with a fixed value corresponding to the Global Account (NCG).

At the same time, a Power BI report is integrated into the interface through an iframe element.

1. Project Overview

The TransactionDashboard.jsx component represents the React interface of a Dashboard dedicated to transaction data analysis and prediction.

It uses React to build the user interface.

It also uses Redux Toolkit to trigger the creation of a transaction and retrieve prediction data.

The component also uses the Recharts library to graphically represent the predicted value and the Global Account (NCG) value.

Finally, a Power BI report is integrated directly into the page through an iframe element.

14. Retrieving the Last Transaction 

const lastTransaction =
    items.length > 0
        ? items[items.length - 1]
        : null;

This instruction retrieves the last element of the items array.

The condition items.length > 0 first checks whether the array contains at least one transaction.

If the array contains data, the component retrieves: 

items[items.length - 1]

If the array is empty, the variable receives: 

null

↓

↓
Otherwise
↓

15. Why Retrieve the Last Transaction?

The component mainly wants to display the result of the most recent transaction.

Therefore, the lastTransaction variable provides direct access to the latest available transaction.

It is then used to display:

  • the transaction value;
  • the prediction;
  • the chart data.
