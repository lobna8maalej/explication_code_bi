🤖 Dashboard de Servidor de Machine Learning — Documentação Técnica

Esta documentação explica detalhadamente como funciona o componente ServerDashboard.jsx, sua conexão com serverSlice.js, seu arquivo ServerDashboard.css, bem como o uso de React, Redux Toolkit, useState, Power BI e o sistema de previsão de Machine Learning.

O Dashboard permite que o usuário selecione um modelo de Machine Learning, insira duas variáveis numéricas X1 e X2 e, em seguida, execute uma previsão utilizando Redux.

O resultado da previsão é posteriormente exibido na interface e adicionado a um histórico de previsões.

1. Visão Geral do Projeto

O componente ServerDashboard.jsx representa a interface principal de um Dashboard dedicado à previsão por meio de Machine Learning.

Ele utiliza React para construir a interface do usuário e gerenciar os estados locais.

Também utiliza Redux Toolkit para gerenciar os resultados das previsões, o estado de carregamento, os erros e o histórico.

O Dashboard também contém um relatório do Power BI integrado por meio de um elemento iframe.

Usuário ↓ ServerDashboard.jsx ↓ Seleção do modelo ↓ Entrada de X1 e X2 ↓ Validação ↓ dispatch(fetchServerPrediction()) ↓ serverSlice.js ↓ Processamento da previsão ↓ Redux Store ↓ result / loading / error / history ↓ ServerDashboard.jsx ↓ Exibição do resultado ↓ Histórico de previsões

Esses estados permitem que o componente memorize as seleções e os valores inseridos pelo usuário.

useSelector

14. Validação dos Campos

if (
x1 === "" ||
x2 === ""
) {

alert(
    "Please fill in x1 and x2."
);

return;

}

Essa condição verifica se X1 ou X2 estão vazios.

Se um dos dois campos não tiver sido preenchido, uma caixa de diálogo será exibida: 

Please fill in x1 and x2.

A palavra-chave return interrompe imediatamente a execução de handlePredict.

Por que essa validação é importante?

Ela evita que uma solicitação de previsão seja enviada com variáveis ausentes.

15. Conversão dos Valores em Números

const valueX1 = Number(x1);
const valueX2 = Number(x2);

Os valores provenientes dos campos HTML geralmente são recuperados como strings de texto.

A função Number() converte esses valores em números.

Por exemplo: 


x1 = "100"
↓
Number(x1)
↓
100

O mesmo princípio se aplica a X2.

16. Validação Numérica

if (

);

Essa condição verifica se os dois valores obtidos são realmente numéricos.

Number.isNaN() permite detectar um valor que não é um número válido.

Se X1 ou X2 não for válido, o sistema exibe: 


x1 and x2 must be numbers.

48. Ciclo Loading → Resultado

O usuário clica ↓ dispatch(fetchServerPrediction()) ↓ loading = true ↓ O botão é desativado ↓ "⏳ Calculating..." ↓ Processamento da previsão ↓ Resposta recebida ↓ loading = false ↓ result atualizado ↓ history atualizado ↓ Resultado exibido

Esse mecanismo permite que o usuário compreenda que o cálculo está em andamento.

49. Ciclo de Erro

O usuário clica ↓ dispatch() ↓ loading = true ↓ Erro durante o processamento ↓ Redux atualiza error ↓ loading = false ↓ ServerDashboard.jsx ↓ error && (...) ↓ Mensagem de erro exibida

A interface pode, portanto, informar ao usuário quando ocorre um erro durante a previsão.

60. Resumo Final para Lembrar

React constrói a interface → useState gerencia o modelo, X1 e X2 → o usuário insere as variáveis → handlePredict() valida os dados → dispatch(fetchServerPrediction()) envia a solicitação ao Redux → serverSlice.js processa a previsão → Machine Learning produz um valor → Redux atualiza result, loading, error e history → useSelector recupera essas informações → React renderiza novamente o componente → o valor previsto é exibido → o histórico é atualizado → Power BI exibe o Dashboard analítico → ServerDashboard.css controla a apresentação final.

O componente ServerDashboard.jsx constitui, portanto, a interface do usuário do sistema de previsão de Machine Learning.

Ele permite que o usuário selecione um modelo, insira duas variáveis numéricas e execute uma previsão.

Antes de enviar a solicitação, o componente verifica se X1 e X2 foram preenchidos e se podem ser convertidos em números.

A função dispatch() permite então enviar a solicitação para fetchServerPrediction() a partir de serverSlice.js.

O Redux gerencia posteriormente os diferentes estados da operação: result, loading, error e history.

Quando a previsão é bem-sucedida, o resultado é exibido em um cartão que contém o modelo utilizado, os valores X1 e X2, assim como o valor previsto.

Cada previsão também pode ser exibida no histórico utilizando history.map().

Ao mesmo tempo, o relatório do Power BI é integrado em um iframe para apresentar análises e indicadores de negócios.

Finalmente, ServerDashboard.css é responsável pela apresentação visual de todo o Dashboard.
