1. Descripción general del Dashboard

Este dashboard está dedicado al análisis de datos relacionados con los bancos.

Los datos utilizados en el proyecto se recopilan automáticamente de fuentes disponibles en Facebook mediante un proceso de Web Scraping.

El objetivo es transformar los datos recopilados en datos estructurados para producir indicadores y visualizaciones en Power BI, y posteriormente utilizar estos datos en un componente de Machine Learning.

8. Integración con Node.js / Express

El sistema de Machine Learning puede integrarse en el backend Node.js / Express para permitir que la aplicación se comunique con los scripts de Python.

Node.js utiliza el módulo child_process y la función spawn() para ejecutar el programa Python. 


const { spawn } = require("child_process");

const python = spawn(
    "python",
    ["prediction.py"]
);

El resultado generado por Python es posteriormente recuperado por Node.js y puede devolverse como una respuesta JSON mediante una ruta Express.

7. Machine Learning — Predicción bancaria

Después de preparar y estructurar los datos, se integra un componente de Machine Learning en el proyecto con el fin de producir una predicción basada en las variables seleccionadas.

7.1 Modelo entrenado

El modelo de Machine Learning se entrena y posteriormente se guarda en un archivo BNA.pkl. Este archivo contiene el modelo entrenado que posteriormente será cargado por el script Python responsable de realizar la predicción.

7.2 Archivo Python — banque.py

Función del archivo:

El archivo banque.py es el programa Python responsable de realizar la predicción. Recibe los datos enviados por Node.js en formato JSON, carga el modelo BNA.pkl, prepara las variables de entrada y ejecuta la predicción.

Código fuente


import sys
import json
import pickle
import os
import traceback

try:

    BASE_DIR = os.path.dirname(__file__)

    model_path = os.path.join(BASE_DIR, "BNA.pkl")

    model = pickle.load(open(model_path, "rb"))

    raw = sys.stdin.read().strip()

    print("RAW INPUT:", raw, file=sys.stderr)

    print("MODEL TYPE:", type(model), file=sys.stderr)

    input_data = json.loads(raw)

    X = [[
        float(input_data["x1"]),
        float(input_data["x2"])
    ]]

    result = model.predict(X)[0]

    print(json.dumps({
        "prediction": float(result)
    }))

except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Explicación del código

sys permite al programa Python comunicarse con el proceso iniciado por Node.js.

json se utiliza para leer los datos recibidos en formato JSON y devolver el resultado de la predicción en el mismo formato.

pickle se utiliza para cargar el modelo de Machine Learning previamente entrenado y guardado en BNA.pkl.

os se utiliza para construir la ruta hacia el archivo del modelo independientemente de la ubicación actual de ejecución.

traceback se utiliza para recuperar información detallada cuando se produce un error.

Carga del modelo


BASE_DIR = os.path.dirname(__file__)

model_path = os.path.join(BASE_DIR, "BNA.pkl")

model = pickle.load(open(model_path, "rb"))

BASE_DIR obtiene la carpeta en la que se encuentra el archivo Python. A continuación, se construye la ruta hacia BNA.pkl a partir de esta carpeta. Finalmente, pickle.load() vuelve a cargar el modelo de Machine Learning.

Recepción de los datos


raw = sys.stdin.read().strip()

input_data = json.loads(raw)

El script lee los datos enviados mediante la entrada estándar (stdin). Los datos recibidos se convierten posteriormente desde JSON a una estructura Python mediante json.loads().

Preparación de las variables de entrada


X = [[
    float(input_data["x1"]),
    float(input_data["x2"])
]]

Las dos variables x1 y x2 se recuperan de los datos JSON. Se convierten en números mediante float() y posteriormente se colocan en una estructura compatible con el modelo de Machine Learning.

Generación de la predicción


result = model.predict(X)[0]

El método predict() aplica el modelo entrenado a los datos de entrada. El resultado correspondiente a la primera predicción se obtiene mediante [0].

Retorno del resultado


print(json.dumps({
    "prediction": float(result)
}))

El resultado se convierte a JSON para que pueda ser recuperado fácilmente por Node.js.

Gestión de errores


except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Si se produce un error durante la carga del modelo, la lectura de los datos o la predicción, el programa devuelve un objeto JSON que contiene el mensaje de error y la traza detallada.
