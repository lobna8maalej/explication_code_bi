Documentação técnica detalhada do módulo imobiliário que permite conectar um banco de dados MySQL, uma API Node.js / Express e vários modelos de Machine Learning em Python.


Python Machine Learning Node.js Express MySQL JSON

1. Apresentação do módulo

O módulo imobiliário permite processar dados provenientes de agências imobiliárias e integrar previsões de Machine Learning em uma aplicação Web.

O sistema utiliza dois modelos de Machine Learning:

  • model_AROUS.pkl
  • model_gamma.pkl

Esses modelos são carregados pelo Python e depois utilizados para produzir duas previsões a partir de um mesmo valor de entrada.

Objetivo principal: permitir que o Node.js se comunique com o Python para utilizar os modelos de Machine Learning na aplicação Web.

3. Script Python de previsão

O script Python constitui a parte de Machine Learning.

📄 predict.py 
import sys

import json
import pickle
import numpy as np
import os

try:

print("START PYTHON", file=sys.stderr)

# ler input Node
data = json.load(sys.stdin)
print("INPUT:", data, file=sys.stderr)

value = data.get("value")

if value is None:
    raise ValueError("value manquante")

X_test = np.array([[float(value)]])

# verificar arquivos dos modelos ANTES do load
if not os.path.exists("model_AROUS.pkl"):
    raise FileNotFoundError("model_AROUS.pkl introuvable")

if not os.path.exists("model_gamma.pkl"):
    raise FileNotFoundError("model_gamma.pkl introuvable")

# carregar modelos
with open("model_AROUS.pkl", "rb") as f:
    model_arous = pickle.load(f)

with open("model_gamma.pkl", "rb") as f:
    model_gamma = pickle.load(f)

# previsões
prediction_arous = model_arous.predict(X_test)
prediction_gamma = model_gamma.predict(X_test)

result = {
    "status": "ok",
    "input": value,
    "arous": prediction_arous.tolist(),
    "gamma": prediction_gamma.tolist()
}

print(json.dumps(result))

except Exception as e:

print(json.dumps({
    "status": "error",
    "message": str(e)
}))

4. Leitura dos dados enviados pelo Node.js

4.1 Importação de sys 

import sys

O módulo sys permite, entre outras coisas, acessar os fluxos de entrada e saída do programa Python.

Aqui ele é utilizado com: 

sys.stdin

sys.stderr

4.2 Leitura da entrada padrão 

data = json.load(sys.stdin)

Esta instrução permite que o Python leia os dados JSON enviados para sua entrada padrão.

Por exemplo, o Node.js pode enviar: 

{
"value": 30
}

O Python transforma então esse JSON em um dicionário Python.

4.3 Exibição do conteúdo recebido 

print("INPUT:", data, file=sys.stderr)

Esta instrução exibe as informações recebidas na saída de erro padrão.

Por que stderr? As mensagens de diagnóstico são separadas da saída JSON destinada ao Node.js. Isso permite manter uma saída padrão limpa para o resultado final.

4.4 Recuperação de value 

value = data.get("value")

O método get() recupera a propriedade value do dicionário.

4.5 Verificação 

if value is None:
raise ValueError("value manquante")

Essa verificação impede que o modelo funcione se nenhum valor tiver sido fornecido.

5. Carregamento dos modelos de Machine Learning

5.1 Conversão da entrada 

X_test = np.array([[float(value)]])

O valor recebido é convertido em um número decimal com float().

Em seguida, ele é transformado em um array NumPy.

Exemplo: 

value = 30

X_test =
[[30.0]]

Essa estrutura corresponde a uma observação contendo uma variável.

5.2 Verificação do primeiro modelo 

if not os.path.exists("model_AROUS.pkl"):
raise FileNotFoundError(
    "model_AROUS.pkl introuvable"
)

Antes de carregar o modelo, o programa verifica se o arquivo realmente existe.

5.3 Verificação do segundo modelo 

if not os.path.exists("model_gamma.pkl"):
raise FileNotFoundError(
    "model_gamma.pkl introuvable"
)

A mesma verificação é realizada para model_gamma.pkl.

5.4 Carregamento de model_AROUS 

with open("model_AROUS.pkl", "rb") as f:
model_arous = pickle.load(f)

O arquivo é aberto em modo binário e o modelo é reconstruído usando pickle.load().

5.5 Carregamento de model_gamma 

with open("model_gamma.pkl", "rb") as f:
model_gamma = pickle.load(f)

O segundo modelo é carregado da mesma maneira.

Arquivo Variável Python Função

6. Execução das previsões

6.1 Previsão AROUS 

prediction_arous =
model_arous.predict(X_test)

O primeiro modelo recebe os dados X_test e calcula sua previsão.

6.2 Previsão Gamma 

prediction_gamma =

O segundo modelo recebe exatamente a mesma entrada, mas produz sua própria previsão.

Ponto importante: um único valor de entrada pode ser utilizado para produzir dois resultados diferentes graças aos dois modelos de Machine Learning.

7. Construção do resultado JSON 

result = {

"input": value,
"arous": prediction_arous.tolist(),

O objeto result reúne todas as informações necessárias para a resposta.

10. Rota POST /insert

Essa rota permite inserir dados imobiliários na tabela MySQL.

📄 routes/immobiliereRoute.js 
router.post("/insert", async (req, res) => {

let connection;

try {

    connection =
        await mysql.createConnection(dbConfig);

    const data = req.body;

    for (let row of data) {

        await connection.query(

            "INSERT INTO immobilier " +
            "(idImmobilier, Type, Surface, Prix, Source) " +
            "VALUES (?, ?, ?, ?, ?)",

            [
                row.idImmobilier,
                row.Type,
                row.Surface,
                row.Prix,
                row.Source
            ]

        );

    }

    res.json({

        status: "success",

        message: "Data inserted",

        rows: data.length

    });

}

catch (err) {

    res.status(500).json({

        status: "error",

        message: err.message

    });

}

finally {

    if (connection)
        await connection.end();

}

});

11. Rota POST /process-data

Essa rota permite realizar o processamento dos dados imobiliários armazenados no MySQL. 

router.post("/process-data", async (req, res) => {

let connection;

try {

    connection =
        await mysql.createConnection(dbConfig);

    const rawData =
        await fetchData(connection);

    const processedData =
        await processData(rawData);

    await insertData(
        connection,
        processedData
    );

    res.json({

        status: "success",

        message:
            "Immobilier data processed successfully",

        rows:
            processedData.length

    });

}

catch (err) {

    res.status(500).json({

        status: "error",

        message: err.message

    });

}

finally {

    if (connection)
        await connection.end();

}

});

Etapa 1 — Conexão MySQL 

connection =
await mysql.createConnection(dbConfig);

Uma conexão é criada com o banco de dados POWERBI_PREDICTION.

Etapa 2 — Recuperação dos dados 

const rawData =
await fetchData(connection);

A função fetchData() recupera os dados da tabela immobilier.

Etapa 3 — Processamento 

const processedData =
await processData(rawData);

Os dados são enviados para processData() para realizar as transformações necessárias.

Etapa 4 — Inserção 

await insertData(
connection,
processedData
);

Os dados transformados são inseridos na tabela: 

immobilier_processed

Etapa 5 — Resposta 

res.json({
status: "success",

    "Immobilier data processed successfully",

15. Gerenciamento de erros

O script Python utiliza: 

try:
...

except Exception as e:
...

Isso permite evitar que um erro do Python interrompa silenciosamente o processamento.

Exemplo: valor ausente 

if value is None:
raise ValueError("value manquante")

Exemplo: modelo ausente 

if not os.path.exists("model_AROUS.pkl"):
raise FileNotFoundError(
    "model_AROUS.pkl introuvable"
)

Resposta em caso de erro 

{
"status": "error",
"message": "..."
}

No Express, os erros também são capturados com: 

catch (err) {

res.status(500).json({

    status: "error",

    message: err.message

});

}
Resultado: o backend pode informar ao frontend que ocorreu um erro em vez de deixar a requisição falhar sem explicação.
