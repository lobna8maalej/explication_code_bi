MACHINE LEARNING

Predicción

De Business Intelligence al análisis predictivo

Business Intelligence permite principalmente analizar los datos existentes.

La predicción va más allá utilizando los datos históricos para estimar un valor futuro o desconocido.

Análisis descriptivo → Análisis predictivo
SCIKIT-LEARN

Regresión lineal

🤖

El modelo utilizado en el proyecto es regresión lineal.

Permite modelar una relación entre una o varias variables de entrada y una variable objetivo.

Python 
from sklearn.linear_model import LinearRegression 
 
model = LinearRegression()
10

ENTRENAMIENTO

Entrenamiento del modelo

📚 Datos de entrenamiento

El modelo se entrena utilizando datos históricos.

Python 
X = np.array([ 
[1, 10], 
[2, 20], 
[3, 30], 
[4, 40] 
]) 
 
y = np.array([15, 25, 35, 45])

X representa las variables de entrada y y representa la variable objetivo.

⚙️ Entrenamiento

El entrenamiento se realiza utilizando:

Python 
model.fit(X, y)

El modelo aprende la relación entre las variables de entrada y la variable objetivo.

SERIALIZACIÓN DEL MODELO

Guardado del modelo

Después del entrenamiento, el modelo se guarda en un archivo llamado MENTION.pkl.

Python 
with open("MENTION.pkl", "wb") as f: 
pickle.dump(model, f)
Datos históricos → Entrenamiento → MENTION.pkl → Nuevos datos → Predicción

COMUNICACIÓN

Envío y recuperación de datos

📤 Node.js → Python

py.stdin.write(JSON.stringify(data)); 
 
py.stdin.end();

Los datos de JavaScript se convierten a JSON y posteriormente se envían al programa Python.

📥 Python → Node.js

py.stdout.on("data", (data) => { 
output += data.toString(); 
 
});

Node.js recupera posteriormente la salida generada por Python.

17

REST API

Ruta Express /kantra

Una ruta POST permite al frontend enviar los datos necesarios para realizar la predicción.

POST /kantra
kantraRoute.js 
router.post("/", async (req, res) => { 
try { 
 
    const result = 
        await runPython("kantra.py", req.body); 
 
    res.json(result); 
 
} catch (err) { 
 
    res.status(500).json({ 
        success: false, 
        error: err?.error || 
               err?.message || 
               err 
    }); 
 
} 
});

CONCLUSIÓN

Un flujo completo de Datos → BI → Machine Learning

El proyecto Kantra me permitió trabajar en diferentes etapas de un proyecto de Datos, desde la preparación de los datos hasta su análisis y utilización predictiva.

Los datos de Facebook utilizados habían sido recopilados previamente por el centro de formación. Mi trabajo se centró en la preparación de los datos, la integración con Talend, la construcción del Data Warehouse, la creación del dashboard de Power BI y la implementación de una solución de predicción con Python.

La integración de Python con Node.js permite finalmente hacer que el modelo de Machine Learning sea accesible mediante una API.

Datos → ETL → Data Warehouse → BI → Machine Learning → API
