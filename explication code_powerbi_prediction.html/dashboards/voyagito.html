```
CONTEXTE

Présentation du projet

Le projet Voyagito est un projet réalisé dans le cadre de ma formation en Business Intelligence.

Ce projet m'a permis de pratiquer différentes étapes d'un projet Data, en commençant par l'extraction des données à partir de Facebook grâce au Web Scraping, puis leur préparation, leur intégration, leur visualisation et enfin leur exploitation à travers un modèle de Machine Learning.

L'objectif est de transformer des données brutes en informations exploitables pour l'analyse décisionnelle et la prédiction.
```

```
API REST

Route Express de prédiction

Une route Express reçoit les données envoyées par le frontend et déclenche le processus de prédiction Python.

POST /voyage
voyageRoute.js 
router.post("/", async (req, res) => {

try {

    if (
        !req.body ||
        Object.keys(req.body).length === 0
    ) {

        return res.status(400).json({
            error: "No input data provided"
        });

    }

    const result =
        await runVoyagePython(req.body);

    res.json({
        message: "Prediction OK",
        data: result
    });

} catch (err) {

    console.error("ERROR:", err);

    res.status(500).json({
        error: err.toString()
    });

}
```

});

```
CONCLUSION

Une expérience complète de la donnée à la prédiction

Le projet Voyagito m'a permis de pratiquer une chaîne complète de traitement des données, depuis leur extraction jusqu'à leur exploitation prédictive.

La pratique du Web Scraping dans le cadre de ma formation m'a permis de mieux comprendre la première étape d'un projet Data : récupérer des données exploitables à partir d'une source web.

J'ai ensuite travaillé sur la préparation des données, leur intégration, leur stockage dans un environnement décisionnel et leur visualisation avec Power BI.

Enfin, la partie Machine Learning m'a permis d'aller au-delà de l'analyse descriptive en utilisant les données pour produire une prédiction avec Python.

L'intégration de Python avec Node.js permet ensuite d'exposer cette fonctionnalité à travers une API, créant ainsi une architecture reliant Data, BI, Machine Learning et Backend.

Web Scraping → Data Cleaning → ETL → Data Warehouse → Power BI → Machine Learning → Python → Node.js → Prediction
```
