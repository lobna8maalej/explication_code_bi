🤖 Machine Learning Server Dashboard — Technical Documentation

This documentation explains in detail how the ServerDashboard.jsx component works, its connection with serverSlice.js, its ServerDashboard.css file, as well as the use of React, Redux Toolkit, useState, Power BI and the Machine Learning prediction system.

The Dashboard allows the user to select a Machine Learning model, enter two numerical variables X1 and X2, and then launch a prediction using Redux.

The prediction result is then displayed in the interface and added to a prediction history.

1. General Project Overview

The ServerDashboard.jsx component represents the main interface of a Dashboard dedicated to Machine Learning prediction.

It uses React to build the user interface and manage local states.

It also uses Redux Toolkit to manage prediction results, loading state, errors and history.

The Dashboard also contains a Power BI report integrated through an iframe element.

User ↓ ServerDashboard.jsx ↓ Model selection ↓ X1 and X2 input ↓ Validation ↓ dispatch(fetchServerPrediction()) ↓ serverSlice.js ↓ Prediction processing ↓ Redux Store ↓ result / loading / error / history ↓ ServerDashboard.jsx ↓ Result display ↓ Prediction history

14. Field Validation

x2 === ""
) {

);

This condition checks whether X1 or X2 is empty.

60. Final Summary to Remember

React builds the interface → useState manages the model, X1 and X2 → the user enters the variables → handlePredict() validates the data → dispatch(fetchServerPrediction()) sends the request to Redux → serverSlice.js processes the prediction → Machine Learning produces a value → Redux updates result, loading, error and history → useSelector retrieves this information → React re-renders the component → the predicted value is displayed → the history is updated → Power BI displays the analytical Dashboard → ServerDashboard.css controls the final presentation.

The ServerDashboard.jsx component therefore constitutes the user interface of the Machine Learning prediction system.

It allows the user to select a model, enter two numerical variables and launch a prediction.

Before sending the request, the component checks that X1 and X2 are provided and that they can be converted into numbers.

The dispatch() function then allows the request to be sent to fetchServerPrediction() from serverSlice.js.

Redux then manages the different states of the operation: result, loading, error and history.

When the prediction succeeds, the result is displayed in a card containing the model used, the X1 and X2 values, as well as the predicted value.

Each prediction can also be displayed in the history using history.map().

At the same time, the Power BI report is integrated into an iframe to present analyses and commercial indicators.

Finally, ServerDashboard.css is responsible for the visual presentation of the entire Dashboard.
