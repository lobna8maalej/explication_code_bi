📡 Radio Analytics Dashboard — Technical Documentation

This documentation explains in detail how the RadioDashboard.jsx component works, its connection with radioSlice.js, its RadioDashboard.css file, as well as the use of Redux Toolkit, Axios through the slice, Recharts, and Power BI.

The component provides an analytics interface that displays a Power BI report, retrieves information from the Redux store, and represents certain data as a Scatter Plot chart.

1. General Overview of the Project

The RadioDashboard.jsx component represents the main Dashboard interface dedicated to RADIO data.

It uses React to build the interface, Redux Toolkit to retrieve and manage global data, and Recharts to create a Scatter Plot chart.

The Dashboard also contains a Power BI report integrated directly into the page using an iframe element.

When the component loads, the fetchRadio() action is executed in order to retrieve the available information from the Redux store.

RadioDashboard.jsx ↓ useEffect() ↓ dispatch(fetchRadio()) ↓ radioSlice.js ↓ Data retrieval ↓ Redux ↓ data / loading / error ↓ RadioDashboard.jsx ↓ Information + Scatter Plot ↓ RadioDashboard.css ↓ Final interface

53. What RadioDashboard.jsx Actually Does

The RadioDashboard.jsx component mainly acts as a presentation and orchestration layer.

It does not directly contain the internal logic for retrieving data through fetchRadio().

It requests this retrieval using: 

dispatch(fetchRadio());

It then retrieves the result from Redux using: 

useSelector((state) => state.radio)

It then transforms some information into data compatible with Recharts.

54. Summary of Redux Operation

fetchRadio() ↓ Redux Action ↓ radioSlice.js ↓ Update of state.radio ↓ data / loading / error ↓ useSelector() ↓ RadioDashboard.jsx ↓ React re-render ↓ New display

When the Redux state changes, the component using useSelector is automatically updated with the new data.

55. Final Summary to Remember

React builds the interface → useEffect triggers fetchRadio() → Redux manages the state → useSelector retrieves data, loading, and error → React displays the information → chartData prepares the chart data → Recharts builds the Scatter Plot → Power BI displays the analytics report → RadioDashboard.css controls the presentation.

The RadioDashboard.jsx component therefore constitutes the main interface of the RADIO Dashboard.

It retrieves data from the Redux store through useSelector and triggers its retrieval using dispatch(fetchRadio()).

The component also manages the different interface states: loading, error, and data availability.

When the data is available, it displays the message, columns, and count information.

It also prepares chartData to build a Scatter Plot with Recharts. The X axis uses reputation_ranking and the Y axis uses tuition_fee.

At the same time, the Power BI report is integrated into an iframe, allowing the business intelligence Dashboard to be displayed directly within the React application.

Finally, RadioDashboard.css is responsible for the visual presentation, while radioSlice.js is responsible for the Redux management associated with RADIO data.
