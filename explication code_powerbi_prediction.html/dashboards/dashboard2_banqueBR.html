1. Visão geral do Dashboard

Este dashboard é dedicado à análise de dados relacionados aos bancos.

Os dados utilizados no projeto são coletados automaticamente de fontes disponíveis no Facebook por meio de um processo de Web Scraping.

O objetivo é transformar os dados coletados em dados estruturados para produzir indicadores e visualizações no Power BI, e posteriormente utilizar esses dados em um componente de Machine Learning.

8. Integração com Node.js / Express

O sistema de Machine Learning pode ser integrado ao backend Node.js / Express para permitir que a aplicação se comunique com os scripts Python.

O Node.js utiliza o módulo child_process e a função spawn() para executar o programa Python. 


const { spawn } = require("child_process");

const python = spawn(
    "python",
    ["prediction.py"]
);

O resultado gerado pelo Python é posteriormente recuperado pelo Node.js e pode ser retornado como uma resposta JSON por meio de uma rota Express.

7. Machine Learning — Predição bancária

Após preparar e estruturar os dados, um componente de Machine Learning é integrado ao projeto com o objetivo de produzir uma predição com base nas variáveis selecionadas.

7.1 Modelo treinado

O modelo de Machine Learning é treinado e posteriormente salvo em um arquivo BNA.pkl. Esse arquivo contém o modelo treinado que posteriormente será carregado pelo script Python responsável por realizar a predição.

7.2 Arquivo Python — banque.py

Função do arquivo:

O arquivo banque.py é o programa Python responsável por realizar a predição. Ele recebe os dados enviados pelo Node.js no formato JSON, carrega o modelo BNA.pkl, prepara as variáveis de entrada e executa a predição.

Código-fonte


import sys
import json
import pickle
import os
import traceback

try:

    BASE_DIR = os.path.dirname(__file__)

    model_path = os.path.join(BASE_DIR, "BNA.pkl")

    model = pickle.load(open(model_path, "rb"))

    raw = sys.stdin.read().strip()

    print("RAW INPUT:", raw, file=sys.stderr)

    print("MODEL TYPE:", type(model), file=sys.stderr)

    input_data = json.loads(raw)

    X = [[
        float(input_data["x1"]),
        float(input_data["x2"])
    ]]

    result = model.predict(X)[0]

    print(json.dumps({
        "prediction": float(result)
    }))

except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Explicação do código

sys permite que o programa Python se comunique com o processo iniciado pelo Node.js.

json é utilizado para ler os dados recebidos no formato JSON e retornar o resultado da predição no mesmo formato.

pickle é utilizado para carregar o modelo de Machine Learning previamente treinado e salvo em BNA.pkl.

os é utilizado para construir o caminho para o arquivo do modelo independentemente da localização atual de execução.

traceback é utilizado para obter informações detalhadas quando ocorre um erro.

Carregamento do modelo


BASE_DIR = os.path.dirname(__file__)

model_path = os.path.join(BASE_DIR, "BNA.pkl")

model = pickle.load(open(model_path, "rb"))

BASE_DIR obtém a pasta na qual o arquivo Python está localizado. Em seguida, o caminho para BNA.pkl é construído a partir dessa pasta. Por fim, pickle.load() recarrega o modelo de Machine Learning.

Recebimento dos dados


raw = sys.stdin.read().strip()

input_data = json.loads(raw)

O script lê os dados enviados por meio da entrada padrão (stdin). Os dados recebidos são então convertidos de JSON para uma estrutura Python usando json.loads().

Preparação das variáveis de entrada


X = [[
    float(input_data["x1"]),
    float(input_data["x2"])
]]

As duas variáveis x1 e x2 são recuperadas dos dados JSON. Elas são convertidas em números usando float() e posteriormente colocadas em uma estrutura compatível com o modelo de Machine Learning.

Geração da predição


result = model.predict(X)[0]

O método predict() aplica o modelo treinado aos dados de entrada. O resultado correspondente à primeira predição é obtido usando [0].

Retorno do resultado


print(json.dumps({
    "prediction": float(result)
}))

O resultado é convertido para JSON para que possa ser facilmente recuperado pelo Node.js.

Tratamento de erros


except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Se ocorrer um erro durante o carregamento do modelo, a leitura dos dados ou a predição, o programa retorna um objeto JSON contendo a mensagem de erro e o rastreamento detalhado.
