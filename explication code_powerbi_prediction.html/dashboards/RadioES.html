Sección Python — Carga del modelo de Machine Learning

El archivo Python representa la parte de Machine Learning del módulo. Es responsable de cargar el modelo diwan.pkl y preparar el resultado que será enviado a Node.js.

Código Python

📄 radio.py 
import os
import pickle
import json

# 📁 Ruta segura al modelo
BASE_DIR = os.path.dirname(__file__)
MODEL_PATH = os.path.join(BASE_DIR, "diwan.pkl")

# 🤖 Cargar el modelo
try:
    with open(MODEL_PATH, "rb") as f:
        model = pickle.load(f)

except Exception as e:
    print("Error al cargar el modelo:", str(e))
    model = None

# 📊 Resultado
result = {
    "status": "success" if model else "error",

    "prediction": 123.4,

    "rows": [
        {
            "reputation_ranking": 80,
            "tuition_fee": 5000,
            "Target": 1
        }
    ],

    "columns": [
        "reputation_ranking",
        "tuition_fee",
        "Target"
    ],

    "images": []
}

# 📤 Mostrar JSON
print(json.dumps(result))

Importación de librerías

El programa comienza importando tres librerías: os, pickle y json.

  • os: permite gestionar rutas y archivos.
  • pickle: permite cargar el modelo de Machine Learning guardado en el archivo .pkl.
  • json: permite convertir los resultados de Python al formato JSON para que Node.js pueda recuperarlos.

Construcción de la ruta del modelo

BASE_DIR = os.path.dirname(__file__)

MODEL_PATH = os.path.join(
    BASE_DIR,
    "diwan.pkl"
)

BASE_DIR obtiene el directorio en el que se encuentra el archivo Python.

A continuación, os.path.join() construye la ruta hacia el archivo diwan.pkl.

Este método es más seguro que escribir manualmente una ruta, ya que permite localizar correctamente el modelo.

Carga del modelo

with open(MODEL_PATH, "rb") as f:
    model = pickle.load(f)

El archivo diwan.pkl se abre en modo rb, que significa read binary.

La función pickle.load() recupera el objeto de Machine Learning almacenado en el archivo.

El modelo se almacena en la siguiente variable:

model

Gestión de errores

except Exception as e:
    print("Error al cargar el modelo:", str(e))
    model = None

El bloque try / except se utiliza para gestionar los errores que pueden producirse durante la carga del modelo.

Por ejemplo, si diwan.pkl no existe, el programa no se detiene inesperadamente. El modelo recibe el valor None.

Estado del modelo

"status": "success" if model else "error"

Esta instrucción comprueba si el modelo se ha cargado correctamente.

Si el modelo existe, el estado es:

success

De lo contrario, el estado se convierte en:

error

Importante: la predicción está actualmente simulada

Importante:

En el código proporcionado, el valor: 

"prediction": 123.4

es un valor simulado.

Todavía no se calcula directamente utilizando model.predict().

En una aplicación predictiva real, esta parte podría reemplazarse por una instrucción como: 

prediction = model.predict(X_test)

utilizando datos de entrada correspondientes a las variables utilizadas durante el entrenamiento del modelo.

Datos de `rows`

"rows": [
    {
        "reputation_ranking": 80,
        "tuition_fee": 5000,
        "Target": 1
    }
]

La propiedad rows contiene los datos que posteriormente serán recuperados por Node.js.

Cada objeto representa una fila de datos.

  • reputation_ranking: valor de ranking o reputación.
  • tuition_fee: valor numérico asociado a las tasas de matrícula.
  • Target: variable objetivo del modelo o resultado asociado a los datos.

Conversión a JSON

print(json.dumps(result))

Esta instrucción convierte el objeto Python a JSON.

Este paso es esencial porque Node.js recuperará esta salida y la utilizará dentro de la aplicación.

Servicio Node.js — Comunicación con Python

El archivo radioservice.js actúa como puente entre Node.js y Python.

Su función es ejecutar el programa Python, recuperar su salida JSON, detectar errores y convertir el JSON de Python en un objeto JavaScript.

Código Node.js

📄 radioservice.js 
const { spawn } = require("child_process");
const path = require("path");

function runPythonPlots() {

    return new Promise((resolve, reject) => {

        console.log("RADIOSERVICE LOADED");

        const py = spawn("python", [
            path.join(
                __dirname,
                "../../python/radio.py"
            )
        ]);

        let output = "";
        let error = "";

        py.stdout.on("data", (data) => {
            output += data.toString();
        });

        py.stderr.on("data", (data) => {
            error += data.toString();
        });

        py.on("close", (code) => {

            if (code !== 0) {
                return reject(
                    error || "Python error"
                );
            }

            try {

                const cleanOutput =
                    output.toString().trim();

                resolve(
                    JSON.parse(cleanOutput)
                );

            } catch (e) {

                console.log(
                    "RAW OUTPUT:",
                    output
                );

                reject(
                    "Invalid JSON from Python"
                );
            }
        });

    });
}

module.exports = {
    runPythonPlots
};

Importación de `child_process`

Permite a Node.js ejecutar programas externos.

Aquí se utiliza para ejecutar:

Uso de `spawn()`

    path.join(

        "../../python/radio.py"

Esta instrucción solicita a Node.js que ejecute el programa Python y el archivo radio.py.

Ruta Express `/radio`

La ruta es responsable de coordinar todo el proceso: conexión con MySQL, ejecución de Python, validación de datos, inserción en MySQL y respuesta final.

📄 radioRoute.js 
const express = require("express");
const router = express.Router();

const {
    runPythonPlots
} = require("../service/radioservice");

const {
    getConnection
} = require("../DBMysql/radiodb");

router.get("/", async (req, res) => {

    let connection;

    try {

        connection = await getConnection();

        const result =
            await runPythonPlots();

        if (
            !result ||
            !result.rows ||
            !Array.isArray(result.rows)
        ) {

            return res.status(400).json({
                error: "Invalid Python output"
            });
        }

        for (const row of result.rows) {

            await connection.execute(
                `INSERT INTO plot_data
                (reputation_ranking,
                tuition_fee,
                Target)
                VALUES (?, ?, ?)`,
                [
                    row.reputation_ranking ?? 0,
                    row.tuition_fee ?? 0,
                    row.Target ?? 0
                ]
            );
        }

        res.json({

            message:
                "Plots processed successfully",

            count:
                result.rows.length,

            columns:
                result.columns || [],

            images:
                result.images || []
        });

    } catch (err) {

        console.error(
            "ERROR:",
            err
        );

        res.status(500).json({
            error: err.toString()
        });

    } finally {

        if (connection) {
            await connection.end();
        }
    }
});

module.exports = router;

Explicación para una presentación comercial

Durante una presentación comercial, no es necesario leer cada línea de código. El objetivo principal es explicar el funcionamiento general y el valor que aporta esta arquitectura.

🎤 Ejemplo de explicación

“En esta parte del proyecto, integré un modelo de Machine Learning desarrollado en Python en una aplicación web basada en Node.js y Express.

El modelo está guardado en un archivo diwan.pkl. Cuando la aplicación solicita los resultados, Express recibe la solicitud y llama a un servicio dedicado de Node.js.

Este servicio utiliza child_process.spawn() para ejecutar Python y lanzar el script de Machine Learning. Python carga entonces el modelo utilizando pickle.

El resultado generado por Python se convierte a JSON. Node.js recupera este JSON, lo convierte en un objeto JavaScript y verifica que los datos recibidos sean válidos.

Los datos validados se almacenan posteriormente en MySQL, dentro de la tabla plot_data.

Finalmente, Express devuelve una respuesta JSON al frontend. El dashboard puede utilizar esta información para mostrar tablas, indicadores o gráficos.

La ventaja de esta arquitectura es que cada tecnología tiene una función específica: Python se encarga del Machine Learning, Node.js y Express gestionan la API y la comunicación, MySQL proporciona el almacenamiento de datos y el frontend se encarga de la visualización.

Esta separación hace que el sistema sea más organizado, mantenible y escalable.”
