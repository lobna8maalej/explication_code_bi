Business Intelligence mainly makes it possible to analyze existing data.

SCIKIT-LEARN

Linear Regression

🤖

The model used in the project is linear regression.

It makes it possible to model a relationship between one or more input variables and a target variable.

Python 
from sklearn.linear_model import LinearRegression

model = LinearRegression()
10

TRAINING

Model Training

📚 Training Data

The model is trained using historical data.

Python 
X = np.array([
[1, 10],
[2, 20],
[3, 30],
[4, 40]
])

y = np.array([15, 25, 35, 45])

X represents the input variables and y represents the target variable.

⚙️ Training

Training is performed using:

Python 
model.fit(X, y)

The model learns the relationship between the input variables and the target variable.

MODEL SERIALIZATION

Model Saving

After training, the model is saved in a file called MENTION.pkl.

Python 
with open("MENTION.pkl", "wb") as f:
pickle.dump(model, f)
Historical data → Training → MENTION.pkl → New data → Prediction

Communication with Python

Node.js 
const { spawn } = require("child_process");

const py = spawn("python", [scriptPath]);

The child_process module allows Node.js to launch the Python script.

16

COMMUNICATION

Sending and Retrieving Data

📤 Node.js → Python

py.stdin.write(JSON.stringify(data));

py.stdin.end();

The JavaScript data is converted into JSON and then sent to the Python program.

📥 Python → Node.js

py.stdout.on("data", (data) => {
output += data.toString();

});

Node.js then retrieves the output generated by Python.

17

REST API

Express Route /kantra

A POST route allows the frontend to send the data required for prediction.

POST /kantra
kantraRoute.js 
router.post("/", async (req, res) => {
try {

    const result =
        await runPython("kantra.py", req.body);

    res.json(result);

} catch (err) {

    res.status(500).json({
        success: false,
        error: err?.error ||
               err?.message ||
               err
    });

}
});
