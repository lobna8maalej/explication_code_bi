📊 Dashboard Plot — Explication du code

Documentation technique détaillée du fonctionnement de React, Redux Toolkit, Axios, Recharts et Power BI dans le Dashboard Plot.

Cette documentation explique le rôle de chaque partie du fichier PlotDashboard.jsx et du fichier plotSlice.js, ainsi que le parcours des données entre le frontend React, Redux et le backend.

# 152 — Présentation du Dashboard Plot

Le Dashboard Plot est une interface frontend développée avec React. Son objectif est de récupérer des données depuis le backend, de les stocker avec Redux Toolkit, de les afficher sous forme de liste et de les représenter graphiquement avec Recharts. Le dashboard intègre également un rapport Power BI grâce à une iframe. La fonctionnalité repose donc sur plusieurs technologies qui travaillent ensemble. React construit l'interface. Redux Toolkit gère l'état des données. Axios communique avec l'API backend. Recharts crée le graphique à barres. Power BI fournit une visualisation Business Intelligence intégrée.

# 153 — Organisation des fichiers

La fonctionnalité Plot repose principalement sur deux fichiers JavaScript :

📄 PlotDashboard.jsx

Ce fichier contient le composant React. Il est responsable de l'affichage du dashboard, de la récupération du state Redux et de la représentation graphique des données.

📄 plotSlice.js

Ce fichier contient la logique Redux. Il récupère les données depuis le backend avec Axios et gère les états loading, error, message et rows.

Cette séparation permet de respecter une architecture claire. Le composant React s'occupe principalement de l'interface tandis que Redux centralise la logique de récupération et de gestion des données.

# 154 — Importation de React et useEffect

Le fichier PlotDashboard.jsx commence par l'importation de React et du hook useEffect : 


```

import React, { useEffect } from "react";
```

React permet de créer le composant d'interface utilisateur. Le hook useEffect permet d'exécuter du code après le rendu du composant. Dans notre cas, il est utilisé pour déclencher automatiquement la récupération des données Plot lorsque le dashboard est chargé. L'utilisateur n'a donc pas besoin d'appuyer sur un bouton pour récupérer les données.

# 155 — Importation de useDispatch et useSelector

Le composant importe ensuite les deux hooks principaux de React Redux : 


```

import {
useDispatch,
useSelector
} from "react-redux";
```

useDispatch() permet au composant d'envoyer une action vers Redux. Dans ce projet, il sera utilisé pour exécuter : 


```

dispatch(fetchPlotData());
```

useSelector() permet au composant de récupérer les données stockées dans le store Redux. Le composant récupère ici : loading, error, message, et rows. Ces valeurs permettent à l'interface de connaître l'état actuel de la requête et les données disponibles.

# 156 — Importation de fetchPlotData

Le composant importe l'action asynchrone fetchPlotData : 


```

import { fetchPlotData }
from "../redux/plotSlice";
```

Cette fonction est définie dans plotSlice.js. Elle utilise createAsyncThunk() pour effectuer une requête asynchrone vers le backend. Le composant React ne contient donc pas directement la logique Axios. Il demande simplement à Redux de récupérer les données.

# 157 — Importation des composants Recharts

Le dashboard utilise plusieurs composants de la bibliothèque Recharts : 


```

import {
BarChart,
Bar,
XAxis,
YAxis,
Tooltip,
CartesianGrid,
Legend,
ResponsiveContainer
} from "recharts";
```

Chaque composant possède une fonction précise.

  • BarChart : structure générale du graphique.
  • Bar : représente une série de données sous forme de barres.
  • XAxis : représente l'axe horizontal.
  • YAxis : représente l'axe vertical.
  • Tooltip : affiche des informations lors du survol.
  • CartesianGrid : ajoute une grille au graphique.
  • Legend : affiche la légende des séries.
  • ResponsiveContainer : rend le graphique adaptable à la largeur disponible.

# 160 — Initialisation de dispatch

Le composant initialise la fonction dispatch : 


```

const dispatch = useDispatch();
```

dispatch représente le mécanisme permettant d'envoyer des actions vers Redux. Dans notre cas, il permettra de déclencher la récupération des données : 


```

dispatch(fetchPlotData());
```

Cette instruction démarre donc le traitement défini dans plotSlice.js.

# 161 — Lecture du state Redux

Le composant récupère ensuite les données depuis le store Redux : 


```

const {
loading,
error,
message,
rows
} = useSelector(state => state.plot);
```

Le composant accède à :

  • loading : indique si les données sont en cours de récupération.
  • error : contient une éventuelle erreur.
  • message : contient le message retourné par le backend.
  • rows : contient les lignes de données Plot.

Grâce à useSelector(), toute modification de ces valeurs dans Redux entraîne automatiquement une mise à jour de l'interface React.

# 162 — Déclenchement automatique de la requête

Le hook useEffect contient : 


```

useEffect(() => {
dispatch(fetchPlotData());
}, [dispatch]);
```

Lorsque le composant est chargé, React exécute ce hook. Celui-ci appelle : dispatch(fetchPlotData()). Redux Toolkit commence alors l'exécution du thunk fetchPlotData. Le processus de récupération des données démarre donc automatiquement.

# 163 — Création de chartData

Les données reçues dans rows sont préparées pour Recharts : 


```

const chartData = rows.map((item) => ({
name: `X${item.x}`,
X: item.x,
Y: item.y
}));
```

La méthode map() parcourt chaque élément du tableau rows. Pour chaque ligne, un nouvel objet est créé.

La propriété : 


```

name: `X${item.x}`
```

construit le nom utilisé sur l'axe horizontal. Par exemple, si item.x = 10, le nom devient : X10.

La propriété : 


```

X: item.x
```

conserve la valeur X.

La propriété : 


```

Y: item.y
```

conserve la valeur Y. Le tableau chartData devient donc une structure adaptée à Recharts.
