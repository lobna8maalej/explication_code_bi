```
📊 Plot Dashboard — Code Explanation

Detailed technical documentation explaining how React, Redux Toolkit, Axios, Recharts, and Power BI work together in the Plot Dashboard.

This documentation explains the role of each part of the PlotDashboard.jsx file and the plotSlice.js file, as well as the data flow between the React frontend, Redux, and the backend.
```

```
# 152 — Plot Dashboard Overview

The Plot Dashboard is a frontend interface developed with React. Its purpose is to retrieve data from the backend, store it using Redux Toolkit, display it as a list, and represent it graphically using Recharts. The dashboard also integrates a Power BI report through an iframe. The functionality therefore relies on several technologies working together. React builds the user interface. Redux Toolkit manages the application state. Axios communicates with the backend API. Recharts creates the bar chart. Power BI provides an integrated Business Intelligence visualization.

```
```

# 153 — File Organization

The Plot functionality mainly relies on two JavaScript files:

📄 PlotDashboard.jsx

This file contains the React component. It is responsible for displaying the dashboard, retrieving the Redux state, and representing the data graphically.

📄 plotSlice.js

This file contains the Redux logic. It retrieves data from the backend using Axios and manages the loading, error, message, and rows states.

This separation helps maintain a clear architecture. The React component mainly handles the user interface, while Redux centralizes the data retrieval and data management logic.

```
```

# 154 — Importing React and useEffect

The PlotDashboard.jsx file begins by importing React and the useEffect hook: 


```

import React, { useEffect } from "react";
```

React is used to create the user interface component. The useEffect hook allows code to be executed after the component has rendered. In our case, it is used to automatically trigger the retrieval of Plot data when the dashboard is loaded. The user therefore does not need to click a button to retrieve the data.

```
```

# 155 — Importing useDispatch and useSelector

The component then imports the two main hooks from React Redux: 


```

import {
useDispatch,
useSelector
} from "react-redux";
```

useDispatch() allows the component to send an action to Redux. In this project, it is used to execute: 


```

dispatch(fetchPlotData());
```

useSelector() allows the component to retrieve data stored in the Redux store. The component retrieves: loading, error, message, and rows. These values allow the interface to know the current state of the request and the available data.

```
```

# 156 — Importing fetchPlotData

The component imports the asynchronous action fetchPlotData: 


```

import { fetchPlotData }
from "../redux/plotSlice";
```

This function is defined in plotSlice.js. It uses createAsyncThunk() to perform an asynchronous request to the backend. The React component therefore does not contain the Axios logic directly. It simply asks Redux to retrieve the data.
```

```
# 157 — Importing Recharts Components

The dashboard uses several components from the Recharts library: 


```

import {
BarChart,
Bar,
XAxis,
YAxis,
Tooltip,
CartesianGrid,
Legend,
ResponsiveContainer
} from "recharts";
```

Each component has a specific role.

  • BarChart: provides the general structure of the chart.
  • Bar: represents a data series using bars.
  • XAxis: represents the horizontal axis.
  • YAxis: represents the vertical axis.
  • Tooltip: displays information when the user hovers over the chart.
  • CartesianGrid: adds a grid to the chart.
  • Legend: displays the legend for the data series.
  • ResponsiveContainer: makes the chart responsive to the available width.
```

```
# 161 — Reading the Redux State

The component then retrieves data from the Redux store: 


```

const {
loading,
error,
message,
rows
} = useSelector(state => state.plot);
```

The component accesses:

  • loading: indicates whether the data is currently being retrieved.
  • error: contains a possible error.
  • message: contains the message returned by the backend.
  • rows: contains the Plot data rows.

Thanks to useSelector(), any modification of these values in Redux automatically causes the React interface to update.
```

```
# 162 — Automatically Triggering the Request

The useEffect hook contains: 


```

useEffect(() => {
dispatch(fetchPlotData());
}, [dispatch]);
```

When the component is loaded, React executes this hook. It calls: dispatch(fetchPlotData()). Redux Toolkit then starts executing the fetchPlotData thunk. The data retrieval process therefore starts automatically.

```

```
# 163 — Creating chartData

The data received in rows is prepared for Recharts: 


```

const chartData = rows.map((item) => ({
name: `X${item.x}`,
X: item.x,
Y: item.y
}));
```

The map() method iterates through each element of the rows array. For each row, a new object is created.

The property: 


```

name: `X${item.x}`
```

builds the name used on the horizontal axis. For example, if item.x = 10, the name becomes: X10.

The property: 


```

X: item.x
```

keeps the X value.

The property: 


```

Y: item.y
```

keeps the Y value. The chartData array therefore becomes a structure adapted to Recharts.
```
