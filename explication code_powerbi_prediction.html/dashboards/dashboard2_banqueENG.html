7. Machine Learning — Bank Prediction

After preparing and structuring the data, a Machine Learning component is integrated into the project in order to produce a prediction based on the selected variables.

7.1 Trained Model

The Machine Learning model is trained and then saved in a BNA.pkl file. This file contains the trained model that will then be loaded by the Python script responsible for performing the prediction.

7.2 Python File — banque.py

File Role:

The banque.py file is the Python program responsible for performing the prediction. It receives the data sent by Node.js in JSON format, loads the BNA.pkl model, prepares the input variables, and performs the prediction.

Source Code


import sys
import json
import pickle
import os
import traceback

try:

    BASE_DIR = os.path.dirname(__file__)

    model_path = os.path.join(BASE_DIR, "BNA.pkl")

    model = pickle.load(open(model_path, "rb"))

    raw = sys.stdin.read().strip()

    print("RAW INPUT:", raw, file=sys.stderr)

    print("MODEL TYPE:", type(model), file=sys.stderr)

    input_data = json.loads(raw)

    X = [[
        float(input_data["x1"]),
        float(input_data["x2"])
    ]]

    result = model.predict(X)[0]

    print(json.dumps({
        "prediction": float(result)
    }))

except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

Code Explanation

sys allows the Python program to communicate with the process launched by Node.js.

json is used to read the received data in JSON format and return the prediction result in the same format.

pickle is used to load the previously trained Machine Learning model saved in BNA.pkl.

os is used to build the path to the model file independently of the current execution location.

traceback is used to retrieve detailed information when an error occurs.

Model Loading


BASE_DIR = os.path.dirname(__file__)

model_path = os.path.join(BASE_DIR, "BNA.pkl")

model = pickle.load(open(model_path, "rb"))

BASE_DIR retrieves the folder in which the Python file is located. The path to BNA.pkl is then built from this folder. Finally, pickle.load() reloads the Machine Learning model.

Data Reception


raw = sys.stdin.read().strip()

input_data = json.loads(raw)

The script reads the data sent through standard input (stdin). The received data is then converted from JSON into a Python structure using json.loads().

Input Variable Preparation


X = [[
    float(input_data["x1"]),
    float(input_data["x2"])
]]

The two variables x1 and x2 are retrieved from the JSON data. They are converted into numbers using float() and then placed into a structure compatible with the Machine Learning model.

Generating the Prediction


result = model.predict(X)[0]

The predict() method applies the trained model to the input data. The result corresponding to the first prediction is retrieved using [0].

Returning the Result


print(json.dumps({
    "prediction": float(result)
}))

The result is converted into JSON so that it can be easily retrieved by Node.js.

Error Handling


except Exception as e:

    print(json.dumps({
        "error": str(e),
        "trace": traceback.format_exc()
    }))

If an error occurs while loading the model, reading the data, or performing the prediction, the program returns a JSON object containing the error message as well as the detailed trace.
