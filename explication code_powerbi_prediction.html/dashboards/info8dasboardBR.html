📊 Explicación del componente InfoDashboard.jsx, del archivo infoSlice.js y de su conexión con CSS

Esta documentación explica el funcionamiento del Dashboard GOMYCODE AI y la comunicación entre React, Redux Toolkit, Axios, el backend, Machine Learning, Power BI, Recharts y el archivo CSS asociado.

1. Presentación general

El componente InfoDashboard.jsx constituye la interfaz React del Dashboard dedicado al análisis y la predicción de los datos de GOMYCODE. Utiliza varias tecnologías complementarias para recuperar una predicción desde el backend, gestionar su estado con Redux Toolkit, mostrar un informe de Power BI integrado y representar la predicción en forma de gráfico con Recharts.

El archivo infoSlice.js constituye la parte de Redux Toolkit responsable de la recuperación y gestión de los datos de predicción.

Finalmente, el archivo InfoDashboard.css es responsable de la presentación visual del componente InfoDashboard.jsx.

``` InfoDashboard.jsx
↓
useEffect()
↓
dispatch(fetchInfoData())
↓
infoSlice.js
↓
Axios
↓
Backend / Machine Learning
↓
Resultado de la predicción
↓
Redux
↓
InfoDashboard.jsx
↓
InfoDashboard.css
↓
Interfaz final
```

2. Imports de InfoDashboard.jsx

El archivo InfoDashboard.jsx comienza importando React y el hook useEffect. El hook useEffect permite ejecutar automáticamente una operación después de cargar el componente.

El componente también importa useDispatch y useSelector desde react-redux. useDispatch permite enviar una acción Redux, mientras que useSelector permite recuperar los datos almacenados en el store de Redux.

El componente importa después fetchInfoData desde ../redux/infoSlice. Esta función asíncrona es responsable de realizar la solicitud al backend para obtener la predicción.

También se importan varios componentes de la biblioteca Recharts: BarChart, Bar, XAxis, YAxis, Tooltip, CartesianGrid y ResponsiveContainer.

Punto importante:

El archivo React también contiene: 

import "./InfoDashboard.css";

Esta instrucción se encuentra en InfoDashboard.jsx, y no en el archivo HTML de documentación.

4. La función InfoDashboard

La función InfoDashboard representa el componente principal de React.

Al inicio del componente, const dispatch = useDispatch() permite obtener la función dispatch de Redux.

Esta función permite al componente enviar la acción fetchInfoData() al store de Redux.

Después, useSelector se utiliza con (state) => state.info para recuperar las tres informaciones principales:

  • data: contiene el resultado de la predicción.
  • loading: indica si la solicitud está en curso.
  • error: contiene un posible error.

6. Preparación de chartData

La constante chartData prepara los datos necesarios para Recharts. 

const chartData = data
? [
    {
        name: "GOMYCODE",
        prediction: data.gomycode_pred
    }

: [];

Si data existe, se crea un array que contiene un objeto.

El objeto contiene:

  • name con el valor "GOMYCODE"
  • prediction con el valor data.gomycode_pred

Si los datos todavía no están disponibles, se devuelve un array vacío:

Esta precaución evita utilizar datos inexistentes durante el primer renderizado.

18. Gestión de la respuesta

Después de ejecutar la solicitud Axios, el código: 

return res.data.data;

recupera los datos útiles de la respuesta HTTP.

Este valor se convierte posteriormente en el resultado de la acción asíncrona de Redux.

19. Gestión de errores con try/catch

La función utiliza un bloque try/catch para gestionar el éxito o el fallo de la solicitud. 

try {
...
```

} catch (err) {
...
}
```

En caso de error, el código utiliza: 

thunkAPI.rejectWithValue(
err.response?.data || err.message
```

)
```

El operador ?. permite acceder a response.data únicamente si response existe.

Si no existe una respuesta del servidor, se utiliza err.message.

21. fetchInfoData.pending

Cuando comienza la solicitud, Redux activa: 

fetchInfoData.pending

El estado se modifica entonces: 

state.loading = true;
```

state.error = null;
```

React recupera después este nuevo valor mediante useSelector.

``` Redux
↓
loading = true
↓
React
↓
className="loading"
↓
InfoDashboard.css
↓
Mensaje de carga estilizado
```

22. fetchInfoData.fulfilled

Cuando la solicitud tiene éxito, Redux activa: 

fetchInfoData.fulfilled

El código establece entonces: 

state.loading = false;
```

state.data = action.payload;
```

La predicción queda, por lo tanto, almacenada en state.info.data.

Gracias a useSelector, el componente React recupera automáticamente los nuevos datos y actualiza su interfaz.

23. fetchInfoData.rejected

Si la solicitud falla, Redux activa: 

fetchInfoData.rejected

El estado pasa a ser: 

state.loading = false;
```

state.error = action.payload;
```

React recupera después error y muestra el mensaje correspondiente mediante la clase CSS error.

24. Conexión entre Redux, React y CSS

Es importante entender que Redux no se comunica directamente con CSS.

Redux proporciona los datos y los estados a React. React decide después qué elementos deben mostrarse. Finalmente, className permite conectar estos elementos con el archivo CSS.

``` infoSlice.js
↓
data / loading / error
↓
InfoDashboard.jsx
↓
JSX + className
↓
InfoDashboard.css
↓
Presentación visual
```

27. Flujo completo del proyecto

Cuando el usuario abre el Dashboard, React carga InfoDashboard.jsx.

El useEffect se ejecuta entonces y activa: 

dispatch(fetchInfoData());

Redux Toolkit entra en el estado pending y establece loading en true.

Axios envía después los valores: 

[1000, 2500]

hacia: 

POST /info/predict

El backend recibe estos valores y utiliza el modelo de Machine Learning para calcular la predicción.

El resultado vuelve después a Redux.

Si la solicitud tiene éxito, Redux entra en el estado fulfilled y almacena el resultado en: 

state.info.data

useSelector recupera entonces los nuevos datos. React actualiza automáticamente la interfaz.

El valor data.gomycode_pred se muestra en la tarjeta de predicción y se utiliza para construir chartData.

Recharts utiliza después chartData para crear el gráfico.

Al mismo tiempo, el iframe muestra el informe de Power BI.

Finalmente, InfoDashboard.css aplica los estilos a los diferentes elementos mediante className.

29. Resumen para recordar durante la presentación

React construye → Redux gestiona → Axios comunica → Backend predice → Recharts visualiza → Power BI analiza → CSS presenta.

El componente InfoDashboard.jsx construye la interfaz y recupera la información desde Redux. El archivo infoSlice.js gestiona la solicitud asíncrona y los estados data, loading y error.

Axios se encarga de la comunicación con el backend, que utiliza el sistema de Machine Learning para producir la predicción.

Recharts transforma después la predicción en una representación gráfica y Power BI proporciona el informe de inteligencia empresarial integrado.

Finalmente, InfoDashboard.css no realiza la predicción ni recupera los datos. Su función es controlar la apariencia de los elementos creados por React.

La conexión entre React y CSS se realiza mediante import "./InfoDashboard.css"; en el archivo JSX y mediante los className que corresponden a los selectores CSS.
