```
💳 Dashboard ML de Transacciones — Documentación Técnica

Esta documentación explica en detalle cómo funciona el TransactionDashboard.jsx, su conexión con transactionSlice.js, su archivo TransactionDashboard.css, así como el uso de React, Redux Toolkit, Recharts, Power BI y el sistema de predicción de Machine Learning.

Introducción

El Dashboard permite activar una predicción de Machine Learning para una transacción de tipo invoice. Se envía un valor de 18175 TND a Redux mediante la acción createTransaction().

El resultado de la predicción se recupera de Redux y se muestra en una tarjeta KPI. El Dashboard también compara el valor predicho con un valor fijo correspondiente a la Cuenta Global (NCG).

Al mismo tiempo, un informe de Power BI se integra en la interfaz mediante un elemento iframe.
```

```

1. Descripción general del proyecto

El componente TransactionDashboard.jsx representa la interfaz de React de un Dashboard dedicado al análisis y la predicción de datos de transacciones.

Utiliza React para construir la interfaz de usuario.

También utiliza Redux Toolkit para activar la creación de una transacción y recuperar los datos de predicción.

El componente también utiliza la biblioteca Recharts para representar gráficamente el valor predicho y el valor de la Cuenta Global (NCG).

Finalmente, un informe de Power BI se integra directamente en la página mediante un elemento iframe.
```

```
14. Búsqueda de la última transacción 

```

const lastTransaction =
items.length > 0
? items[items.length - 1]
: null;
```

Esta instrucción recupera el último elemento del array items.

La condición items.length > 0 comprueba primero si el array contiene al menos una transacción.

Si el array contiene datos, el componente recupera: 

```

items[items.length - 1]
```

Si el array está vacío, la variable recibe: 

```

null
``` 
```

¿items contiene datos?
↓
Sí → Última transacción
↓
En caso contrario
↓
null
```

15. ¿Por qué recuperar la última transacción?

El componente desea principalmente mostrar el resultado de la transacción más reciente.

Por lo tanto, la variable lastTransaction proporciona acceso directo a la última transacción disponible.

A continuación, se utiliza para mostrar:

  • el valor de la transacción;
  • la predicción;
  • los datos del gráfico.
```
